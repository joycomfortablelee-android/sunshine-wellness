## 1. 워드가 여백을 넘고 있었다 — `bceca60`

사용자가 **「그린박스가 넓어서 튀어 나가고 있어. 내용적 손실은 절대 없이」**라 했다.
워크북 DOCX의 AI 기록 상자가 오른쪽 여백을 넘어가 있었다.

원인은 표 폭 지정이 **두 겹으로 어긋나** 있던 것이다.

```
본문 폭 18.20cm  |  표가 실제로 차지한 폭 18.4cm 남짓
                 └ tblW 가 auto  ·  tblInd 없음  ·  셀 여백 워드 기본값 108twips
```

`wb_lib.py` 의 `_set_tblpr()` 를 고쳤다. **`tblPr` 의 자식은 순서가 정해져 있어서**
(`tblW → jc → tblInd → tblLayout → tblCellMar → tblLook`) 아무 데나 붙이면 워드가 무시한다.
`tblLook` 앞에 순서대로 끼우고, 표 최대폭을 **17.9cm**(여유 0.3), 셀 여백을 **57twips**로 낮췄다.

> **한 번 헛디뎠다.** 처음엔 `tblW` 를 새로 만들어 붙였는데, python-docx 가 이미 만들어 둔
> `auto` 짜리가 앞에 있어서 `find()` 가 그것을 집었다. **있는 것을 고쳐야 했다.**

행 폭은 twips 로 직접 못박았다 — `Cm()` 로 왕복시키면 반올림에서 1twip 씩 새고,
그 오차가 열여섯 시트에 쌓이면 다시 넘친다. 반올림 나머지는 **끝 칸이 흡수**하게 했다.

같은 커밋에서 페이지의 알약 문구를 **「16주」 → 「16시트」**로 바꿨다.
시간이 아니라 분량이라는 것 — 사용자의 지적이 맞다.

## 2. 위캔 · 캔슬마켓 — 목록에서 회사 하나를 꺼내다 — `6fe57eb` · `d0d91c3`

사용자가 PT 두 개를 주며 **「THE VC 카드 아래에 제시해줘」**라 했다.
열어 보니 **성격이 갈리는 두 파일**이었다.

| 파일 | 정체 |
|---|---|
| `위캔_캔슬마켓_4장_PT.pptx` (6.0MB) | 그림만 있는 **시각 요약본** 네 장 |
| `wecan_cancelmarket_pt.ppt` (578KB) | 텍스트 + **발표자 노트**가 붙은 **본편** 열 장 |

그래서 **요약본은 캐러셀로 보이고, 본편은 내려받게** 했다.
6MB짜리 pptx 는 저장소에 넣지 않았다 — 네 장이 그대로 WebP(각 170~210KB)로 들어가 있으니
같은 것을 두 번 두는 셈이다.

캐러셀은 만화 캐러셀과 같은 조작을 쓰되 **키 입력을 뷰어에 가뒀다**(`stopPropagation`).
문서 전체에 걸면 이 페이지의 다른 부품과 부딪힌다 — 9월 초에 한 번 겪은 일이다.

아래에 **다섯 대목 요약 띠**를 두었다. 본편 열 장의 뼈대다.

```
문제 → 해결 → 수익 구조(양면시장) → 성패 요인(신뢰 절차) → 확장
```

> **이 사례의 요지는 기술이 아니다.** 캔슬마켓은 호텔을 새로 짓지 않았고,
> **쓰이지 못하고 사라질 예약권을 시장화**했을 뿐이다. 그리고 그것을 굴린 것은
> OCR·AI 가격추천이 아니라 **등록 편의 · 상품 검수 · 안전거래 · 숙박 보장**이라는 절차다.

**숫자를 인용하는 법도 적었다.** 매출은 2022년 2.2억 → 2023년 4.8억 → **2024년 7.2억(정점)**
→ 2025년 5.8억이다. *계속 성장한 회사*로 말하면 틀린다. **「공개 기업정보 기준」**이라는
단서를 붙이고 *실제 매출은 있으나 변동이 있는 소규모 스타트업*으로 말하게 했다.

뒤에 사용자가 **「이거 태그 형식으로」**라 해서 본편 내려받기를 알약으로 바꿨다(`d0d91c3`).
기존 알약 스타일 `.tb-tags` 는 `.task-box` 안에서만 먹어서, 본문용 `.dltags` 를 새로 만들었다.

## 3. 참여기업 아홉 곳 — PT 가 텍스트였다 — `6fe57eb`

`스마트관광_참여기업_문제해결.pptx` 를 **하나의 섹션으로** 넣어 달라 했다.

슬라이드 이미지를 뽑아 보니 이랬다.

```
smart1.png  15,721 bytes
smart2.png   8,708 bytes
smart3.png  15,721 bytes   ← 전부 같은 크기
...
smart12.png 15,721 bytes
```

**같은 배경 하나가 열두 번 나온 것**이었다. 실제 내용은 **텍스트 도형**에 있었다.
그림으로 넣었으면 배경만 열두 장 올릴 뻔했다.

그래서 그림 대신 **읽는 섹션**으로 옮겼다. 다섯 분야를 색 띠로 가르고, 회사마다
**문제 두 줄 · 해결 두 줄 · 사이트**를 카드로 폈다.

| 분야 | 한 줄 | 회사 |
|---|---|---|
| 스마트 주차 | "차량이 몰린다" | 베스텔라랩 |
| 스마트 지도 | "길을 못 찾는다" | 다비오 · 딥파인 |
| 스마트 결제 | "줄이 길어진다" | 유디아이디 · 테이블매니저 |
| 스마트 안전 | "위험을 못 본다" | 아이디비 · 피치에이아이 |
| 자유 주제 | "누군가 소외된다" | 시정 · 애프터워크 |

**원자료의 유보 사항을 지우지 않았다** — 다비오·딥파인의 중복 등장,
㈜시정의 동명기업 확인 필요, ㈜애프터워크 웹사이트 미확인. 이런 것은 감추면
학생이 그대로 인용해 버린다.

마무리 문장은 이렇게 적었다.

> **아홉 곳 중 어느 하나도 「축제를 위한 신기술」을 새로 발명하지 않았다.**
> 이미 가진 기술을 축제라는 현장의 특정 불편에 붙였을 뿐이다.

```

      └ 구비서류 칸이 요구하는 것이
            ② 여행사 사업계획서 예시(HWP · 선라이즈젠 종합여행업)
            ③ 사무실 임대차계약서 예시(DOCX) ← 「부동산의 사용권을 증명하는 서류」
```

그 관계를 설명에 적었다. 그리고 **②를 과제 1의 공모용 사업계획서와 견주게** 했다.

> 공모용이 *「왜 이 문제를 나에게 맡겨야 하는가」*를 설득하는 글이라면,
> 이쪽은 *「이 사업이 굴러갈 수 있는가」*를 관청에 보이는 글이다.
> **묻는 사람이 다르면 같은 사업도 다르게 쓴다.**

저녁에 사용자가 **자본금 요건**을 정리해 주어 세 카드에 넣었다(`8b5166b`).

| 종류 | 자본금 |
|---|---|
| 종합여행업 | **5,000만원** 이상 |
| 국내외여행업 | **3,000만원** 이상 |
| 국내여행업 | **1,500만원** 이상 |

법인은 **납입자본금**, 개인사업자는 **그 사업에 제공되는 자산의 평가액** 기준이고,
국내여행업의 **750만원 한시 특례는 2026년 6월 30일로 끝났다.** 인터넷에 남은
「750만원이면 된다」는 글이 지난 기준이라는 것까지 적어 두었다 —
학생이 검색해서 그대로 옮겨 쓸 자리라서.

이 숫자들이 **① 신청 화면의 「자본금」 칸이 왜 필수 입력인지**에 대한 답이다.
