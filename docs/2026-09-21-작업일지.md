## 8. **ADsP 1과목 50문항 실전훈련 판** (`30866f0` · `497c078`)

### 먼저, 구조를 뜯어보고 제안을 냈다
사용자가 「10번 해설이 불충분해 보여 HTML 둘을 만들었는데, 어떻게 넣는 게 좋겠냐」고 물었다. 세 파일을 열어 본 뒤 **다섯 가지를 근거로** 답했다.

1. 워크북은 **탭 셸 + iframe 3개**를 **base64 문자열**로 주입하는 구조다(`pages={study,exam,review}`).
2. ③ 해설은 **데이터 구동식** — `Q[{n,q,opts,expl,key}]` + `ROUNDS` · `FULL` · `KW`. 그래서 **버튼을 손으로 박을 필요가 없다**(표에 한 줄 더하는 방식이 맞다).
3. **SQL은 10번만이 아니다** — **17번**이 「관계형 DB를 쿼리·수정하는 언어는?」 이다.
4. iframe 안이라 **상대경로 링크가 깨진다** — 절대주소 + 새 탭.
5. 장기적으로 **base64를 풀어야** Ctrl+F · 인쇄 · 딥링크가 산다.

### 그런데 새로 받은 판에 그게 이미 들어 있었다
`빅데이터분석_50문항_11-50_해설강화_통합본.html`(375KB)을 열어 보니 ③ 해설이 **48.6KB → 112KB** 로 커졌고, 새 표가 셋 붙어 있었다.

| 표 | 무엇 |
|---|---|
| `DEEP` | 11~50번의 **출제 규칙 · 함정** 두 줄 |
| `LESSON_BY_Q` | 문항 → 보충자료 매핑 |
| `LESSON_TITLE` · `LESSON_B64` | 보충자료 **9종**(db · dw · systems · bigdata · methods · risks · ds · basic · count) |

- **10번은 렌더 코드에 특례 분기**(`q.n===10`)가 있어 「COUNT 완전정복」(주) + 「SQL이 처음이라면」(보조) **두 개**가 뜬다. 제안한 순서 그대로다.

### 3·4번에 보충학습과 심화해설을 더했다 (`497c078`)
「정형 → 반정형 → 비정형 순서」 문항이 무엇인지 찾아보니 **4번**, 같은 자료를 쓰는 「유형이 다른 하나」가 **3번**이었다. **둘 다** 걸었다.

- **코드 한 줄도 고쳤다** — 심화해설이 `!!deep && q.n>=11` 로 잠겨 있어 3·4번에서 뜨지 않았다. `!!deep` 로 풀었다. **앞으로 1~9번에 더해도 바로 뜬다.**

> **작업 방법** — 파일이 base64라 `디코드 → 문자열 수술 → 재인코드 → 셸에 되쓰기` 로 했다. 표 세 개는 여는 중괄호 뒤에 항목을 끼워 넣는 식이라 JSON 왕복 없이 안전하다. 375KB → **413KB**.
> **남은 구멍** — 이제 1·2·5~9번에 `DEEP` 도 보충자료도 없다.
