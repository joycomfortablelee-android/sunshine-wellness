- 색을 새로 정하지 않고 **카드가 쓰는 색조 클래스를 사례 `li` 에 그대로 얹었다** — `t-rose`(텍스트 마이닝) · `t-violet`(군집). 그 클래스가 `--v-tc` / `--v-ac` 를 넘겨주므로 규칙은 두 줄이면 된다.

```css
.learn-article .reslist li.case-tone > a { color: var(--v-tc); }
.learn-article .reslist li.case-tone > a:hover { color: var(--v-ac); }
```

> **왜 이렇게 했나** — 색을 직접 적어 두면 나중에 카드 색을 바꿀 때 두 군데를 고쳐야 한다. 지금은 **카드를 바꾸면 사례 제목이 따라온다.**

## 8. **ADsP 1과목 50문항 실전훈련 판** (`30866f0` · `497c078`)

### 먼저, 구조를 뜯어보고 제안을 냈다
사용자가 「10번 해설이 불충분해 보여 HTML 둘을 만들었는데, 어떻게 넣는 게 좋겠냐」고 물었다. 세 파일을 열어 본 뒤 **다섯 가지를 근거로** 답했다.

1. 워크북은 **탭 셸 + iframe 3개**를 **base64 문자열**로 주입하는 구조다(`pages={study,exam,review}`).
2. ③ 해설은 **데이터 구동식** — `Q[{n,q,opts,expl,key}]` + `ROUNDS` · `FULL` · `KW`. 그래서 **버튼을 손으로 박을 필요가 없다**(표에 한 줄 더하는 방식이 맞다).
3. **SQL은 10번만이 아니다** — **17번**이 「관계형 DB를 쿼리·수정하는 언어는?」 이다.
4. iframe 안이라 **상대경로 링크가 깨진다** — 절대주소 + 새 탭.
5. 장기적으로 **base64를 풀어야** Ctrl+F · 인쇄 · 딥링크가 산다.

### 그런데 새로 받은 판에 그게 이미 들어 있었다
`빅데이터분석_50문항_11-50_해설강화_통합본.html`(375KB)을 열어 보니 ③ 해설이 **48.6KB → 112KB** 로 커졌고, 새 표가 셋 붙어 있었다.

| 표 | 무엇 |
|---|---|
| `DEEP` | 11~50번의 **출제 규칙 · 함정** 두 줄 |
| `LESSON_BY_Q` | 문항 → 보충자료 매핑 |
| `LESSON_TITLE` · `LESSON_B64` | 보충자료 **9종**(db · dw · systems · bigdata · methods · risks · ds · basic · count) |

- **10번은 렌더 코드에 특례 분기**(`q.n===10`)가 있어 「COUNT 완전정복」(주) + 「SQL이 처음이라면」(보조) **두 개**가 뜬다. 제안한 순서 그대로다.
- **17번은 `basic` 에 연결**돼 있다. 짚었던 대로다.
- 보충자료는 **모달 iframe + `data:text/html;base64`** 로 열린다.

### 3·4번에 보충학습과 심화해설을 더했다 (`497c078`)
「정형 → 반정형 → 비정형 순서」 문항이 무엇인지 찾아보니 **4번**, 같은 자료를 쓰는 「유형이 다른 하나」가 **3번**이었다. **둘 다** 걸었다.

> **한 곳은 되돌렸다** — 판다랭크 설명의 「06장 홍보」는 이 페이지가 아니라 **스마트 투어리즘 모듈**의 장이었다. 그대로 두면 이 페이지 파트 06(공모전)으로 잘못 읽히므로 **「스마트 투어리즘 06장 홍보」**로 명시했다. *일괄 치환에서 늘 확인해야 하는 종류의 예외다.*

### 파트 머리글을 색 띠로 (`554215c`)
사용자가 **관광벤처창업론 페이지의 양식**을 참고하라고 지목했다. 그 CSS를 그대로 옮겨, 왼쪽에 **색 사각형(「파트」 라벨 + 큰 숫자)**, 오른쪽에 **제목과 작은 부제**가 놓이는 띠로 바꿨다.

- **파트마다 색이 다르다** — 01 파랑 · 02 청록 · 03 초록 · 04 다홍 · 05 보라 · 06 금색 · 07 겨자 · 08 남색 · 09 벽돌. 파트의 성격 색(04 텍스트마이닝 다홍, 09 호텔 벽돌)에 맞춰 골랐다.
- 「관련 링크 · 더 배우기」는 번호 대신 **`＋`에 회색** — 본 파트가 아니라 부록이라는 표시.
- **리드 문단 여섯 개를 부제로 접었다.** 「데이터는 저절로 답을 주지 않습니다…」 같은 한 줄짜리 문단을 머리글 안으로 넣고 원래 문단은 지웠다 — 제목과 설명이 한 덩어리로 읽히고 문단이 하나씩 줄어든다.
