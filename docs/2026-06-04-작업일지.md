## 1. DeepSeek AI 채팅봇 (Vercel Serverless + DeepSeek API)

### 배경·요구사항
- 사용자 요청: "딥시크 모델을 사용할 수 있도록 업데이트 하자" / "AI 채팅봇 위젯"
- 목적: 방문객이 사이트에서 직접 AI 상담사와 여행 프로그램·요금·일정 등을 대화 형태로 문의

### 아키텍처
```
브라우저(UI) → /api/chat (Vercel Serverless) → https://api.deepseek.com/v1/chat/completions
```
- **프론트엔드**: 우측 하단 💬 플로팅 버튼 → 채팅창 토글 → 메시지 전송
- **백엔드**: `api/chat.js` (Vercel Serverless, 의존성 0)
  - DeepSeek API 프록시 — 클라이언트에 API 키 노출 방지
  - 환경변수 `DEEPSEEK_API_KEY` 필요
  - 모델: `deepseek-chat`
  - `max_tokens: 1024`, `temperature: 0.7`

### 시스템 프롬프트
- 선샤인 웰니스 여행 상담사 역할
- 9개 프로그램(근교투어·감천문화마을·사찰·예술·시장미식·다크투어리즘·을숙도생태·축제·야경야식) 지식 포함
- 사용자가 쓴 언어(KO/EN/ZH)로 응답
- 300단어 이내 간결한 답변, 맞춤 문의 유도

### 제작물
| 파일 | 내용 |
|---|---|
| `api/chat.js` | DeepSeek API 프록시 서버리스 함수 (CORS 허용, POST만) |
| `index.html` | 챗봇 토글 버튼(`#chatbotToggle`) + 채팅창(`#chatbotWindow`) 마크업 |
| `style.css` | 챗봇 스타일(플로팅 버튼·채팅창·메시지 버블·입력창) — 모바일 반응형 포함 |
| `script.js` | `toggleChatbot()`, `sendChat()`, `appendChat()` — 대화 이력 유지, typing 표시 |

### 대화 이력 관리
- `_chatHistory` 배열에 사용자+어시스턴트 메시지 누적
- 매 요청 시 전체 이력 전송으로 문맥 유지
- 시스템 프롬프트는 서버에서 자동 prepend

### UI/UX
- 우측 하단 💬 "AI 상담" 플로팅 버튼 (배경색 `--accent`)
- 클릭 시 채팅창 슬라이드 인 애니메이션
- 초기 봇 인사말 자동 표시
- 입력창 + 전송 버튼, Enter 키 전송 지원
- 응답 대기 중 "답변을 작성 중입니다..." typing 표시
- 모바일: 화면 전체 너비 사용, 높이 60vh

## 3. 교육자료 허브 카드 — 아이콘+모듈 한 줄 정렬

### 요구사항
- 사용자: "각 카드 안에서 아이콘 사이즈를 줄이고, 그 옆에 모듈을 적어달라"
- 기존: 카드 안에서 아이콘(세로) → Module 0X → 제목 순으로 3줄
- 변경: 아이콘과 `Module 0X` 라벨을 같은 줄에 가로 정렬

### 제작물
| 파일 | 내용 |
|---|---|
| `learn/index.html` | 6개 카드 모두 `.ico`+`.mod`를 `<div class="ico-row">` 한 묶음으로 감쌈 |
| `learn/learn.css` | `.ico` 30px→20px 축소, `.ico-row { display:flex; align-items:center; gap:8px }` 추가 |

### 세부
- 아이콘 폰트 `30px → 20px`, `line-height:1`
- `.ico-row` 가로 정렬(flex), 아이콘·라벨 간격 8px, 아래 여백 12px
- 그리드(2열 배치)는 그대로 유지
- CSS 캐시 버전 `learn.css?v=7 → v=8`
