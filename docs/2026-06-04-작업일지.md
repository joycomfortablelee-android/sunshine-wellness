## 1. FAQ 챗봇 (Vercel Serverless, 키워드 매칭, API 키 불필요)

### 배경·요구사항
- 목적: 방문객이 사이트에서 직접 여행 프로그램·요금·예약·위치 등을 대화 형태로 문의
- **비용 $0** 전제 — LLM API 미사용, 키워드 매칭으로 사전 정의 답변 반환 (서버리스 실행시간만 소모)

### 아키텍처
```
브라우저(UI) → https://sunshine-wellness.vercel.app/api/chat (Vercel Serverless) → 키워드 매칭 응답
```
- **프론트엔드**: 우측 하단 💬 플로팅 버튼 → 채팅창 토글 → 메시지 전송
  - ⚠️ 호출은 **절대 URL**(`https://sunshine-wellness.vercel.app/api/chat`). 고객 도메인은 GitHub Pages라 `/api`가 없으므로 게시판과 동일하게 vercel.app 절대 URL로 호출.
- **백엔드**: `api/chat.js` (Vercel Serverless, 의존성 0, CommonJS)
  - `FAQ_DB`: ko/en/zh 언어별 `{keywords, answer}` 배열
  - `findAnswer()`: 입력에 포함된 키워드 길이 합으로 best 매칭, 미매칭 시 연락처 안내 fallback
  - `detectLang()`: **한글(가-힣) 우선 → 한자 → 라틴 3자+ → 기본 ko**. (한글에 영문약어 BIFF/KTX 섞여도 한국어로 판정)
  - CORS `*` 허용, POST만(그 외 405), 빈 메시지 400

- 프로그램/투어, 가격/요금, 예약/문의, 운영시간, 위치/주소, 사찰, 감천문화마을, 시장·떡볶이 미식, 야경·야식, 축제(BIFF), 할인쿠폰, 입금/계좌, 카카오채널, 인사
