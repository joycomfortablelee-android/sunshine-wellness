## 3. **평가방식 2안에 웹판** (`df5c67f`)

인터랙티브 강의계획서는 **논문 리딩형(138편 · 30회차)** 이라 2안이 정확히 그 내용이다.
문서 알약 옆에 흰 알약으로 붙였다.

```css
/* 막힌 곳 — .pcol a.mapl 에 margin-top:auto 가 걸려 있어
   알약을 하나 더하면 나란히 서지 않고 위아래로 쌓인다. */
.syl-box .pcol .pc-tags { display: flex; flex-wrap: wrap; gap: 6px; margin-top: auto; }
.syl-box .pcol .pc-tags a.mapl { margin-top: 0; }
```

줄을 하나 만들어 `margin-top:auto` 를 **알약에서 줄로 옮겼다.**
표지 소속은 열어 확인했다 — **국립경국대학교 관광경영학과**(9/13 에 고친 그 파일이 아니다).
