## 9. **파트 머리글을 큰 번호 블록으로** (`c94cd63` · `8e8c8b1`)

사용자가 **「파트 바를 눈에 띄게 하려면 너의 제안은?」**이라 물었다. 세 안을 그려 보였다 —
**꽉 찬 색 바**(가장 강하지만 여덟 번이면 무겁다) · **큰 번호 블록** · **옅은 유령 숫자 + 윗선**(가장 차분).
**큰 번호 블록**을 골랐고, 적용은 **관광벤처창업론만 먼저**로 정했다.

```
┌──────┬──────────────────────────────────────────┐
│ 파트 │  낼 것을 먼저 본다                        │
│  01  │  이 수업의 산출물은 리포트가 아니라…      │
└──────┴──────────────────────────────────────────┘
  56px 진한 색           연한 바탕 + 연한 테두리
```

| | 전 | 후 |
|---|---|---|
| 번호 | 알약 안 11px 「파트 01」 | 색 사각형 안 **26px 숫자**, 위에 9px 「파트」 |
| 테두리 | 왼쪽 6px 선만 | 사방 1px **연한 파트색**(`--pp-ln` 신설) + 모서리 10px |
| 제목 · 머리말 | 가로로 폭을 나눠 가짐 | 오른쪽 칸에 **위아래로** |

**머리말이 눌리지 않게 된 것이 실익이다.** 전에는 제목과 머리말이 한 줄에서 폭을 나눠,
파트 04처럼 머리말이 긴 곳은 글자가 좁게 접혔다.

`grid-template-columns: 56px 1fr` 만 주고 **각 항목이 어느 칸 어느 줄인지는 적지 않았다.**
CSS 격자는 남는 자리에 알아서 채우므로, 항목 수가 칸 수의 배수가 아니면 이렇게 샌다.

```css
.pt     { grid-column: 1; grid-row: 1 / span 2; }  /* 사각형이 두 줄을 다 차지 */
.pt-ti  { grid-column: 2; grid-row: 1; }
.pt-sub { grid-column: 2; grid-row: 2; }
```

좁은 화면(620px)에서는 한 칸이므로 셋을 1 · 2 · 3행으로 되돌렸다.

> **교훈 — 격자에 항목을 넣을 때는 칸 수와 항목 수를 먼저 센다.**
> 맞지 않으면 `grid-column` · `grid-row` 를 항목마다 못박는다.
> 태그 균형 검사도, 링크 검사도 이건 못 잡는다. **화면을 봐야 보이는 종류다.**
