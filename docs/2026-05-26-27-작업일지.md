### 1. 서브페이지 오버레이 아키텍처 전환

#### 문제
- 기존: 서브페이지(프로그램 소개, 웰니스 소개, 문의하기 등)가 `window.open(blob URL)` 방식으로 새 탭에서 열림
- 홈 헤더가 새 탭에서는 표시되지 않아 UX 불일치

#### 해결
- `showSubPageFull(html)` 공통 함수로 전체 화면 오버레이(`#subPageOverlay`) 주입
- `makeSubPageHeader()` 공통 헤더 함수 분리 (로고 + 홈 버튼 + 언어 버튼 일관성)
- 로고 클릭 시 오버레이 닫고 홈으로 복귀
- 홈 버튼: `javascript:void(0)` 방식으로 모든 서브페이지에서 안정적 동작
- 커밋: `eefb147`, `8dedff8`, `7bae765`, `bef8f35`

### 6. FAQ 테이블 구조 전환 (다수 이터레이션)

#### 기존 → 변경
- flexbox div 구조 → `<table class="sp-table">` 구조 전환
- 게시판(`sp-table`)과 동일한 열 정렬 구현

#### 최종 구조

| NO. | 제목 | 날짜 | 열기 |
|---|---|---|---|
| 01 | 질문 텍스트 | 04-01 | [클릭] |

- 4열 구성: NO.(60px) / 제목(flex) / 날짜(90px) / 열기(60px)
- "클릭" 배지 → 토글 시 "닫기"로 전환 (배경 #1a2e2a 다크그린)
- 답변 행: `colspan=4`, 왼쪽 여백은 NO. 열 너비와 동기화
- 게시판 스타일 툴바 추가: "총 6건 | 문의하기" 버튼
- 질문 텍스트 굵기(bold) 및 색상(black) 적용
- 커밋: `fc496d0`, `57f660d`, `69cc95a`, `a78bb50`, `36eb7cc`, `32c53cd`, `118544e`, `b1750df`

### 8. 이미지 BASE URL 버그 수정

#### 문제
