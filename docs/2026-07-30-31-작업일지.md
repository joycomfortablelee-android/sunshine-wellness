## 3. 저장소 정리 — 작업용 원본 소재 gitignore (`e1413bc`, 7/31)

오래 남아 있던 미추적 파일 4건을 **커밋하지 않고 `.gitignore` 처리**하기로 결정.

| 항목 | 내용 | 크기 |
|---|---|---|
| `reference/` | 원본 사진·docx·md 초안(템플·광안대교·자갈치 등) | 약 70MB |
| `logo/` | 로고 원본 + 템플 대형 PNG 2장 | 약 28MB |
| `_shot_modal.png` | 스크린샷 | 305KB |
| `_shot.mjs` | 스크린샷 촬영용 임시 스크립트 | 3.5KB |

판단 근거:
- 합계 **약 100MB** → GitHub Pages 저장소 clone이 무거워지고, 한 번 커밋하면 히스토리에서 제거가 번거로움.
- `*.html/css/js` 전체를 grep한 결과 **`logo/`·`reference/`를 참조하는 코드 0건** → 배포에 영향 없음. 최적화 사본은 이미 `images/`에 커밋되어 있음.
- `git check-ignore -v` 로 4건 모두 실제 무시되는 것 확인. 이후 `git status` 클린.

> ⚠️ 이 방식은 **원본이 로컬 PC에만 남는다**는 뜻 → 저장소가 백업 역할을 하지 않음. 약 100MB 원본은 외장/클라우드 드라이브에 별도 사본 권장.
> 📌 7/23 일지에 적힌 "스크린샷 헬퍼 `_shot.mjs`"는 이제 **추적 대상이 아님**(로컬 전용).
