## 2. 서브페이지 오버레이 열린 상태에서 언어 전환 즉시 반영

- **문제**: 서브페이지는 열릴 때의 언어로 한 번만 그려져, 오버레이가 떠 있는 동안 언어 버튼을 눌러도 안 바뀜
- **해결**: 전역 `_activeSubPageRender` 도입
  - 각 `open***Page()` 함수가 자기 자신(인자 있으면 클로저)을 등록
  - `setLang()`에서 오버레이가 열려 있으면 그 함수를 현재 언어로 재호출
  - `closeSubPage()`에서 초기화
- 적용 11개 서브페이지 전체
- **부작용(의도된 트레이드오프)**: 재렌더이므로 언어 전환 시 페이지가 초기 상태로 그려짐(게시판 페이지·검색·폼 입력 초기화). 글 상세는 같은 글 유지

## 6. Where to Next? 게시판 — 실제 저장(영구화) + 관리자 삭제 (별도 터미널 작업)

### 배경
- 기존 게시판 글쓰기(`boardSubmit`)는 **메모리(JS 배열)에만** 추가 → 새로고침 시 소멸, 타 기기 공유 불가
- 사용자 요청: "글 쓰면 진짜 올라가나?" → **간단형(로그인 없음) 영구 저장** 으로 구현

### 핵심 제약 발견 — 호스팅 실체
- 사용자 도메인 `sunshinewellness.co.kr`은 **GitHub Pages**(정적, `/api` 서버함수 실행 불가)
- 같은 repo가 **Vercel**(`sunshine-wellness.vercel.app`)에도 배포됨 → 여기선 `/api` 함수 실행됨
- **해결책**: 도메인·DNS는 그대로 두고, GitHub Pages 사이트가 **Vercel 함수를 cross-origin 호출**

### 백엔드 — `api/posts.js` (Vercel Serverless, 의존성 0)
- 저장소: **Upstash Redis** (Vercel Marketplace, DB `upstash-kv-alizarin-coin`, Free)
  - env `KV_REST_API_URL` / `KV_REST_API_TOKEN` (native `fetch`로 REST 호출, 패키지 설치 없음)
  - 환경변수 이름 자동 감지(Custom Prefix 대응), 읽기전용 토큰 제외
- `GET` 목록조회(`LRANGE`) / `POST` 등록(`LPUSH`+`LTRIM 1000`) / `OPTIONS` preflight
- **보안**: 사용자 입력 HTML 이스케이프(XSS 방지), 줄바꿈→`<p>`/`<br>`, 길이 제한
- **CORS**: `Access-Control-Allow-Origin: *` (GitHub Pages 도메인에서 호출 위함)
- Redis 리스트 키 `board:posts`

### 프론트 — `script.js`
- `const BOARD_API = 'https://sunshine-wellness.vercel.app/api/posts'` (절대 URL 직접 호출)
- `_boardLoadUserPosts()`(GET)·`boardSubmit()`(POST async)
- 기존 8개 샘플글은 JS 하드코딩 유지, 사용자 글만 Redis 적재 후 위에 merge
- 저장소 미연결 시 graceful fallback(사이트 안 깨짐)

### 관리자 삭제 (비밀번호 보호)
- `api/posts.js` `DELETE` 핸들러: **`BOARD_ADMIN_KEY` 환경변수**로 검증(미설정 시 403, 불일치 401)
  - `?id=` 단건 / `?all=1` 전체. 헤더 `x-admin-key`. CORS에 DELETE + `x-admin-key` 허용
  - 리스트 읽어 해당 id 제외 후 재구성(순서 유지)
- 프론트: 툴바 **🔧 버튼 → 비번 prompt → localStorage**, 사용자 글 행에 **[삭제]** 버튼
  - 샘플글(1~8)은 삭제 대상 제외
- ⚠️ 운영자가 Vercel에 `BOARD_ADMIN_KEY` 등록 + 재배포 필요 (완료됨)

### 검증 (live)
- POST→저장→GET 영구성 확인 / CORS·OPTIONS 204 / GitHub Pages script.js 반영 / DELETE 401(키 보호 작동)

### ⚠️ 운영 주의 — Vercel 빌드 트리거
- Vercel "Ignored Build Step"이 **커밋 메시지에 "배포" 포함 시에만** 자동 빌드.
  게시판 커밋들은 "배포" 미포함 → 동일 메시지의 타 커밋/수동 Redeploy로 반영됨.
  **게시판만 단독 배포하려면 커밋 메시지에 "배포" 포함하거나 대시보드에서 Redeploy 할 것.**
