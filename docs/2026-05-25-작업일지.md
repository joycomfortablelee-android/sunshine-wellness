### 히어로 캐러셀 UX 개선

#### 슬라이드 전환 방식 변경 (슬라이드 → 크로스페이드)
- 기존: 전체 화면이 옆으로 밀리는 방식 (`translateX`) → 어지러움 유발
- 변경: 제자리 페이드인/아웃 (`opacity` 크로스페이드)
- CSS: `.slides-wrapper` → `position: relative`, `.slide` → `position: absolute; opacity: 0; transition: opacity 1.2s ease`
- JS: `wrapper.style.transform` 제거, `active` 클래스로 opacity 제어

#### Ken Burns 줌 강도 조정
- `scale(1.2 → 1.0)` → `scale(1.05 → 1.0)` (20% → 5% 축소)
- 전환 시 어지러움 감소

#### 슬라이드 전환 속도 조정
- `0.85s cubic-bezier(0.77, 0, 0.175, 1)` → `1.1s cubic-bezier(0.25, 0.46, 0.45, 0.94)` (부드러운 easing)

#### z-index 버그 수정
- 슬라이드 01이 보이지 않는 문제: DOM 순서상 마지막 슬라이드가 위에 쌓여 1번 가림
- `.slide.active { z-index: 1; }` 추가로 해결

#### 초기 로딩 검은 화면 제거
- 원인: 모든 슬라이드 `opacity: 0` 상태에서 JS가 `active` 추가 → 1.2초 페이드인 동안 배경 노출
- 해결: 첫 슬라이드에 `transition: none` 적용 후 즉시 표시, `requestAnimationFrame`으로 transition 복원
