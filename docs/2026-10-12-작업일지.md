## 2. **빅데이터 파트 03 — 육각형 → 칠각형, 0.5번 「데이터 출처 보기」 추가**

- 교수님: 수업에서 「우리가 쓴 데이터가 무엇이고 어디 있나」를 공부했고, 수상작(Reference)을 보면 데이터 출처도 알 수 있다 — 0과 1 사이에 0.5를 두고 칠각형으로.
- `learn/big-data-analytics.html` 파트 03: Reference(0) → **0.5 데이터 출처 보기**(하늘색 `t-sky`) → 1 문제 정의 → … → 5 시각화 → 0. 0.5 카드: 수상작 발표 자료의 「데이터 출처」 장 · 볼 것(어떤 데이터를 몇 개 겹쳤나 — 출처 이름을 적어 온다, 수집 카드에서 옮김) · 우리가 써 본 것(KOSIS · 네이버 데이터랩 → `#kosis-card` · `#naver-datalab`). 수집 카드 설명에 「0.5에서 적어 온 출처 이름을 아래에서 찾는다」.
- 번호: 0.5만 `hx-half`로 직접 적고 자동 번호는 건너뜀(뒤는 1–5 그대로). 그림 viewBox 1000×800 → 1000×940, 꼭짓점 7 · 화살표 7 다시 계산, 카드 글자 크기는 그대로. 1300 · 960px 캡처로 카드 겹침 없음 확인, 900px 아래는 기존대로 한 줄 쌓기. 파트 제목 「다섯 걸음」 · 링크 `#hx-ref` 그대로.
- 카드 이름은 후보 셋 중 추천안 「데이터 출처 보기」로 진행(교수님이 따로 고르지 않음 — 바꿀 수 있음). 다른 창 미커밋 작업(데이터마이닝 그림)은 섞지 않고 index로 커밋.
