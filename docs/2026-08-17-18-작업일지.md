## 1. 한국어 TTS — 다른 챗봇은 "못 한다"고 했다

사용자가 다른 챗봇의 답을 가져왔다. *"이 대화 환경에는 한국어 TTS를 합성해 MP3로 내보내는 도구가 연결돼 있지 않습니다. 클로바 더빙에서 만든 뒤 올려 주십시오."*

웹 채팅 기준으로는 맞는 말이다. 하지만 **여기는 셸이 있다.**

`edge-tts`(rany2/edge-tts, MIT)를 설치했다. Microsoft Edge의 신경망 TTS를 그대로 호출하고 **API 키도 글자수 제한도 없다.** 한국어 음성 셋을 확인해 샘플을 만들어 들려드렸고, 사용자가 `ko-KR-SunHiNeural`(여성)을 골랐다.

### 1-1. 인용된 답에서 틀린 것 하나를 짚었다

그 답에는 *"SSML로 쉼(break)이나 속도·피치까지 세밀하게 조절됩니다"*라고 적혀 있었다. **틀렸다.** 설치한 7.2.8의 CLI 옵션은 `--rate` `--volume` `--pitch`가 전부고 SSML 입력 경로가 없다. Microsoft가 이 엔드포인트에서 커스텀 SSML을 막았기 때문이다.

> **이게 대본 작업 방식을 바꾼다.** 쉼을 `<break time="500ms"/>`로 넣을 수 없으니 **호흡은 문장부호와 문장 분할로만** 설계해야 한다.

### 1-2. 인용에 없던 기능이 이번 작업의 핵심이었다

`--write-subtitles`가 **문장 단위 타임코드(SRT)를 함께 뱉는다.**

```
1  00:00:00,100 --> 00:00:05,194   유럽 녹색 수도는 2010년 스톡홀름에서…
2  00:00:05,144 --> 00:00:09,236   지금까지 열네 곳의 도시가 선정되었습니다.
```

**음성 길이를 재서 페이지 전환을 맞출 필요가 없다.** 합성과 동시에 각 페이지의 시작·종료가 확정된다.

| | |
|---|---|
| 총 길이 | **6분 52초** (412.4초) |

### 2-1. 첫 빌드에서 영상이 7.7초 더 길었다

`ffmpeg` concat demuxer는 **목록 마지막 이미지를 여분으로 한 번 더 내보낸다.** `-shortest`로는 잡히지 않았다. 오디오 총 길이로 `-t`를 명시해 잘랐다.

```python

# -shortest 로는 끝이 맞지 않는다. 오디오 총 길이로 자른다.
"-t", "%.3f" % total
```

### 2-2. 프레임을 뽑아 눈으로 확인했다

길이가 맞는 것과 **내용이 맞는 것은 다르다.** 세 지점의 프레임을 뽑아 그 시점 나레이션과 화면을 대조했다.

## 10. 색 체계를 세웠다

절 제목을 무게 순으로 갈랐다.

| 절 | 형태 |
|---|---|
| **이론 01~06** | 진한 초록 띠 · 흰 글자 · 흰 원 숫자 |
| **곁들여 보기 1** Ⓛ 로컬크리에이터 | 진한 보라 · 흰 글자 |
| **곁들여 보기 2** Ⓡ 재생 | 연한 브라운 · 흰 글자 |
| **공모 · 사례 · 링크** | 색 띠 + 유형 라벨(`공모` `사례 1` `링크`) |

이론 장 안의 카드는 **장마다 색이 다르고, 각 장 안에서는 읽는 순서대로 진해지는** 규칙으로 갔다.

| 장 | 색 |
|---|---|
| 01 유형 | 연두 3단계 |
| 02 세 질문 | **주황 3단계 · 진한 바탕 + 흰 글자** |
| 03 비즈니스 모델 | 청록 3단계 |

02는 네 번 고쳤다. 보라 → 살구 주황 → 에르메스 오렌지 → **진한 주황 바탕 + 흰 글자**. 제목 색도 흰색 → 짙은 남색(보색) → **진한 번트오렌지**로 옮겼다. 사용자가 *"보색 싫어, 주황 계통에서 진한 주황 없어?"*라고 해서 같은 계열 안에서 가장 깊은 톤을 찾았다.

> **카드 상단 3px 띠가 반투명 흰색이라 아래 주황이 비쳐 어중간한 연주황으로 보였다.** 사용자가 그것을 짚었고, 제목과 같은 번트오렌지로 바꿔 위아래를 묶었다.

## 12. 사고 두 건

### 12-1. `--amend`로 이미 푸시한 커밋을 덮어썼다

커밋 메시지를 파일로 넘기려다 `git commit -F ... -m ""` 뒤에 `--amend`를 붙였고, **원격에 이미 올라간 `e0592b7`을 덮어썼다.** 푸시가 `non-fast-forward`로 거부되면서 드러났다.

`git reset --soft origin/master`로 원격 기준으로 되돌린 뒤 새 커밋을 쌓아 해결했다. **작업 트리는 그대로였고 원격 히스토리도 덮어쓰지 않았다.**

### 12-2. 절을 잘라내며 푸터를 통째로 날렸다

초광역 절을 카드로 옮기는 스크립트에서 절의 끝을 *"다음 `learn-part`, 없으면 파일 끝"*으로 잡았다. **그 절이 페이지 마지막이었다.** 목차 링크·모듈 네비·저작권·닫는 태그가 함께 잘려 나갔다.

`div` 태그 균형 검사(18 여는데 17 닫힘)에서 잡혔다. 직전 커밋에서 푸터 18줄을 그대로 복원했다.

> **큰 블록을 스크립트로 옮길 때는 "그 블록이 파일의 마지막인가"를 먼저 확인해야 한다.** 이번엔 태그 균형 검사를 매번 돌리고 있어서 커밋 전에 잡혔다.

## 13. 그 밖에

- **커밋 메시지의 큰따옴표** — PowerShell here-string 안의 `"`가 인자를 쪼개 `git`이 단어를 파일 경로로 받았다. 두 번 겪은 뒤로는 메시지를 파일로 넘겼다.
- **`id` 앵커 때문에 치환이 빗나갔다** — 로컬크리에이터 절 제목만 `id="local-creator"`가 붙어 있어 일괄 치환에서 제외됐다. 사용자가 "여기도"라고 짚어 줬다.
- **경북센터 카드가 엉뚱한 칸에** — 스크립트가 `two-col`을 앞에서부터 찾다가 초광역 절을 잡았다. 바로잡았다.
