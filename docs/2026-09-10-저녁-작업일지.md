**최종 형태.** 넷 다 번호가 아니라 **성격**으로 불린다.

```
실습          →   대비              →   실습            →   기말발표
국내 도시        인성면접 · 지원서       유럽 벤치마킹        응모신청서 ·
벤치마킹         취업 서류를 미리        발표                업무 수행계획서
                써 둔다                9~15주차            모의 PT · 졸업 뒤까지
```

> **왜 번호를 버렸나.** 번호는 **순서**를 약속한다. 그런데 이 넷은 순서가 아니라 **성격이 다른 넷**이다 —
> 둘은 수업 중 실습이고, 하나는 취업 대비이고, 하나는 기말발표다. 「과제 2」라고 쓰면 학생은
> **1이 끝나야 2를 하는 줄 안다.** 날짜를 버린 것과 같은 이유로 번호도 버렸다.

**작은 교훈 하나.** 18:38의 문제는 **번호가 세 번 반복된 것**이었다. 같은 단계에서 갈라져 나온 셋인데
각자 번호를 달고 있으니 **셋이 서로 다른 단계처럼** 보였다. 한 칸에 모아 세 줄로 넣자 해결됐다 —
`li.multi` 안에 `f3-rows`를 두고 줄 사이를 점선으로 갈랐다.

## 5. 도형 문법에 **다섯이 들어왔다** — 오각형 순환

낮에 셋(삼각형)과 넷(사분면)이 정해졌다. 저녁에 **06장 다섯 걸음**을 만나 **다섯**이 추가됐다.

```
         ① 문제 정의
    ⑤              ②
       ↻ 시계 방향 ↻
      ④          ③
```

정오각형 꼭짓점(**-90°에서 72°씩**)에 지름 196px 원을 놓고, 가운데 점선 원과 화살표 다섯으로 **시계 방향 순환**을 표시한다.
상자를 `aspect-ratio: 1 / 1`로 잠갔다 — **정사각형이 아니면 오각형이 찌그러진다.**

> **왜 오각형인가.** 04장 린 스타트업을 삼각형으로 그린 것과 같은 이유다. 이 다섯은
> **1에서 5로 끝나는 줄**이 아니라 **5에서 다시 1로 돌아오는 고리**다. 가로로 늘어놓으면 거짓말이 된다.

그래서 규칙이 이렇게 자랐다:

```
셋 → 삼각형    넷 → 사분면    다섯 → 오각형 순환
(세 방향)      (두 축)        (도는 고리)
```

같은 커밋에서 **05장 사분면 둘에 왼쪽 바 머리줄**을 붙였다. 사분면이 두 개가 되자 어느 행이 무엇인지 흐려져서,
행 이름을 왼쪽 바로 뽑아냈다 — 「지원 · 돈과 사람은 어디서 오는가 — 창구 넷」, 「배우기 · 어디서 배우고 누구에게 묻는가 — 자리 셋」.

### 08장 외식 — 「관광의 곁다리가 아니다」

> 외식은 관광의 곁다리가 아닙니다. **여행 지출에서 먹는 데 쓰는 몫이 크고**, 요즘은 *먹으러 가는 여행*이 따로 있습니다.

순서는 **콘셉트 개발 → 메뉴경영 → 위생·안전 → 접객 매뉴얼 → (넓힐 때) 프랜차이즈**.
승부처는 **맨 앞 콘셉트**이고, 마지막 프랜차이즈는 **넓히지 않기로 하는 것도 전략**이라 적었다 —
그 문장을 받는 사례가 **성심당**이다. 가맹점 없이 대전 직영만 고집해 「여기서만」이라는 희소성을 만든 곳.
**03장 가치 제안**과 **06장 차별화**가 실제 사업에서 어떤 **선택**으로 나타나는지 보라고 이어 붙였다.

### 11장 연구용역 — **배운 전공 자체를 파는 창업**

부산 **어반리즘 하우스**(URBAN + TOURISM + HAUS). 관광학 박사가 세운 관광 컨설팅·연구 회사로,
연구컨설팅 · 교육행사 · 행사운영 세 갈래를 한다. 울산문화관광재단 발주 「2026 울산 무장애 관광 인력양성 교육」 같은
**지자체·관광재단 용역이 곧 매출**이다.

> **03장 고객·채널을 다시 보면 성격이 분명해진다** — 고객이 일반 여행자(B2C)가 아니라 **공공기관(B2G)**이다.

학생에게 주는 함의를 마지막에 붙였다 — **관광계획을 세우고 데이터를 읽고 보고서를 쓰는 능력 자체가 사업이 될 수 있다.**
