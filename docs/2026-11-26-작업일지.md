- **교보문고 상세페이지는 WebFetch로 두 번 다 빈 응답**(CloudFront가 데스크톱 UA에는 `Content-Length: 0`을 돌려줌) — Bash `curl`에 **모바일 Safari User-Agent**를 줘서야 실제 HTML을 받아 책 정보·표지 이미지를 추출함. **교보문고 링크는 WebFetch가 막히면 모바일 UA curl로 우회 가능**
- "mice경영에 북파트를 신설하고" 요청으로 `hotel-mice-management.html`에 새 "📌 참고교재" 섹션을 만들고 『전시컨벤션산업론』(정숙화 · 창조와지식 · 2024, YES24)을 추가 — 같은 책이 그 아래 "교재별 차별적 강점" 비교 위젯(`mx-book`)에도 이미 있어 중복 가능성을 사용자에게 알림
- 이어서 "이거 실제책처럼 그리드 형태로 해줘. 하지만 웹검색에서 노출은 안되도록 해줘" 요청 — HRM 참고교재 전체(주교재 2 + 참고교재 7, 총 9권)를 **실제 표지 그림**으로 보여주는 새 페이지 `hrm-reference-books.html`을 만듦
  - YES24 표지 이미지는 `https://image.yes24.com/goods/<상품번호>/XL` 패턴이 확인되어, 책마다 WebFetch 없이 URL만 조합해서 바로 씀
  - 교보문고 표지는 위에서 모바일 UA curl로 받은 HTML의 `og:image`에서 추출(`contents.kyobobook.co.kr/sih/fit-in/...`)
  - 조직론[제3판](임창희 외)·조직행동론(김경수·김공수) 두 권은 정확한 YES24 상품 링크를 못 찾아(검색 결과가 모호함) **그리드에서 제외** — 틀린 책을 연결하는 것보다 안전하게 뺌
  - **검색 비노출은 페이지 전체가 아니라 이 새 그리드 페이지에만 적용**: `hotel-tourism-hrm.html` 본문(HRM 핵심기능 등 다른 내용)은 계속 검색에 노출되게 두고, 서점 표지 이미지가 들어간 그리드 페이지만 기존 "교재 저작권" 패턴([[private-page-noindex-pattern]])대로 `noindex` 메타 + `robots.txt` Disallow 처리 — 허브 페이지를 통째로 막지 않고도 요청(그리드 + 비노출)을 둘 다 만족시키는 쪽으로 판단
  - `hotel-tourism-hrm.html`의 기존 텍스트 목록은 그대로 두고, 그 위에 그리드 페이지로 가는 링크 한 줄만 추가(다른 곳에서 이 목록 항목들을 가리키는 기존 링크가 깨지지 않도록)
