## 1. **영상은 언제나 정중앙** (`326c28d`)

어젯밤 다른 세션이 정주영 경진대회 영상을 **520px 로 줄였는데**(`27ff94e`), 줄(`.ir-row`)이 왼쪽 정렬이라 영상이 한쪽으로 쏠렸다.
사용자: **「영상 정 중앙 위치야. 항상 영상은 정중앙 위치야」**.

- `.ir-row` 전체에 `justify-content:center`, 가로 영상 캡션도 가운데 정렬.
- 다른 영상을 모두 훑었다 — 성심당 · 예비창업패키지 1편(`max-width:720px; margin:0 auto`), 서울시 빅데이터(`margin:0 auto`), 스마트투어리즘 · 비건부산 데모(폭 100%) — **이미 가운데**였다.
- 메모리 `feedback.md` 에 규칙으로 남겼다.

> **교훈 — 영상의 폭을 줄이는 일과 가운데 정렬은 한 세트다.** 줄이기만 하면 한쪽으로 붙는다.

## 2. **타겟팅 판 첫 화면에 영상 설명 구조** (`c6e911f`)

사용자가 룰루레몬 영상의 타겟팅 설명을 정리한 글을 주며 **「첫번째 화면에 넣어줘 · 표를 살려줘」**.
`startup-marketing-targeting-slides.html` 1장 기존 소개(정의 · 핵심 한 줄) 아래 점선으로 나누고 이어 붙였다.

- **표** — 단계 / 영상에서 설명하는 내용 / 쉽게 바꾸면, 일곱 줄(① 시장 세분화 ~ ⑦ 포지셔닝으로 연결). 좁은 화면에서는 표만 가로 스크롤(`min-width:620px`).
- 한 줄 논리(시장 전체 → S → T → 제품·마케팅 → P), 「이 시장이 우리 회사의 규모와 역량에 맞는가?」, **시장 매력도 × 구매 가능성 × 기업의 실행 가능성**, 넓은 고객 ↔ 구체적 고객(서울 · 20~30대 일본인 여성 · K-뷰티와 카페 · 개별여행) 두 칸.
- 한 화면(100vh)을 넘어 **이 장만 `overflow-y:auto`**, 쪽 번호(`.footer`)는 절대 위치를 풀어 끝에 둔다 — 그대로 두면 스크롤 중간에 글 위로 떠 있다.

## 3. **여행업 창업전략 판에 AI 프롬프트 네 장** (`c6e911f`)

사용자가 **「프롬프트 손실없이 추가」**라며 두 묶음을 줬다. 각 원 장 **바로 뒤**에 두 장씩.

| 뒤에 붙은 원 장 | 새 장 | 담은 것 |
|---|---|---|
| 02 소자본 창업 5단계 | **AI Prompt ① 통합** | 통합 프롬프트 전문 |
| | **AI Prompt ② 단계별 · 검증** | 학생용 5질문 **표** · 심사위원 검증 프롬프트(6항목 5점) · 마무리 문장 |
| 10 시그니처 상품 체크리스트 | **AI Prompt ① 체크리스트 작성** | 8항목 작성 프롬프트 전문(「확인 필요」 표시 지시까지) |
| | **AI Prompt ② 한 단계씩** | 「AI가 나에게 하나씩 묻는」 시작 프롬프트 · 왜 이 방식이 좋은가 |

- 프롬프트는 `<pre class="prompt">`(`white-space:pre-wrap`)에 **줄바꿈까지 원문 그대로**. 원문의 `**굵게**` 는 `<b>` 로 옮겨 **채울 칸이 노랗게** 보인다.
- 상자마다 **「복사」** 버튼 — `innerText` 를 클립보드로. `<b>` 는 복사할 때 글자만 남는다. **버튼은 눌러 보지 않았다.**
- 카드 높이가 고정(`min(680px,78vh)`)이라 긴 프롬프트는 카드 안에서 스크롤.
- 크롬 헤드리스로 3 · 4 · 14장을 찍어 확인. 넘김 스크립트의 마지막 `render();` 를 `go(i)` 로 바꾼 임시 사본을 찍었다(`sed` 정규식이 안 걸려 `awk` 로 줄 통째 교체).
- 원문 머리의 「좋습니다.」 같은 대화 말은 뺐고, 「학생들이 자신이 생각한…」 · 「이렇게 하면 학생들이…」 · 「이 두 번째 방식은 특히 좋습니다…」 설명은 장 안에 살렸다.

> **교훈 — 「손실 없이」 받은 프롬프트는 `<pre>` 로 줄바꿈째 담고, 복사 버튼을 붙인다.** 학생은 읽는 게 아니라 붙여 쓴다.
