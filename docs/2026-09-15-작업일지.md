## 3. **여행업 창업전략 판에 AI 프롬프트 네 장** (`c6e911f`)

사용자가 **「프롬프트 손실없이 추가」**라며 두 묶음을 줬다. 각 원 장 **바로 뒤**에 두 장씩.

| 뒤에 붙은 원 장 | 새 장 | 담은 것 |
|---|---|---|
| 02 소자본 창업 5단계 | **AI Prompt ① 통합** | 통합 프롬프트 전문 |
| | **AI Prompt ② 단계별 · 검증** | 학생용 5질문 **표** · 심사위원 검증 프롬프트(6항목 5점) · 마무리 문장 |
| 10 시그니처 상품 체크리스트 | **AI Prompt ① 체크리스트 작성** | 8항목 작성 프롬프트 전문(「확인 필요」 표시 지시까지) |
| | **AI Prompt ② 한 단계씩** | 「AI가 나에게 하나씩 묻는」 시작 프롬프트 · 왜 이 방식이 좋은가 |

- 프롬프트는 `<pre class="prompt">`(`white-space:pre-wrap`)에 **줄바꿈까지 원문 그대로**. 원문의 `**굵게**` 는 `<b>` 로 옮겨 **채울 칸이 노랗게** 보인다.
- 상자마다 **「복사」** 버튼 — `innerText` 를 클립보드로. `<b>` 는 복사할 때 글자만 남는다. **버튼은 눌러 보지 않았다.**
- 카드 높이가 고정(`min(680px,78vh)`)이라 긴 프롬프트는 카드 안에서 스크롤.
- 크롬 헤드리스로 3 · 4 · 14장을 찍어 확인. 넘김 스크립트의 마지막 `render();` 를 `go(i)` 로 바꾼 임시 사본을 찍었다(`sed` 정규식이 안 걸려 `awk` 로 줄 통째 교체).
- 원문 머리의 「좋습니다.」 같은 대화 말은 뺐고, 「학생들이 자신이 생각한…」 · 「이렇게 하면 학생들이…」 · 「이 두 번째 방식은 특히 좋습니다…」 설명은 장 안에 살렸다.

> **교훈 — 「손실 없이」 받은 프롬프트는 `<pre>` 로 줄바꿈째 담고, 복사 버튼을 붙인다.** 학생은 읽는 게 아니라 붙여 쓴다.

- 복사 스크립트 `node --check` 통과. **버튼은 눌러 보지 않았다.**

**프롬프트 문장은 한 글자도 바꾸지 않았다.** 바꾼 것은 둘레 설명의 화자뿐 —
「학생들에게는 … 사용하게 하면 좋습니다」 「창업 수업에서는」 「…기억시키면 좋습니다」 「관광에서는 **저는** … 본다」 「학생용으로는 … 제공해도 좋습니다」.

## 오늘의 규칙

- **영상을 넣거나 폭을 줄이면 가운데 정렬까지 한다.**
- **긴 내용을 좌우 넘김 한 장에 더하면 그 장만 세로 스크롤을 열고, 절대 위치 꼬리(쪽 번호)를 풀어 준다.**
- **받은 프롬프트는 `<pre>` 에 원문 줄바꿈 그대로 + 복사 버튼.**
- **부정어가 잘린 요청(「1행으로 하지 …」)은 앞 요청을 뒤집는 것일 수 있다** — 두 해석을 적거나 묻는다.
- **채팅 답을 붙여 넣으면 페이지로 짓되, 프롬프트 문장은 그대로 · 둘레 설명의 화자만 학생 쪽으로.**
- **한 번 받은 말투 결정(「학생 말투로」)은 같은 종류의 파일에 그대로 쓴다** — 매번 묻지 않는다.
- **태그가 낀 한글 치환은 글자 사이 태그를 허용하는 정규식으로 처음부터.**
- **남의 강의자료 · 책 원본은 올리기 전에 묻는다** — 올린다면 `noindex` 와 출처 표기, 그리고 「공개는 공개」라고 알린다.
- **기관 이름은 주소를 열어 운영 주체를 확인하고 쓴다** — 짐작으로 「한국관광공사」라 쓰지 않는다.
- **복사용 상자 안에는 별표 같은 장식을 넣지 않는다** — 붙여 넣는 글에 섞인다.
- **받은 그림은 열어 보고 내용대로 이름 짓는다. `width`·`height` 는 파일 머리에서 읽는다.**
- **링크 목록 자료는 올리기 전에 주소를 전부 연다** — 404 는 첫 화면 주소로, 닫힌 곳(410)은 표시가 있는지 본다.
- **수 MB 짜리 판은 내장 그림을 webp 파일로 떼어 낸다. 슬라이드 트랙 그림에 `lazy` 를 붙이지 않는다.**
