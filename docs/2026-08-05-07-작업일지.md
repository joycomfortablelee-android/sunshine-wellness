## 1. 산업군 지도 통합 — 별도 페이지를 흡수 (`22f8362`)

다운로드 폴더의 `관광경영학과_취업분야_메뉴정리.html`(자체 CSS 566줄, 네이비·골드 테마)을 `learn/career-map.html`로 임시 편입했다가, 사용자 지시로 **`careers.html` 한 페이지에 통합하고 원본은 삭제**.

### 통합 판단 근거
두 문서는 중복이 아니라 **층위가 달랐음**.

| | 기존 careers.html | 지도 문서 |
|---|---|---|
| 답하는 질문 | 어디에 지원하나 (WHERE) | 무슨 일을 하나 (WHAT) |
| 구성 | 5경로 × 외부 링크 | 산업군 14 카드 + 직무이해 6 + 성향표 9행 |

→ 지도(WHAT) → 경로(WHERE) 순으로 이으면 한 페이지에서 완결됨.

### 처리
- 원본 인라인 CSS 566줄을 **그대로 옮기지 않고**, 필요한 컴포넌트만 **`cmap-` 스코프 122줄**로 재작성해 `learn.css`에 추가. 기존 규칙은 수정하지 않음.
- 네이비(#10233f)·골드(#d5a72f) 테마 폐기, learn.css 변수(`--green #3B6259` / `--ivory #FAF7F2`) 톤으로 흡수.
- 산업군 14색 파스텔은 **채도를 낮춰** 유지(사용자 결정 A) — 예: `#eef6ff → #eff3f7`. `--c-bg/--c-line/--c-ico` 변수로 카드별 지정.
- 인쇄·PDF 버튼은 폐기(사용자 결정 B).
- 검색창 + 6개 범주 필터(전체/서비스/교통/콘텐츠/공공·연구/창업) JS는 인라인 `<script>`로 이식.
- 지도의 참고사이트 6건은 삭제 — 5건이 기존 목록과 중복. **한국철도공사(코레일) 1건만** 「철도·교통」에 추가.

## 2. GNB 명칭 — 3차에 걸친 정비

### 2차: 「취업」 → 「진로」 + 영문 Career Resources (`1d52b3a`, `0477251`)
사용자 문제 제기: **「취업」만으로는 창업이 빠진다.** 「Job코칭」 제안이 나왔으나 **실제 1:1 상담·첨삭 서비스가 없어 기대 불일치**를 일으키므로 채택하지 않음.

이때 **영문에서 실재하던 오독을 발견**:
> 당시 영문 라벨이 `Careers`(복수)였음. 기업 웹사이트에서 「Careers」는 **"우리 회사가 채용 중"**을 뜻하는 관례어 → 선샤인 웰니스가 직원을 모집하는 것으로 읽힘. `Career Resources`로 교체해 해결.

- 홈 `#career` 섹션 eyebrow도 `Career` → `Career Resources`, 제목 「취업·진로」 → 「진로·취업 가이드」로 통일(홈·페이지 명칭 일치).
- **부작용 수정(`0477251`)**: `careers.html`은 원래 교육자료 목차에서 들어오는 하위 모듈이라 상단 버튼이 「교육자료 목차」 하나뿐이었음. GNB에 직행 메뉴가 생기면서 **홈으로 돌아가는 버튼이 상단에 없는 상태**가 됨 → `.learn-navs`로 감싸 「← 메인으로」 + 「교육자료 목차」 2개 노출. 560px 이하 패딩·폰트 축소로 줄바꿈 방지.

### 3차: 「진로」 → 「취업자료」 (`a73f358`) ← 최종
사용자 재지적: **여행사 웹사이트에 「진로」만 있으면 학교·상담기관 서비스처럼 읽혀 어색하다.**

**최종 라벨**

| 교육자료 | 교육 | Learn | 学习 |
| 취업 자료실 | **취업자료** | **Career Resources** | **就业资料** |

### 4차(별건): 「견적의뢰 및 문의」 → 「견적문의」 (`f85b97d`)
8글자로 GNB 최장 항목이었음. 같은 메뉴에 문의 성격이 둘(견적의뢰 및 문의 / 고객센터) 있던 것을 **견적문의=구매 전 상담, 고객센터=일반 문의**로 갈라 정리. 「문의」로만 줄이면 고객센터와 겹쳐 채택하지 않음.
- ko 견적문의 / en `Get a Quote`(← Inquire) / zh `报价咨询`(← 咨询预约)

### 사실 확인에서 바로잡은 것 (중요)
- **BPEX = 「포항」이 아니라 「부산항」** — 사용자가 포항국제컨벤션센터로 전달했으나, 실제로는 **부산항국제전시컨벤션센터**(부산 동구, 부산항국제여객터미널 5층, 운영 부산항시설관리센터). `부산항`/`포항` 혼동. 부산 시설이라 학생 접근성은 오히려 좋아짐. **크루즈 터미널 안의 MICE 시설**이라는 점을 지도 카드의 「MICE」·「크루즈·해양관광」을 잇는 사례로 서술.
- **어반리즘 하우스는 HTTPS가 없음** — 인증서 만료, `www`는 https 무응답 → `http://` 로 링크. HTTPS 우선 모드 브라우저에서 경고를 거칠 수 있음(외부 사이트 문제로 우리가 고칠 수 없음).
- **PRISM은 봇 차단** — CLI에서 400 반환. 브라우저 UA로는 200 확인 후 게재.

### 설명 작성 원칙
단순 링크 나열이 아니라 **데이터에서 나오는 해석**을 붙임.
- 포브스 호텔: 17곳 중 **16곳이 서울·인천**(나머지 1곳 제주) → 럭셔리 호텔 커리어는 근무지가 사실상 수도권으로 정해짐. 지역에 남으려면 복합리조트 등 다른 축을 봐야 함.
- BIPA: 공고에 **추정금액·계약형태**가 공개됨 → *"이런 일이 얼마짜리 일인지"* 라는, 학생이 가장 알기 어려운 감각을 잡는 창.
- 한계도 명시 — BIPA 입찰 참여는 **사업자등록+나라장터 등록**이 전제라 재학생은 바로 수주 불가. 안 쓰면 학생이 들어가서 닫아버림.
- 아웃소싱타임스: **관광 특화 매체가 아님**을 명시하고 경로1~2와 역할 분담 안내.

| 항목 | 이전 → 변경 |

| 히어로 상하 패딩 | 72/64px → **50/44px** |
| h1 | 34px → **29px** |
| sub | 16px/1.9 → **15px/1.8** (폭 640→620) |

히어로 하단 + 본문 상단 간격이 **120px → 84px**.

### ⚠️ 캐시 버전 통일 (재발 방지용 기록)
`learn.css`는 전 페이지 공유인데 각 페이지가 `?v=` 를 **제각각(v9~v19)** 로 물고 있었음 → 공유 CSS를 바꿔도 옛 버전에 고정된 페이지는 반영되지 않음. **14개 페이지 전부 `v=20`으로 통일**. 이후 careers.html만 `li.hi` 추가로 `v=21`.

**앞으로 `learn.css` 공통 규칙을 건드리면 전 페이지 버전을 함께 올려야 함.**

- **vercel.app** — 커밋 메시지 "배포" 규칙 준수(18/19).
- ⚠️ **GitHub Pages 빌드 API 지연** — `gh api .../pages/builds`가 새 커밋 항목을 만들지 않거나 이전 커밋에 머무는 경우가 반복됨(빌드 합쳐짐). **빌드 목록이 아니라 라이브 URL의 실제 콘텐츠로 판정**하는 것이 정확함.
- ⚠️ **Vercel CLI 토큰 만료** — `vercel ls`/`vercel --prod` 모두 `The specified token is not valid`. 강제 배포가 필요하면 사용자가 `vercel login`을 직접 실행해야 함. 관련 메모리 `board-and-hosting` 갱신함.
