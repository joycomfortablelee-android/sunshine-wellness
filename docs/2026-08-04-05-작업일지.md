## 4. 기존 버그 2건 수정 (작업 중 발견)

### 4-1. `index.html` DOCTYPE 오타 — 홈 호환 모드 유발
- 첫 줄이 **`<!D작업 OCTYPE html>`** 상태였음. IME 켜진 채 타이핑된 것으로 추정.
- 깨진 DOCTYPE은 브라우저를 **quirks mode**로 떨어뜨려 레이아웃이 미묘하게 틀어짐.
- 8/4 시점엔 **커밋하지 않고 보고만** 함(로컬 변경이라 배포 영향 없었음). 8/5엔 `index.html`을 커밋해야 해서 **함께 복구**.

### 4-2. GNB 겹침 — **메뉴 추가 이전부터 있던 버그**
- 측정 결과 **현재 라이브 사이트가 이미 1280px에서 "아트 컨시어지"와 "로그인"이 겹치고 있었음**. 1280px은 가장 흔한 노트북 폭.
- 원인: `.gnb a { white-space: nowrap }` + 항목 과다 → 줄바꿈 못 하고 `header-right`를 침범. 기존 브레이크포인트는 900px에서야 햄버거로 전환.
- 메뉴가 7개가 되면 1440px에서도 겹치므로 함께 해결:

| 구간 | 처리 |
|---|---|
| ≤1500px | `gap 26→18px`, `margin-left 40→24px`, 폰트 `0.92→0.86rem`, 헤더 패딩 24px |
| <1280px | **햄버거로 전환** (기존 900px에서 상향) |

- ⚠️ **주의해서 처리한 부분**: 기존 900px 블록에는 헤더 규칙과 **본문 레이아웃 규칙(About 2단→1단, define-grid, pillars-grid, contact-inner 등)이 섞여 있었음.** 통째로 1279px로 올리면 1024~1279px 태블릿에서 본문이 전부 1단으로 무너짐 → **헤더 규칙만 분리해 1279px 블록으로 올리고, 본문 레이아웃은 900px에 그대로 남김.**
- 트레이드오프: 나브 폰트가 `0.95 → 0.86rem`으로 작아짐. 폰트를 유지하는 안도 측정했으나 **1440px까지만 커버**되어 실용성이 낮아 채택하지 않음. → **사용자 확인 필요 항목**.
