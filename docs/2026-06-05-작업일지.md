## 1. 챗봇·문의(Inquiry) UX 개편 — 3단계

### 배경 (현황 파악에서 발견)
- 홈 카드 `문의하기`는 `openProgramsPage()`(상품 목록 이동), 상품페이지 카드 `문의하기`는 `openContactPage()`(문의 폼) — **같은 라벨인데 동작이 달랐음**.
- "여행 정보" 모달이 일부 환경에서 안 열림 → 원인: `openModal`이 Blob + `window.open('_blank')` **새 탭**으로 열어, 모바일/팝업차단에서 무반응.
- 히어로 슬라이더 우측 화살표(`.next`)가 우하단 챗봇 버튼과 겹침.

### Step 1 — '여행 정보' 모달: 새 탭 → 인페이지 iframe 오버레이 (`116b4e9`)
- `openModal`에서 `Blob`+`window.open` 제거. 죽어있던 `#modalOverlay`/`#modalContent`를 재사용.
- 생성된 **완전한 HTML 문서를 `<iframe srcdoc>`로 격리**해 인페이지 오버레이에 표시 → 스타일 충돌 없음, 모바일·팝업차단에서도 항상 열림.
- `closeProgramModal()` 추가: ✕ 버튼 / 배경 클릭 / ESC 로 닫기, body 스크롤 잠금. 오버레이 없을 때만 기존 새 탭 방식 폴백.
- CSS: `.modal-box.modal-box-frame`(94%/max 860px/90vh, 패딩0), `.modal-frame`(iframe 풀필), 닫기버튼 흰 원형.

### Step 2+3 — '문의하기' → AI 상담 팝업으로 통일 (`4983593`)
- 홈 6개 + 상품 9개 카드의 `문의하기`를 **모두 `openConsult(programKey)`** 로 교체 → 홈/상품 동작 통일(3번)이 2번에 흡수됨.
- `openConsult()`: 챗봇 팝업을 열고, **누른 프로그램명을 첫 메시지로 자동 안내**("「부산 다크 투어리즘」 문의 주셔서 감사합니다…").
- 챗봇 헤더: **"선샤인 AI 상담사" + 💁‍♀️ 아바타**(이모지 임시본 — 추후 일러스트 `<img>` 교체 가능), 상태문구 "실시간 자동 응답 · 빠른 연결".
- 챗봇 상단에 **빠른 연결 버튼 상시 노출**: `[📞 전화]`(tel) · `[💛 카카오]`(오픈채팅) · `[📝 견적문의]`(챗봇 닫고 `openContactPage()`). → AI 즉답 + 실제 견적 리드 유지.
- 푸터·About·고객센터의 "견적의뢰" CTA는 기존 문의 폼 그대로 유지(의도된 구분).
- CSS: `.chatbot-quick` / `.cbq-btn` 추가.
- z-index 확인: `#subPageOverlay`(900) < 챗봇(9000) → 상품 페이지 위에서도 정상 노출.

### 화살표 겹침 수정 (`37036df`)
- 히어로 슬라이더 `.prev`/`.next` `right` 값 증가(데스크톱 56/112→96/152, 모바일 24/80→88/144)로 우하단 챗봇 코너를 비켜남. 챗봇은 우하단(`right:24/16`) 유지.

## 3. 교육자료(/learn) 허브 확장 — 모듈 7→9개 + 그리드/폭 정리

모듈 2개를 추가(7→**9개**)하고, 9개에 맞춰 그리드와 폭을 다시 잡았다.

### 3-1. Module 08 — 웰니스 관광 (`learn/wellness-tourism.html`, 신규) (`037707c`)
- 선정 이유: 사이트 이름이 **"Sunshine Wellness"** 인데 웰니스 모듈이 없었음 → 브랜드명과 커리큘럼 일치. 부산이 실제 자원(온천·숲·사찰·해변) 보유.
- 본문형(04와 동일 구조): 정의(의료/일반 관광과 차이) → 성장 배경 → 유형 6종(온천·숲치유·명상·한방·식이·영성) → **부산의 웰니스 자원** → 해설(02)과 연결 → 한 걸음 더.
- ⚠️ **「부산의 웰니스 자원」(동래온천·금정산·이기대·범어사 템플스테이 등)은 Claude 작성 초안** → 페이지 내 **노란 "검수 요청" callout** 표기. 사용자 검수 후 확정 예정(원칙: 관광 본문 = 사용자 전문영역).

### 3-2. Module 09 — 영상 홍보 제작 실습 (`learn/video-promotion.html`, 신규) (`037707c`)
- 별도 모듈로 분리: 04(관광 홍보론)는 *이론*, 영상 제작은 *실습* → 05·07과 같은 실습 트랙. 04의 **실습편**.
- 구성: 왜 영상인가(04 연결) → 기획(한 문장 메시지·타깃·길이) → 촬영(빛·안정화·구도·B롤·세로) → 편집(컷·자막·음악 저작권·색보정) → 배포(플랫폼·썸네일·해시태그·SEO) → **실습 과제: 30초 부산 한 장소 영상 체크리스트**.

### 3-3. 허브 연결·sitemap (`037707c`)
- `learn/index.html` 카드 2개(🌿08, 🎬09) 추가 / `travel-english.html`(07) 네비 `only-prev`→양방향, 08 연결 / 08↔09 양방향, 09는 `only-prev`(마지막) / `sitemap.xml` 2건 등록.

### 3-4. 그리드 2열 → 3열 (9 = 3×3 정사각) (`e6e6d2a`)
- 9개를 2열에 넣으면 맨 아래 1개가 외톨이(2+2+2+2+1) → `repeat(2,1fr)`→**`repeat(3,1fr)`** 로 빈칸 없는 3×3.
- 반응형 단계 추가: **≤1000px 2열 / ≤720px 1열**.

### 3-5. 허브 폭 960 → 1160px (프로그램 페이지와 통일) (`f46dcd7`)
- 비교: 허브 960px(카드 ≈289px) vs 프로그램 페이지 1160px(카드 ≈341px) → 허브가 좁고 빽빽 → 1160px로 통일.
- **스코프 분리가 핵심**: `.lw`는 모든 learn 페이지 공통 래퍼라 그대로 넓히면 **본문 모듈 페이지 읽기폭(960px)이 깨짐**. → **`body.hub .lw { max-width:1160px }`** + `index.html`에 `<body class="hub">` 부여 → **허브만 1160px, 본문 모듈 페이지는 960px 유지**.
- 결과: 허브 카드 1장 ≈289px → **≈356px**(프로그램 ≈341px와 정렬).
- 캐시: `learn.css?v`(index.html) **10→11(그리드)→12(폭)**. 그리드/폭은 허브에만 렌더되므로 index.html만 버전 갱신.
