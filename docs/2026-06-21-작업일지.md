## 1. 여행 정보 모달 — 정보 화면이 매우 좁게 보이던 문제 (`1ed2852`) ⭐ 메인 작업

### 증상
- 메인 "웰니스 여행 프로그램"에서 카드의 **"여행 정보"** 버튼 클릭 시 뜨는 상세 모달의 **정보 화면이 스크롤바를 포함해 매우 좁게(짧게)** 보임.

### 원인
- "여행 정보" 모달은 생성된 완전한 HTML 문서를 `<iframe srcdoc>`(`.modal-frame`)으로 **격리**해 인페이지 오버레이에 표시(`openModal()` in `script.js`).
- iframe에 `height:100%`가 걸려 있으나 **부모 `.modal-content`에 높이 지정이 없어** `100%`가 계산되지 못함 → iframe이 **브라우저 기본 높이 150px**로 축소.
- 결과: 박스는 폭 860px·높이 90vh로 충분한데, 내부 iframe만 **w:860 / h:150** 으로 쪼그라들고 콘텐츠(scrollH 903)가 150px 영역에 스크롤바와 함께 갇힘.

### 수정 — `style.css`
```css
.modal-box.modal-box-frame .modal-content {
  height: 100%;
}
```
- `.modal-content`가 모달 박스(90vh) 높이를 채우게 하여 iframe `height:100%`가 정상 계산되도록 함. (CSS `height:100%`는 부모 높이가 정해져 있어야 작동)

### 검증 (headless Edge 스크린샷 `_shot.mjs`)
- 수정 전: `frame {w:860, h:150}`, `clientH:150` (콘텐츠 903px가 150px에 갇힘)
- 수정 후: `frame {w:860, h:810}`, `clientH:810` → 방문 장소·추천 코스·여행 팁·관련 링크가 한눈에 표시 ✅
