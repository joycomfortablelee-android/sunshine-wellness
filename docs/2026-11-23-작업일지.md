- **4장 통계분석 11개 페이지로 확인 범위 확대**: 이어서 4장 전체 목차(1~6절, 11개 "개념+기출" 페이지)를 올려 같은 질문 → **11개 전부 같은 공개형(toggleAnswer) 버그**였음(40문제). "슬라이드"류(a1-x)와 자동채점 문제판(`q-practice62/40.html`)은 샘플 확인 결과 이미 선택형으로 정상
- **11개 파일 일괄 수정은 포크(fork)에 위임**: 11개가 전부 동일한 템플릿(같은 CSS 변수명·같은 `toggleAnswer` 함수)을 쓰고 있어서, 포크가 수동 11회 편집 대신 **파이썬 스크립트로 일괄 변환** 후 각 파일의 문제 수·`data-answer`·`data-choice` 개수를 검증 스크립트로 재확인. 반복적인 기계적 작업은 포크에 넘겨 메인 대화 컨텍스트를 아끼는 방식이 유효했음(34ead57f)
- **백그라운드 세션의 PR 병목**: 오늘도 커밋마다 PR 링크를 드리고 사용자가 직접 "Create pull request → Merge pull request"를 눌러야 했음(PR #6, #7). 사용자가 번거로움을 지적 — 이유는 백그라운드 세션이 안전장치로 master 직접 push·merge가 막혀 있어서라고 설명하고, 앞으로는 급하지 않으면 모아뒀다가 한 번에 머지 요청하는 방식으로 바꾸기로 함. **다음 백그라운드 세션에서도 같은 제약이 있을 것** — 평범한 대화형 세션으로 켜야 이 제약이 없어짐
