## 2. **알약 표식 — ★ 로 넣었다가 중단, ✦ 로 확정** (`3f7bff7`)

「해당 알약에 별표와 노란색 알약으로」 → 2477줄 알약을 `mapl form hot`(남색 꽉 참) **→ `mapl form ylw`**(노랑 `#ffe800` · 글자 `#14120a` · 굵기 800)로 바꾸고 `★` 를 붙였다.

바로 **「스톱」** 과 **「별표 말고 다른 하이라이트 특수 기호 추천」** 이 왔다. 넷을 미리보기로 내놓았다.

| 후보 | 왜 |
|---|---|
| `▶` | 좌우로 넘겨 보는 판이라는 성격과 맞다 |
| `◆` | 11.5px 알약에서도 형태가 뭉개지지 않는다 |
| **`✦`** ← 선택 | ★보다 가볍다. 다만 일부 구형 브라우저에서 이모지 글꼴로 대체될 여지 |
| `✔` | 과제·제출 체크로 읽힐 소지 |

- **`✦` 로 확정.** 슬라이드 판 **안쪽**에 이미 쓰는 금색 `★`(9/16 `cc130e7`)와 겹치지 않아, 알약 표식과 본문 표식이 서로 구분된다.
- **`U+2726` 은 기본이 문자 표현**이라 변이 선택자(`U+FE0E`) 없이 그대로 두었다.
