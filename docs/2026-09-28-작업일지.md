## 2. **⚠️ 로컬이 원격과 갈라져 있었다 (1 ↔ 9)**

커밋하려는데 `git status` 가 **「1과 9 커밋만큼 diverged」** 라고 했다. 9/24 저녁 이후 다른 창이 올린 것이 로컬에 들어와 있지 않았고, 로컬에는 방금 것 하나가 남아 있었다.

```
git pull --rebase   → 충돌 없이 f71ac83 이 d1c2177 위로 얹힘
git push            → 같은 자리
```

- 앞서 `git pull` 이 **`incorrect old value provided`** 로 한 번 실패했는데, 이것이 **다른 창이 같은 순간 ref 를 갱신하고 있었다는 신호**였다. 그때 멈추지 않고 편집을 이어 간 것이 갈라짐을 키웠다.
- **다음부터는 pull 이 실패하면 그 자리에서 다시 맞춘 뒤 편집한다.**

**진단** — 퀴즈가 어려운 게 아니라 **순서가 거꾸로**다. ADsP 는 *말*을 묻는데(DIKW · 정형/비정형 · 지도/비지도) 학생은 그 말을 **아직 써 본 적이 없다.** 써 보지 않은 말은 외우는 수밖에 없고, 외우려니 재미가 없다.

교수님이 적어 준 넷이 정확히 그 빈칸이었다 — **데이터가 어디 있는지 · 분석 방법론 · 프로그램 기술 · 해 보려는 의지.**

| 질문 | 편 | 어디서 하나 |

| 어떻게 하나 | 이론 | 파트 03 다섯 걸음 · 파트 04 기법 |

**줄 순서가 곧 밟는 순서다** — 찾고 · 배우고 · 만져 보고 · 내 보고 · 확인한다. 맨 아래 한 줄로 못박았다: **「ADsP는 출발점이 아니라 도착점입니다.」**

### 7-5. 수업 목표 — 줄이고, 번호 달고, 갈랐다 (`2b416de` · `f090dd8`)

다섯 문장짜리 서술문이 **목적 · 출발 · 할 수 있는 것 넷**을 한 덩어리로 안고 있었다. **왜 하는가**는 앞 두 문장에 남기고, **무엇을 할 수 있게 되는가**는 전부 번호 목록으로 내렸다. 여섯 줄 모두 **「~한다」로 끝나는 동사 하나**만 남겨 길이를 맞췄다.

그다음 교수님이 물었다 — *「문제를 세우는 다섯 걸음과 대표 기법이 뭐야?」* 확인해 보니 **한 줄에 서로 다른 자리의 둘이 묶여 있었다.** 「문제를 세운다」는 다섯 걸음의 **1번(문제 정의)** 이고, 대표 기법 넷은 **4번(분석)** 에서 쓰는 도구다. 갈라서 일곱 줄로 만들고, ➌ ➍ 에만 작은 둘째 줄을 붙여 이름을 폈다.

```
➌ 다섯 걸음으로 분석을 설계한다
   문제 정의 → 수집 → 정제 → 분석 → 시각화·해석   [파트 03 ↓]
➍ 대표 기법 넷으로 패턴을 찾는다
   기술 통계·시각화 · 텍스트 마이닝·감성 분석 · 군집 분석 · 예측 분석   [파트 04 ↓]
```

**교훈** — 목록을 줄일 때는 *길이*만 보지 말고 **한 줄에 두 가지가 들어 있지 않은지**를 본다. 짧아지면서 오히려 섞이는 수가 있다.

```

목표: 찾아낸다   / 설계한다   / 돌린다        / 발표한다 / 증명한다
```

여기서 목표만 2열 표로 만들면 **표 둘이 나란히 서서 같은 내용을 두 번** 읽힌다. 그래서 A · B 두 안을 적어 보이고 **A(합치기)** 를 권했고, 승인을 받아 **네 열 여섯 줄 한 표**로 다시 짰다.

| 배우는 것 | 편 | 논문으로 보면 | 어디서 하나 |
|---|---|---|---|
| 현장의 물음을 **연구 문제로 세운다** | 실전 | 서론 · 연구 필요성 | 파트 03 |
| 빅데이터가 **무엇이며, 어디에 있나** | 이론 · 실전 | 이론적 배경 · 자료 | 파트 01 · 02 · 10 |
| **다섯 걸음**으로 설계한다 | 이론 | 연구 설계 · 방법론 | 파트 03 |
| **기법 넷**을 도구로 돌린다 | 기술 | 분석 | 파트 04 · 05 |
| 시각화해 **의사결정 이야기로 발표한다** | 실전 | 결과 · 논의 | 파트 06 · 11 |
| **공모전 · ADsP**로 증명한다 | 증명 | *논문 밖 · 성과* | 파트 06 · 07 |

- **서론 줄을 첫 줄로 새로 넣어** 빈칸을 메웠다. 다른 창이 「왜 하나」에 적어 둔 *「의지의 바탕은 이론적 관점과 도메인 지식」* 은 그 줄의 설명으로 옮겨 살렸다.
- 「논문으로 보면」은 **연보라 라벨**, 마지막 줄만 **회색**으로 눌러 *논문 밖*임을 보인다.

> **작업 전에 최근 커밋을 확인하고 들어갔다.** 이 영역을 오후에만 다른 창이 일곱 번 고쳤기 때문이다. 확인해 보니 이 파일의 최근 두 커밋이 내 것이었고, 다른 창의 마지막 손질은 **파트 05 도구표**(다른 자리)라 충돌 없이 들어갔다. **7-6에서 세운 규칙을 처음으로 지켜 본 셈이다.**

### 9-4. 수업 목표를 셋으로 (`962f69e`)

교수님이 직접 불러 준 셋으로 갈았다.

```

**이때 이름이 겹치는 문제가 생겼다** — 위에 「수업 목표」가 서고, 아래 표의 첫 열도 「수업 목표」였다. 표의 열 이름을 **「배우는 것」** 으로 바꿔 층을 갈랐다.

```
