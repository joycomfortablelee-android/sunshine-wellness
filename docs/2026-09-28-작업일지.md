## 2. **⚠️ 로컬이 원격과 갈라져 있었다 (1 ↔ 9)**

커밋하려는데 `git status` 가 **「1과 9 커밋만큼 diverged」** 라고 했다. 9/24 저녁 이후 다른 창이 올린 것이 로컬에 들어와 있지 않았고, 로컬에는 방금 것 하나가 남아 있었다.

```
git pull --rebase   → 충돌 없이 f71ac83 이 d1c2177 위로 얹힘
git push            → 같은 자리
```

- 앞서 `git pull` 이 **`incorrect old value provided`** 로 한 번 실패했는데, 이것이 **다른 창이 같은 순간 ref 를 갱신하고 있었다는 신호**였다. 그때 멈추지 않고 편집을 이어 간 것이 갈라짐을 키웠다.
- **다음부터는 pull 이 실패하면 그 자리에서 다시 맞춘 뒤 편집한다.**
