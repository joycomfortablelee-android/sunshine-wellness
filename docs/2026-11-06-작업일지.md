## 관광벤처 04장 린 흐름 — 작은 고리(프로토타입) · 큰 고리(MVP) 두 줄 + 「묻기 두 가지」 표

- 「고객에게 묻고 → 프로토타입 → MVP …」 한 줄을 두 줄로: **작은 고리 · 보여 주고 확인**(불편 묻기 → 프로토타입 → 보여 주고 묻기 ↺, 「공모 서류 · 피칭은 여기까지로도」) / **큰 고리 · 실제로 쓰게**(최소 MVP 테스트 → 불만 듣고 → 고치고 · 최적화 → 시장 · 기업에 → 혁신 · 확장 ↺ 다시 묻기).
- 아래 표(`.fb-ask`): ① 불편 묻기(문제 인터뷰) — 프로토타입 없어도 됨(없어야 진짜 불편을 말함) / ② 보여 주고 묻기(해결책 확인) — 프로토타입 있어야 함. 설명 줄에 「프로토타입 = 보여 주고 묻는 것 · MVP = 실제로 써 보게 하는 것」과 #poc 연결.
