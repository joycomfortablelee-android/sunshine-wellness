## 3. **「취업자료」를 「취업 · 상담」으로 넓혔다** (`3413603`)

수업(교육)과 **상담은 성격이 다르다.** 수업 기록은 *그날 무엇을 했나*이고, 상담 기록은 *이 학생과 지난번에 어디까지 이야기했나*다. 뒤엣것이 이어지지 않으면 상담은 매번 처음부터 다시 시작된다.

그래서 **진로·취업 가이드(`learn/careers.html`) 맨 앞**에 칸을 새로 냈다.

```
상담 · 학생 상담 일지
  날짜 | 학생 | 상담 주제 | 나눈 이야기 | 다음까지 할 일
```

**마지막 칸이 이 표의 핵심**이다 — *다음 상담에서 먼저 확인하는 칸*이기 때문이다. 표는 지금 **빈 상태**로 두었다. 실제 상담 기록은 지어낼 수 없고, 상담이 끝나는 대로 한 줄씩 채우는 자리다.

**상담 전에 학생이 할 일**도 한 줄 붙였다 — 같은 페이지의 「나에게 맞는 진로 찾기」 표에서 자기 줄을 하나 고르고, 「취업 분야 지도」에서 그 줄이 가리키는 산업군 카드를 열어 보고 올 것. *「무엇을 할지 모르겠다」* 보다 *「이 둘 사이에서 고민된다」* 가 상담을 훨씬 멀리 데려간다.

## 4. **스마트관광 학생 노트에 출석부를 새로 냈다** (`4d682b6`)

요청은 한 줄이었다 — *「학생들 출석 표시 좀 만들어줄 수 있어?」*

이 과목은 **수 1–2교시 · 목 2교시**라 한 주에 두 번 만난다. 그래서 다른 과목 출석부와 달리 **한 주에 두 칸**을 뒀다 — 1주 9/2·9/3 부터 16주 12/16·12/17 까지 **8명 × 32회차**. 머리글은 두 줄로 겹쳐 위는 주차와 날짜, 아래는 **수 · 목**을 적었다.

**표시할 값이 없다는 것이 문제였다.** 관광벤처 출석부는 교수님이 준 기록을 그대로 박아 넣은 고정 표인데, 이 과목은 아직 기록이 없었다. 지어내면 안 되고, 빈 표만 두면 쓸모가 없다. 그래서 **눌러서 표시하는 표**로 만들었다.

```
빈칸 → ○ 출석 → 지 지각 → 결 결석 → – 공결·취업계 → 빈칸
```

칸을 누르면 상태가 돌고, 오른쪽 **학생별 출석 수**와 맨 아래 **회차별 출석·결석**이 즉시 다시 셈해진다(지각은 출석에 포함). 값은 `localStorage` 에 담긴다.

| 단추 | 하는 일 |
|---|---|
| 오늘 칸으로 | 오늘 회차로 가로 스크롤 + 포커스 |
| 오늘 회차 모두 출석 | 그 회차 여덟 칸을 한 번에 ○ |
| 표 내용 복사 | 표 전체를 탭 구분 텍스트로 클립보드에 |
| 전부 지우기 | 확인 뒤 초기화 |

**「표 내용 복사」를 넣은 이유**가 핵심이다. 정적 페이지라 서버가 없고, `localStorage` 는 **그 브라우저 안에만** 남는다 — 기기를 옮기면 비어 있고, 나에게도 보이지 않는다. 복사 단추는 그 벽을 넘는 유일한 길이다.

## 5. **9/23 회차는 브라우저가 아니라 페이지에 박았다** (`b1243af` · `bec426f`)

그날 저녁 교수님이 명단을 줬다 — **서효원 · 김준호 · 심태섭 · 전승예 · 박상준 · 김윤서** 여섯 명.

여기서 선택지가 갈렸다. 클릭으로 넣으면 **교수님 브라우저에만** 남는다. 확정된 기록이므로 **HTML 안에 값으로 적는** 쪽을 택했고, 그러려면 두 가지가 같이 살아야 했다.

```js
/* HTML 에 박혀 있는 값(data-v)은 기본값 — 이 브라우저에서 누른 값이 있으면 그쪽이 이긴다. */
cells().forEach(function (td) {
  var id = idOf(td);
  if (td.dataset.v && !(id in data)) data[id] = td.dataset.v;
});
```

즉 **고정 기록과 즉석 체크가 한 표 안에 공존**한다. 지나간 회차는 페이지가 들고 있고, 앞으로의 회차는 눌러서 표시한다.

**김대호는 「결석」이 아니라 「–」로 적었다.** 처음엔 결석으로 두고 물었다 — 관광벤처 출석부에서 이 학생이 **(취업계)**로 잡혀 있었기 때문이다. 같은 학생이 맞다는 답을 받고 이름 옆에 꼬리표를 달고 칸을 `–`로 바꿨다. 맨 아래 **결석 수에는 그대로 들어간다**(관광벤처와 같은 규칙) — 범례에 그 단서를 적어 두었다.

## 9. **한 학기에 쌓이는 것 — 누적 막대** (`48d031c`)

교수님 제안: 「1~15주에 걸쳐 능력이 신장되는 느낌의 막대 그래프」. **높이에 근거를 두는 쪽**으로 답했다.

- **8주(중간) · 15주(보강)는 빗금**으로 두고 높이를 올리지 않았다. *올라가기만 하는 그래프는 시험 주에 거짓말을 한다.*
- 색은 **한 초록의 네 단계**(틀 잡기 → 좁히기 → 증명하기 → 묶기). 여러 색을 쓰면 「종류가 다르다」로 읽힌다.
- 막대를 누르면 그 주차 접기 상자가 **열리면서** 그리로 내려간다(`details.open = true`). 이를 위해 주차 상자 열여섯에 `id="wk1"~"wk16"` 를 달았다.
- 1~4주 막대 아래 짙은 선 = 「여기까지 왔다」. **매주 한 칸씩 늘린다.**

> **처음에 막대가 납작했다** — `height: var(--h)` 의 기준(부모 높이)이 없어서였다. `.gb-track { height: 172px }` 를 두고 해결. *퍼센트 높이는 기준이 있어야 산다.*

## 13. **출석부 두 벌을 한 벌로 합쳤다 — 그리고 목요일이 네 번뿐이었다** (`ccd81b6`)

6번에서 적어 둔 문제(같은 과목 출석부가 두 페이지에)를 교수님이 정리해 줬다. **발표 현황 페이지 쪽으로 옮기라**는 것, 그리고 결정적인 사실 하나 —

> **목요일 수업은 네 번뿐이다** — 10/1 · 10/29 · 11/19, 그리고 1주차(각 3시간 · 09–12시).

내가 만든 표는 **32회차**였다. 수·목이 매주 있다고 읽고 16주 × 2로 짠 것이다. 실제로는 **수요일 16주 + 목요일 네 번 = 20회차**다. **열두 칸이 있지도 않은 수업이었다.**

시간표에 적힌 「수 1–2교시 · 목 2교시」를 **매주 두 번**으로 읽은 것이 화근이다. 시간표는 <em>배정된 시간</em>이고, 실제로 만나는 날은 그것과 다를 수 있다 — 물어봤어야 했다.

### 합친 방식

| | 어떻게 했나 |
|---|---|
| 표 | 발표 현황 페이지의 **고정 표를 걷어 내고**, 학생 노트에 있던 **눌러서 표시하는 표**를 그 자리에 놓음 |
| 기록 | 고정 표에 있던 **9/9 · 9/16 · 9/23** 세 회차를 새 표에 `data-v` 로 박음 (지워지지 않게) |
| 칸 | 20칸 — 목요일이 있는 주(1 · 5 · 9 · 12주)만 머리글이 둘로 갈라짐 |
| 목요일 | **연녹색 바탕**으로 따로 보이게, 범례에 <b>「목 = 3시간 수업」</b> 한 줄 |
| 학생 노트 | 표를 덜어 내고 **「출석부 · 발표 현황 열기 →」** 단추 하나만 남김 |
| 오가는 길 | 발표 현황 위쪽에 **「학생 이해 노트 →」** 알약 추가 |

**고정값과 즉석 체크가 한 표에 같이 산다**(5번에서 만든 구조가 그대로 쓰였다). 지나간 세 회차는 페이지가 들고 있어 어느 기기에서나 보이고, 앞으로의 회차는 눌러서 표시한다.

### 날짜 하나가 어긋난다

주신 목요일 날짜 중 **9/2는 수요일**이다(9/1이 화요일이므로). 나머지 셋이 모두 목요일이고 9/3이면 정확히 4주 간격으로 맞아떨어져 **9/3으로 넣고 물었다.** 9/2 수요일에 3시간 수업을 한 것이라면 1주차 칸을 다시 짜야 한다.

**교훈** — 6번에서 *「새 표를 만들기 전에 그 과목 페이지들을 먼저 훑어야 했다」* 고 적었는데, 여기에 하나 더 붙는다: **수업이 실제로 몇 번 열리는지는 시간표가 아니라 교수님만 안다.** 회차를 짜는 표는 날짜를 먼저 확인하고 만든다.
