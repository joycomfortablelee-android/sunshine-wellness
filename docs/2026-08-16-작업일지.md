## 1. 2022 수상 도시 항목을 도시별로 줄 나눔

파트 02 「2022년 유럽 스마트관광 수도」 카드의 첫 번째 번호 항목이 문제였다. 한 덩어리 안에 **도시 둘의 지표가 이어 붙어** 있어, 어디서 도시가 바뀌는지 읽으면서 찾아야 했다.

### 1-1. 바뀐 모습

```
무엇인가 — 유럽연합이 해마다 뽑는 「유럽 스마트관광 수도」의 2022년
           수상 도시가 프랑스 보르도와 스페인 발렌시아입니다.
보르도:    인구 약 25만 7천, 18세기 도시 경관을 간직한 채 유네스코 세계유산
           등재 구역이 세계 최대 규모(등재 대상 347건)이고 도시 재생의 선두주자.
발렌시아:  인구 약 79만으로 스페인 세 번째로 큰 도시, 연 220만 명이 찾고
           유네스코 세계유산 세 곳을 보유하며 관광업 종사자가 3만 명을 넘습니다.
           두 도시 모두 규모가 아니라 관리 방식으로 뽑혔습니다.
```

**도시 이름이 줄머리에 선다.** 보르도와 발렌시아를 견주어 읽을 때 눈이 왼쪽 끝만 따라가면 된다.

### 1-2. 마지막 문장은 붙여 뒀다

「두 도시 모두 규모가 아니라 관리 방식으로 뽑혔습니다」는 **두 도시를 아우르는 요약**이라 한 줄 더 떼어 낼지 물었는데, 사용자가 **「떼어내지 말고 이어서」**라고 정했다.

> **줄 나눔은 「항목이 바뀌는 곳」에만 넣는다.** 요약은 새 항목이 아니라 앞 내용의 마무리다. 여기서 또 나누면 *셋째 도시가 있나* 하고 눈이 한 번 멈춘다.

넣은 것은 `<br />` **두 개뿐**이고 문구도 CSS도 건드리지 않았다. (`7ce7611`)

## 2. ⚠️ 「Vercel 배포 정지」는 오진이었다 — 실은 엣지 캐시

### 2-1. 내가 내린 진단

어제 25-7과 오늘 아침까지 이렇게 판단했다.

> `sunshine-wellness.vercel.app`이 `v=116`에 묶여 연속 다섯 커밋을 놓쳤다. 전부 「배포」가 들어 있었으니 알려진 규칙 문제가 아니다.

근거는 **curl 결과 하나뿐**이었다. 20초 간격 6회를 포함해 여러 번 확인했고 계속 `v=116`이었다.

### 2-2. 실제로는 전부 빌드되고 있었다

사용자가 `vercel login`을 마친 뒤 CLI로 직접 확인했다.

```
vercel ls sunshine-wellness

  11m   ● Ready   Production   10s
  16m   ● Ready   Production   10s
  10h   ● Ready   Production   10s
  11h   ● Ready   Production   10s   … (20건 전부 Ready)
```

**실패도 취소도 큐 대기도 없었다.** 10~11시간 전 항목이 어젯밤 22:17~22:38의 그 커밋들이다. 빌드는 매번 10초에 끝났고 전부 `Ready`였다.

그리고 지금 두 호스팅을 대조하니 **완전히 같다.**

| 항목 | `sunshinewellness.co.kr` | `sunshine-wellness.vercel.app` |
|---|---|---|
| CSS 버전 | `v=119` | `v=119` |
| 5단 `--fs-hero` | 28px | 28px |
| 줄간격 `--lh-read` | 1.8 | 1.8 |
| 글꼴 통일 규칙 | 3개 | 3개 |
| 연구표 `table-layout: fixed` | 있음 | 있음 |
| 보르도·발렌시아 줄나눔 | 2곳 | 2곳 |

### 2-3. 무엇이 잘못됐나

`vercel.app` 별칭이 **새 배포가 `Ready`가 된 뒤에도 한동안 옛 HTML을 엣지에서 돌려줬다.** `learn.css?v=…`는 HTML 안에 박힌 문자열이라, HTML이 캐시되면 CSS 버전도 옛것으로 보인다. **CSS 파일 자체는 바뀌었는데 그것을 가리키는 HTML이 낡아 있었던 것이다.**

> ⚠️ **`curl` 한 번으로 「배포 실패」를 단정하지 말 것.** 배포 상태는 `vercel ls`가 말하고, 캐시 상태는 curl이 말한다. **둘은 다른 질문이다.** 순서는 `vercel ls`(빌드가 됐나) → `curl`(엣지가 갱신됐나)이다.

> **「배포」 키워드 규칙은 이번 건과 무관하다.** 다섯 커밋 모두 「배포」가 들어 있었고 모두 빌드됐다. 규칙 자체는 유효하니 계속 지킬 것.

### 2-4. 사람에게 시킬 일과 내가 할 일

`vercel login`은 브라우저 기기 인증이라 사용자가 직접 해야 했다. **하지만 로그인 이후는 전부 내가 할 수 있는 일이었다.** 사용자가 「이거 너가 할 수 있는 거 아냐?」라고 물어서야 CLI를 직접 잡았다.

> **사람에게 넘길 것은 「인증」 하나뿐이다.** 그 뒤의 조회·진단까지 떠넘기면, 사용자는 알 필요 없는 명령어를 배우게 된다.
