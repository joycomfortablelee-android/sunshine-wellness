### 게시판 클릭 시 아무것도 안 열리는 버그 수정 (3단계)

#### 1차 시도 — window.open(blob URL) → 실패
- 원인: `file://` 로컬 환경에서 브라우저 팝업 차단기가 blob URL 새 탭을 자동 차단
- 시도: `showSubPage(html)` 오버레이 방식으로 교체

#### 2차 시도 — showSubPage() → 여전히 안 열림
- 원인 파악 어려움 (기존 `#subPageOverlay` 인프라와의 충돌 또는 상태 간섭 의심)
- `closeSubPage` 자동 호출 경로 없음 확인, JS 문법 오류 없음 확인 (`node --check`)

#### 3차 시도 — 완전 독립 오버레이 직접 생성 → 적용
- `showSubPage` 의존 완전 제거
- `document.createElement('div')` 로 `#_boardPostOvl` 오버레이를 body에 직접 append
- `innerHTML`/`onclick` 속성 대신 `addEventListener('click', ...)` 사용 (전역 스코프 의존 제거)
- `z-index: 9999` 로 최상위 표시 보장
- 닫기 버튼: `ov.remove()` + `document.body.style.overflow = ''`

```js
function openBoardPost(id) {
  const post = boardData.find(function(p) { return p.id === id; });
  if (!post) return;
  const prev = document.getElementById('_boardPostOvl');
  if (prev) prev.remove();
  const ov = document.createElement('div');
  ov.id = '_boardPostOvl';
  ov.style.cssText = 'position:fixed;top:0;left:0;width:100%;height:100%;background:#f8f9fa;z-index:9999;overflow-y:auto;font-family:inherit';
  // ... DOM 구성 후
  document.body.appendChild(ov);
  document.body.style.overflow = 'hidden';
}
```

### About 페이지 타이포그래피 통일 (모바일 특히)

#### 문제
- 5개 About 섹션 모두 인라인 `style="font-size:..."` 로 작성
- 섹션마다 폰트 크기가 제각각 → 모바일에서 특히 들쑥날쑥하게 보임

#### 해결 — CSS 클래스 시스템 도입

`style.css`에 공통 타이포그래피 클래스 추가:

| 클래스 | 데스크톱 | 모바일 | 용도 |
|---|---|---|---|
| `.ab-eyebrow` | 11px | 10px | 레이블 (SUNSHINE WELLNESS, WHO WE ARE 등) |
| `.ab-h1` | clamp(26–40px) | 22px | 메인 제목 |
| `.ab-h2` | clamp(20–30px) | 19px | 섹션 제목 |
| `.ab-body` | 15px | 13.5px | 본문 |
| `.ab-caption` | 13px | **13.5px** | 카드 설명 |

- `@media (max-width:640px)` 에서 모든 클래스 일관된 크기로 통일
- 모바일 레이아웃도 동일 미디어쿼리에서 처리:
  - `.ab-stats` → 세로 스택 (`flex-direction: column`)
  - `.ab-who-grid`, `.ab-for-you-grid`, `.ab-promise-grid` → 단일 열

`script.js` 에서 5개 섹션 (sec1~sec5) 인라인 font 스타일 → 클래스 교체:
- `style="font-size:...;font-weight:..."` → `class="ab-h2"` 형식으로 통일
- `fix_about_typo.js` 스크립트로 적용 (Node.js 파일 수술)

#### 캡션 최소 사이즈 조정
- 사용자 요청: "본문 안 설명과 카드 설명의 제일 작은 사이즈를 13.5로"
- `.ab-caption` 모바일: 12.5px → **13.5px** (`.ab-body`와 동일)
