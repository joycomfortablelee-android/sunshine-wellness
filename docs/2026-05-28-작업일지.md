### 게시판 클릭 버그 — 근본 원인 규명 및 수정

#### 진단 과정
- `openBoardPost(1)` 콘솔 직접 실행 → 완벽히 정상 작동 확인
- 마우스 클릭 → 어떤 이벤트 리스너도 반응 없음
- `document.elementsFromPoint(cx, cy)` 실행 결과:

```
0 TD  "sp-col-title"   z: auto  pos: static   → 오버레이 내부 요소
4 DIV "subPageOverlay" z: 900   pos: fixed    → 원인
5 BUTTON "board-post-button"                  → 실제 버튼 (가려짐)
```

#### 근본 원인
- `#subPageOverlay` (position: fixed, z-index: 900) 가 게시판 위를 완전히 덮고 있었음
- "Where to Next?" 오버레이 안에 별도 게시판 목록(`#boardList`)이 있는데 행에 `onclick`이 없었음
- 사용자는 오버레이 안의 게시판을 클릭하고 있었으나 아무 반응이 없었던 것

#### 수정 내용
1. **`_boardRender()` 행에 onclick 추가**: `onclick="_openBoardDetailInOverlay(id)"`
2. **`_openBoardDetailInOverlay(id)` 신규 함수**:
   - 오버레이를 닫지 않고 오버레이 내부에 게시글 상세 내용 직접 렌더링
   - `boardData`에서 전체 내용(content) 가져와 표시
   - "← 목록으로" 버튼 → `openWhereToNextPage()` 호출로 목록 복귀
3. **`#boardTable` 버튼에 인라인 onclick 추가**: `onclick="openBoardPost(N)"`
4. **`.hero { overflow: hidden }` 추가**: 슬라이드가 히어로 영역 밖으로 벗어나는 경우 차단
5. **캡처 핸들러 `stopPropagation` 제거**: 불필요하게 하위 요소 이벤트를 막던 문제 제거

### 오버레이 게시판 테이블 헤더 개선

#### 변경 전: 3열
| NO. | 제목 | 날짜 |

#### 변경 후: 5열 (데스크톱) / 3열 (모바일)
| 번호 | 여행지 | 제목 | 작성자 | 등록일 |

- `boardData` 각 게시글에 `destination` 필드 추가 (부산/제주도/미정)
- `_boardRender()`에서 `boardData` 크로스 참조하여 여행지·작성자·날짜 표시
- 오버레이 `<th>` 에 CSS 클래스 추가 (`.sp-col-dest`, `.sp-col-date` 등)
- 날짜 줄나눔 방지: `white-space: nowrap`
- 헤더-바디 열 폭 통일
