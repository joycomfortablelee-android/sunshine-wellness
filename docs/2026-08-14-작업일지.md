대상은 `learn/smart-tourism.html` 최상단의 파란 강조 카드(`li.hi`). 제목 줄은 이미 링크였지만, 그 아래 **메타 줄의 도메인 텍스트는 링크가 아니라 회색 글자**였다. 사용자가 그 줄을 눌러 봤다는 뜻이므로, 보이는 URL은 눌리는 게 맞다고 판단.

## 1. 메타 줄 링크화 (`learn/smart-tourism.html:45`)

**변경 전**
```html
<span class="meta">한국관광공사 · korean.visitkorea.or.kr/smarttourcity · "여행을 더 똑똑하게, 로컬을 더 생생하게"</span>
```

**변경 후** — 도메인을 제목과 같은 목적지로 연결하고(`↗`), 뒤에 「함께 보기」로 경희대 링크 추가.
```html
<span class="meta">한국관광공사 ·
  <a href="…/smarttourcity/main/index.kto" target="_blank" rel="noopener">korean.visitkorea.or.kr/smarttourcity ↗</a>
  · "여행을 더 똑똑하게, 로컬을 더 생생하게" · 함께 보기
  <a href="https://strc.khu.ac.kr/01/02.php" target="_blank" rel="noopener">경희대 스마트관광연구소 연혁 ↗</a>
</span>
```

### 링크 문구를 "연혁"으로 잡은 근거
`strc.khu.ac.kr/01/02.php` 는 URL만으로는 무슨 페이지인지 알 수 없어 **WebFetch로 실제 내용을 확인**한 뒤 문구를 정했다.

> 경희대학교 관광산업연구원 **스마트관광연구소** — `History` 페이지. 2013년 개소부터 2020년까지 연구 성과·교수진 활동·정부 과제 선정·국제 학술활동을 시간 역순으로 기록.

즉 이 링크는 **공식 플랫폼(현장)** 옆에 붙는 **학술·연구 계보**다. 카드의 성격(현장 먼저 보기)과 층위가 다르므로 제목 링크로 올리지 않고 메타 줄에 「함께 보기」로 배치.

## 2. CSS — 메타 줄 전용 링크 규칙 신설 (`learn/learn.css:115`)

`.meta` 안에 그냥 `<a>`를 넣으면 **자료실 링크 기본 규칙이 먼저 잡힌다**:

```css
.learn-article .reslist a { font-size: 16px; font-weight: 800; color: var(--deep); }
```

→ 12px 회색 메타 줄 한가운데에 **16px 굵은 제목 크기 글자**가 끼어들어 줄이 깨진다. `.desc a` 에 이미 같은 목적의 오버라이드가 있었으므로(`:114`) 같은 방식으로 `.meta a` 를 추가:

```css
.learn-article .reslist .meta a { font-size: inherit; font-weight: 700; color: inherit; border-bottom: 1px solid currentColor; }
.learn-article .reslist .meta a:hover { text-decoration: none; opacity: .78; }
```

- `color: inherit` — `li.hi .meta { color: #2563a8 }`(`:127`)를 그대로 물려받아 카드 파란색 유지. 색을 새로 박지 않아 강조/비강조 카드 양쪽에서 자동으로 맞는다.
- 링크임을 알리는 신호는 **밑줄 1px만** — 크기·색이 주변과 같으므로 밑줄이 유일한 단서다.

## 3. ⚠️ 캐시 버전 누락 — 커밋 후 발견해 후속 수정

첫 커밋(`3fd222c`)에서 **`learn.css` 를 수정하고도 `smart-tourism.html` 의 캐시 버전을 올리지 않았다.** 그 페이지는 `learn.css?v=20` 을 참조 중이었다.

**증상(재방문자 한정)**: HTML은 새로 받지만 CSS는 브라우저 캐시의 v=20 — `.meta a` 규칙이 없으므로 `.reslist a` 가 적용돼 **메타 줄의 두 링크가 16px 굵은 글씨로 튀어나온다.** 신규 방문자·강력새로고침에서는 정상이라 놓치기 쉬운 종류.

→ `learn.css?v=20` → **`v=24`** 로 상향(`learn/smart-tourism.html:14`).

### 현재 캐시 버전 현황 (불일치 상태)
| 파일 | 버전 |
|---|---|
| `smart-tourism.html` | **v=24** (오늘) |
| `careers.html` | v=23 (2026-08-08) |
| 나머지 12개 페이지 | v=20 |

이번 변경은 `.meta a` **추가 규칙뿐**이고 `.meta a` 를 쓰는 페이지가 현재 `smart-tourism.html` 하나이므로, 나머지 페이지를 함께 올리지 않아도 깨지는 곳은 없다. 다만 **버전이 세 갈래로 갈라진 상태**라, 다음에 공통 규칙을 건드릴 때는 13개 페이지를 한 번에 통일할 것.

> 교훈: **`learn.css` 를 수정했으면 그 규칙을 쓰는 페이지의 `?v=` 를 같은 커밋에서 올린다.** 08-08 세션에서 "CSS 변경 없음 → 버전 유지"를 여러 번 판단한 것의 반대 방향인데, 반대쪽을 빠뜨렸다.
