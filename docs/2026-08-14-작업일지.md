## 1. 메타 줄 링크화 (`learn/smart-tourism.html:45`)

**변경 후** — 도메인을 제목과 같은 목적지로 연결하고(`↗`), 뒤에 「함께 보기」로 경희대 링크 추가.

## 2. CSS — 메타 줄 전용 링크 규칙 신설 (`learn/learn.css:115`)

`.meta` 안에 그냥 `<a>`를 넣으면 **자료실 링크 기본 규칙이 먼저 잡힌다**:

```css
.learn-article .reslist a { font-size: 16px; font-weight: 800; color: var(--deep); }
```

→ 12px 회색 메타 줄 한가운데에 **16px 굵은 제목 크기 글자**가 끼어들어 줄이 깨진다. `.desc a` 에 이미 같은 목적의 오버라이드가 있었으므로(`:114`) 같은 방식으로 `.meta a` 를 추가:

```css
.learn-article .reslist .meta a { font-size: inherit; font-weight: 700; color: inherit; border-bottom: 1px solid currentColor; }
.learn-article .reslist .meta a:hover { text-decoration: none; opacity: .78; }
```

- `color: inherit` — `li.hi .meta { color: #2563a8 }`(`:127`)를 그대로 물려받아 카드 파란색 유지. 색을 새로 박지 않아 강조/비강조 카드 양쪽에서 자동으로 맞는다.
- 링크임을 알리는 신호는 **밑줄 1px만** — 크기·색이 주변과 같으므로 밑줄이 유일한 단서다.

## 3. ⚠️ 캐시 버전 누락 — 커밋 후 발견해 후속 수정

### 9-2. 01~05장을 한 화면 좌우 슬라이드로 (`4e50a6a`, `d49ef66`)

사용자 질문: *"01 02 03 04 슬라이드 형식으로 좌우로 나오게 할 수 있나. 한 개의 화면에서?"*

`<p class="learn-part">` 로 나뉘어 있던 다섯 절을 파이썬 스크립트로 **`<section class="slide">` 다섯 개로 감싸고**, 그 위에 덱 UI를 얹었다.

- **점 네비** `01 정의 / 02 네 기둥 / 03 기술 / 04 여정 / 05 부산` — 강의 중 특정 절로 바로 점프하기 위한 것.
- **이전/다음 버튼 + `01 / 05` 카운터**, 양 끝에서 `disabled`.
- **키보드 ←→** — 단, `getBoundingClientRect()` 로 **덱이 화면에 보일 때만** 가로챈다(페이지 다른 곳에서 방향키를 눌렀을 때 슬라이드가 멋대로 넘어가지 않게).
- **터치 스와이프** 55px 임계값.
- **「전체 펼쳐 보기」 토글** — 슬라이드가 싫은 사람은 기존처럼 쭉 읽을 수 있다.

**진행 강화(progressive enhancement)로 설계했다** — HTML에는 `hidden` 을 넣지 않고, JS가 로드되면 `deck.classList.add('deck--on')` 을 붙이고 그때 첫 슬라이드만 남긴다. 따라서 **JS가 없거나 실패하면 예전 그대로의 연속된 글**이고, 검색엔진도 다섯 절을 모두 읽는다. 인쇄 시에도 전부 펼쳐진다(`@media print`).

**CSS 함정 2건**
1. 처음엔 슬라이드를 `grid-area: 1/1` 로 겹쳐 높이를 최대 슬라이드에 맞추려 했으나, 02장과 01장의 길이 차가 커서 **빈 공간이 크게 남는다** → `hidden` + `min-height: 330px` 으로 바꿔 높이 점프만 완화.
2. `.learn-part:first-of-type { margin-top: 8px }` 가 **각 `<section>` 안에서 다시 발동**해, 펼침 모드에서 절들이 붙어 버렸다 → `.deck--on.is-open .slide + .slide .learn-part { margin-top: 46px }` 로 회복(`d49ef66`).

`learn.css` 를 두 번 건드려 **`?v=26 → 27 → 28`** 로 올렸다(매번 14개 페이지 일괄).
