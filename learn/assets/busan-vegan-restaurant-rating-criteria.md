# 부산 비건 맛집·카페 찾기 — 온라인 조사용 등급 기준

> 공개된 온라인 자료만으로 식당과 카페의 비건·베지테리언 제공 수준, 식물성 우유 대체 가능 여부와 정보 신뢰도를 일관되게 분류하기 위한 조사 기준이다. 이 등급은 현장 검증이나 공인 인증을 의미하지 않는다.

## 1. 조사 목적

- 조사자가 같은 자료를 보고 유사한 결론을 내릴 수 있게 한다.
- `비건 전문`, `비건 옵션`, `베지테리언 옵션`을 구분한다.
- 카페의 비건 디저트와 식물성 우유 대체 가능 음료를 조사 대상에 포함한다.
- 확인된 사실과 추정 정보를 분리한다.
- 오래되거나 근거가 약한 온라인 정보를 사용자에게 명확히 알린다.

## 2. 조사 가능 범위

### 온라인으로 평가하는 항목

- 식당의 현재 영업 여부
- 공식적인 비건·베지테리언 표방 여부
- 메뉴 이름과 메뉴 설명
- 공개된 원재료 및 알레르기 정보
- 비건 메뉴의 수와 선택 범위
- 두유, 오트밀크, 아몬드밀크 등 식물성 우유 대체 가능 여부와 추가 요금
- 비건 디저트·베이커리 제공 여부
- 최근 정보의 존재 여부
- 공용 조리시설 및 교차 접촉에 관한 공개 안내

### 온라인 자료만으로 확정하지 않는 항목

- 실제 조리 시 원재료 대체 여부
- 육수·소스·김치에 포함된 비공개 원재료
- 조리도구, 튀김기, 그릴의 실제 분리 여부
- 직원의 비건 주문 대응 수준
- 알레르기 안전성
- 공식 자료가 없는 메뉴의 비건 여부
- 식물성 우유로 바꾼 음료의 시럽, 소스, 파우더, 휘핑크림 등 나머지 원재료

확인할 수 없는 항목은 감점 사유가 아니라 `미확인`으로 표시한다. 단, 비건 여부를 결정하는 핵심 원재료가 미확인이라면 비건 메뉴로 확정하지 않는다.

## 3. 사용 가능한 온라인 출처

### 출처 우선순위

| 우선순위 | 출처 | 예시 |
|---:|---|---|
| 1 | 식당 공식 자료 | 공식 홈페이지, 공식 메뉴판, 예약 페이지, 공식 SNS |
| 2 | 공공·인증기관 자료 | 지자체, 관광기관, 비건 인증기관의 공개 목록 |
| 3 | 지도·예약 플랫폼 | 네이버지도, 카카오맵, Google Maps, 예약 서비스의 메뉴 정보 |
| 4 | 최근 방문자 자료 | 날짜가 확인되는 메뉴판 사진, 상세 리뷰 |
| 5 | 블로그·기사·커뮤니티 | 보조 자료로만 사용하며 단독 확정 근거로 사용하지 않음 |

출처 간 정보가 다르면 최신 공식 자료를 우선한다. 최신 날짜를 비교할 수 없거나 핵심 정보가 충돌하면 `확인 필요`로 분류한다.

## 4. 온라인 조사 등급

### O-V1 — 비건 전문 표방 🟢

다음 조건을 모두 충족해야 한다.

- 식당 공식 채널이 매장 또는 전체 메뉴를 `비건`으로 명시한다.
- 최근 12개월 이내 공식 게시물이나 메뉴에서 영업 상태를 확인할 수 있다.
- 공식 메뉴에서 명백한 동물성 메뉴가 발견되지 않는다.
- 서로 독립적인 출처 2개 이상에서 동일한 내용을 확인할 수 있다.

**서비스 표시**: `🟢 O-V1 · 온라인 확인 · 비건 전문 표방`

### O-V2 — 비건 중심

- 공식 메뉴에서 비건으로 명시된 메뉴가 전체의 절반 이상이거나 5개 이상이다.
- 논비건 메뉴도 함께 판매한다.
- 최근 12개월 이내 공식 자료에서 비건 메뉴를 확인할 수 있다.

**서비스 표시**: `온라인 확인 · 비건 중심`

### O-V3 — 비건 옵션

- 공식 자료에 `비건`, `vegan`, `식물성` 등으로 명시된 완성 메뉴가 1개 이상 있다.
- 또는 공개된 전체 원재료를 통해 동물성 원료가 없음을 명확히 확인할 수 있다.
- 카페는 비건으로 명시된 음료 또는 디저트가 1개 이상 있거나, 식물성 우유로 변경한 뒤 다른 동물성 원료가 남지 않는 음료가 공식 자료로 확인되어야 한다.
- 단순히 고기나 달걀을 빼 달라는 사용자 후기만으로는 이 등급을 부여하지 않는다.

**서비스 표시**: `온라인 확인 · 비건 옵션`

### O-V4 — 베지테리언 옵션 🟡

- 공식 자료에 `베지테리언`, `vegetarian`, `채식` 메뉴가 1개 이상 표시되어 있다.
- 달걀, 유제품 또는 꿀을 포함할 가능성이 있거나 비건 여부를 확인할 수 없다.
- 식물성 우유 대체는 공식적으로 가능하지만 시럽, 소스, 파우더 등 다른 원재료의 비건 여부를 확인할 수 없는 카페도 포함한다.
- 비건으로 오해하지 않도록 구분해 표시한다.

**서비스 표시**: `🟡 O-V4 · 온라인 확인 · 베지테리언 옵션 · 비건 여부 미확인`

### O-V0 — 확인 필요 🔴

다음 중 하나에 해당한다.

- 공식 온라인 자료가 없다.
- 비건 관련 정보가 사용자 후기나 오래된 블로그에만 존재한다.
- 마지막 유효 자료가 24개월을 초과했다.
- 출처별 메뉴 또는 영업 정보가 서로 충돌한다.
- `채식 가능`이라는 표현만 있고 구체적인 메뉴나 원재료를 확인할 수 없다.

**서비스 표시**: `🔴 O-V0 · 온라인 정보 확인 필요`

### 등급 색상 규칙

| 등급 | 표시 색상 | 의미 |
|---|---|---|
| O-V1 | 그린 `#15803D` | 온라인 근거상 비건 전문점으로 확인됨 |
| O-V2 | 틸 `#0F766E` | 비건 메뉴가 중심이지만 논비건 메뉴도 있음 |
| O-V3 | 블루 `#2563EB` | 일반 식당에서 비건 옵션을 제공함 |
| O-V4 | 옐로 `#CA8A04` | 베지테리언 옵션이며 비건 여부는 미확인 |
| O-V0 | 레드 `#DC2626` | 정보가 부족하거나 출처가 충돌함 |

색상만으로 상태를 전달하지 않는다. 접근성을 위해 색상 원형, 등급 코드와 설명 문구를 항상 함께 표시한다.

## 5. 온라인 조사 점수표

등급은 제4장의 필수 조건으로 정한다. 점수는 자료의 충실도와 신뢰도를 비교하는 보조 지표이며, 점수만으로 상위 등급을 부여하지 않는다.

| 평가 항목 | 배점 | 기준 |
|---|---:|---|
| 공식 비건 표기 | 25점 | 매장 전체 비건 25 / 개별 메뉴 표기 18 / 베지테리언만 표기 8 / 없음 0 |
| 메뉴 확인 가능성 | 20점 | 최신 전체 메뉴 20 / 일부 메뉴 12 / 메뉴명만 확인 6 / 확인 불가 0 |
| 원재료 투명성 | 20점 | 상세 원재료·알레르기 정보 20 / 주요 재료 설명 12 / 설명 없음 0 |
| 출처 신뢰도 | 15점 | 공식·공공 출처 2개 이상 15 / 공식 출처 1개 10 / 플랫폼 자료만 5 / 후기만 0 |
| 정보 최신성 | 15점 | 3개월 이내 15 / 6개월 이내 12 / 12개월 이내 8 / 24개월 이내 3 / 초과·날짜 없음 0 |
| 교차 접촉 안내 | 5점 | 분리 또는 공용 여부 명시 5 / 관련 안내 없음 0 |
| **합계** | **100점** | 온라인 정보 신뢰도 점수 |

### 점수 해석

- 80~100점: 온라인 근거가 매우 충분함
- 60~79점: 온라인 근거가 충분함
- 40~59점: 추가 확인 권장
- 0~39점: 정보 부족

예를 들어 공식 메뉴에 비건 메뉴 1개가 명확하게 표시되고 자료가 충실한 일반 식당은 `O-V3 · 85점`일 수 있지만 `O-V1`로 승급하지 않는다.

## 6. 핵심 용어 판정 규칙

| 온라인 표현 | 기본 판정 |
|---|---|
| `100% vegan`, `비건 전문점`, `전 메뉴 비건` | 다른 자료와 모순이 없으면 O-V1 후보 |
| `vegan restaurant` | 공식 채널의 실제 메뉴를 추가 확인한 뒤 판정 |
| 메뉴 옆 `Vegan`, `VG`, 식물성 인증 마크 | 범례가 확인되면 해당 메뉴를 비건으로 인정 |
| `Vegetarian`, `채식 메뉴` | O-V4 후보; 비건으로 자동 해석하지 않음 |
| `Plant-based`, `식물성` | 달걀·유제품·꿀 포함 여부를 확인한 뒤 판정 |
| `고기 없음`, `meat-free` | 생선·육수·유제품 가능성이 있어 비건으로 인정하지 않음 |
| `비건 변경 가능` | 변경 방법과 대체 원재료가 공식 자료에 있어야 O-V3 인정 |
| 사용자 후기의 `비건 가능` | 조사 단서로만 사용하고 단독 등급 근거로 사용하지 않음 |
| `식물성 우유 변경 가능` | 대체 가능 배지 부여; 완성 음료의 비건 여부는 별도 확인 |
| `오트`, `두유`, `아몬드` 옵션 | 공식 메뉴의 우유 대체 옵션일 때만 인정하고 브랜드·추가 요금 기록 |
| `논데어리`, `dairy-free` | 달걀·꿀 등 다른 동물성 재료가 있을 수 있어 비건으로 자동 인정하지 않음 |

`V`, `VG` 같은 약어는 플랫폼마다 의미가 다르므로 해당 메뉴판의 범례가 없으면 확정 근거로 사용하지 않는다.

## 7. 카페 및 식물성 우유 조사 기준

### 별도 표시 배지

| 배지 | 부여 기준 |
|---|---|
| `식물성 우유 가능` | 공식 메뉴에서 우유를 한 종류 이상의 식물성 우유로 변경할 수 있음 |
| `비건 음료 확인` | 식물성 우유를 포함한 모든 공개 원재료가 비건이거나 공식 비건 표기가 있음 |
| `비건 디저트 있음` | 공식 메뉴에 비건으로 명시된 디저트·베이커리가 1개 이상 있음 |
| `원재료 확인 필요` | 식물성 우유 변경은 가능하지만 다른 재료의 비건 여부가 불명확함 |

### 조사할 세부 항목

- 제공 식물성 우유 종류: 두유, 오트밀크, 아몬드밀크, 코코넛밀크 등
- 식물성 우유 브랜드 또는 제품명
- 변경 가능 음료와 변경 불가 음료
- 대체 추가 요금
- 기본 휘핑크림의 제외 가능 여부
- 초콜릿·카라멜 소스, 베이스 파우더, 시럽의 우유·꿀 함유 여부
- 블렌더, 스팀 피처 등 공용 기구 관련 공개 안내
- 비건 디저트의 달걀, 유제품, 꿀, 젤라틴 사용 여부

### 판정 예시

| 온라인 확인 내용 | 판정 |
|---|---|
| 공식 메뉴에 비건 라떼와 오트밀크 원재료가 명시됨 | `O-V3` + `식물성 우유 가능` + `비건 음료 확인` |
| 우유를 두유로 바꿀 수 있지만 시럽·파우더 정보가 없음 | `O-V4` + `식물성 우유 가능` + `원재료 확인 필요` |
| 사용자 리뷰에만 “오트밀크 가능”이라고 적혀 있음 | `O-V0`; 공식 자료 추가 조사 |
| 공식 메뉴에 비건 케이크가 있고 음료 대체 정보는 없음 | `O-V3` + `비건 디저트 있음` |

식물성 우유 대체 가능 여부는 중요한 탐색 정보지만, 그것만으로 매장 전체나 해당 음료를 비건으로 확정하지 않는다.

## 8. 온라인 조사 절차

1. 식당명, 지점명, 주소가 같은 업장인지 확인한다.
2. 지도 서비스 2곳에서 영업 상태와 공식 채널 링크를 확인한다.
3. 공식 홈페이지, 공식 SNS, 예약 페이지에서 최신 메뉴를 찾는다.
4. 페이지 또는 게시물의 게시·수정 날짜를 기록한다.
5. `비건`, `vegan`, `vegetarian`, `채식`, `plant-based` 키워드를 검색한다.
6. 메뉴명, 설명, 원재료, 가격 및 비건 표기를 근거와 함께 기록한다.
7. 카페라면 식물성 우유 종류, 대체 가능 음료, 추가 요금과 기타 원재료를 확인한다.
8. 독립적인 두 번째 출처로 내용을 교차 확인한다.
9. 등급 필수 조건을 적용한 뒤 온라인 조사 점수를 계산한다.
10. 충돌하거나 확인되지 않은 내용은 추정하지 않고 메모한다.
11. 출처 URL, 확인 날짜, 캡처 또는 인용 위치를 저장한다.

## 12. 품질 관리 규칙

- 식당별 최소 2개 출처를 조사하되, 최소 1개는 공식·공공 출처를 우선한다.
- 검색 결과의 요약 문구만 보지 않고 원문 페이지를 확인한다.
- 지점마다 메뉴가 다를 수 있으므로 지점 단위로 조사한다.
- 후기 작성일과 방문일이 다르면 실제 방문일을 우선 기록한다.
- 번역한 메뉴명은 원문과 함께 보관한다.
- 조사자가 운영하는 블로그나 광고성 게시물은 이해관계 여부를 표시한다.
- 두 조사자의 등급이 다르면 근거를 재검토하고 상위 등급을 임의 채택하지 않는다.

## 13. 면책 및 사용자 안내

- 온라인 정보는 실제 매장 운영과 다를 수 있다.
- 본 등급은 비건 적합 가능성을 탐색하기 위한 정보이며 공인 인증이 아니다.
- 알레르기 또는 엄격한 교차 접촉 관리가 필요한 사용자는 매장에 직접 확인해야 한다.
- 서비스에는 정보 수정 요청과 근거 제보 기능을 제공한다.
