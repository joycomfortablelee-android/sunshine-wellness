사생활 침해

2

책임원칙 훼손

핵심: 책임 소재 불분명, 알고리즘 블랙박스, 데이터 편향

3

데이터 오용

핵심: 데이터 목적의 일탈, 사기 및 조작, 잘못된 지표 사용

위기 요인 → 통제 방안 시험에서 기억할 말
사생활 침해 → 동의에서 책임으로 개인정보 제공자의 동의만이 아니라 사용자의 책임
책임원칙 훼손 → 결과 기반 책임원칙 고수 예측만으로 불이익을 주지 말고 결과에 대한 책임을 명확히
데이터 오용 → 알고리즘 접근 허용 예측 알고리즘의 부당함을 검증·반증할 수 있게
★ 출제 포인트: 교재에서는 위기 요인과 통제 방안을 짝지어 이해하고, 각 통제 방안의 내용과 기대효과를 함께 정리하는 것을 강조합니다.

34회 기출 위기 요인 구분

빅데이터 기술이 발전함에 따라 발생할 수 있는 위기 요인과 그 예시로 적절하지 않은 것은?

(가) 사생활 침해: 개인의 검색 기록을 무단으로 수집하여 맞춤형 광고를 제공
(나) 책임 원칙 훼손: 자동화된 채용 시스템이 과거 데이터를 기반으로 일부 후보자의 면접을 거부
(다) 책임 원칙 훼손: 기술이 사용자 행동을 1시간 후 87% 정확도로 예측한다고 주장
(라) 데이터 오용: 학교가 학생들의 성적을 학문적 목적에 맞게 분석하여 교육 과정 개선에 활용

② (나), (라)

(라)
부적절
학생 성적을 교육 과정 개선이라는 정당한 목적에 활용했다면, 교재가 말하는 데이터 목적의 일탈에 해당하지 않습니다.

교재와 연결해서 보기

사생활 침해 → 동의 없는 수집·익명성 부족

책임원칙 훼손 → 예측 알고리즘의 희생양·책임 소재 문제

데이터 오용 → 잘못된 지표·목적 일탈·조작

★ 한 줄 구분법
사생활 침해 = “내 정보를 허락 없이 썼나?”
책임원칙 훼손 = “예측 때문에 불이익을 받았는데 누가 책임지나?”
데이터 오용 = “데이터나 지표를 잘못된 목적·방식으로 썼나?”

35회 기출 사생활 침해 대응

다음 중 사생활 침해를 해결하기 위한 빅데이터 기술로 적절한 것은?

① 익명화
② 범주화
③ 데이터 정규화
④ 값 표준화

정답 · 오답 해설

정답 ① 익명화
보기 핵심 해설
① 익명화 정답 개인 식별 정보를 삭제하거나 알아볼 수 없는 형태로 변환하여 개인을 식별하기 어렵게 합니다.
② 범주화 기출 정답 아님 정확한 값을 범위·그룹으로 바꾸는 방식입니다. 예: 35세 → 30~40세.
③ 데이터 정규화 오답 데이터 구조를 효율적으로 구성하고 중복을 줄이는 데이터베이스 설계 개념입니다.
④ 값 표준화 오답 분석을 위해 값의 단위·척도 등을 일정한 기준으로 맞추는 처리입니다.
예: “25세, 남성, 서울”처럼 세부 정보가 있는 데이터를 동일 조건의 여러 명으로 묶거나 식별 정보를 지워 개인을 바로 알아볼 수 없게 만드는 것이 익명화의 핵심입니다.
교재 읽기 주의: 이 문항의 기출 해설은 정답을 ① 익명화로 제시합니다. 다만 같은 교재의 ‘비식별 기술의 종류와 예’ 표에서는 범주화 역시 비식별 기술의 한 종류로 설명됩니다. 시험에서는 문항이 묻는 대표 대응 기술 = 익명화로 기억하는 것이 안전합니다.
★ 시험용 한 줄
사생활 침해 → 익명화(Anonymization)

36회 기출 개인정보 비식별화

개인정보 비식별화 기법은 데이터 활용 중 개인정보 노출을 방지하는 데 사용된다. 다음 중 설명으로 가장 적절하지 않은 것은?

① 가명처리 - 특정 식별 정보를 직접적으로 알 수 없는 값으로 변경
② 범주화 - 식별 정보를 해당 데이터가 속하는 범주나 그룹으로 변환
③ 데이터 마스킹 - 개인 정보 식별이 가능한 특정 데이터 값 삭제 처리
④ 총계처리 - 데이터 값을 집계 값으로 대체하여 원본 데이터를 숨김

정답 · 오답 해설

정답 ③ 데이터 마스킹

③이 틀린 핵심 이유: 데이터 마스킹(Data Masking)은 값을 단순히 삭제하는 것이 아니라, 길이·유형·형식 같은 속성을 유지하면서 일부를 가리거나 다른 형태로 익명화하는 방식입니다.

비식별 기술 교재 핵심 내용 쉽게 보는 예
데이터 마스킹 데이터의 길이·유형·형식 등의 속성을 유지하면서 익명 형태로 생성 홍길동 → 홍**
한국대 → **대
가명처리 개인정보 주체의 이름 등을 다른 값으로 변경 홍길동 → 임꺽정 등 다른 값
총계처리 개별값 대신 총합·평균 같은 집계값을 보여줌 학생별 키 → 합 660cm / 평균 165cm
데이터값 삭제 필요 없는 값이나 개인 식별에 중요한 값을 실제로 삭제 이름 삭제, 상세 날짜를 연 단위로 처리
범주화 데이터 값을 범주의 값으로 변환하여 값을 숨김 35세 → 30~40세

교재의 추가 비식별화 개념

난수화 : 일정한 순서나 규칙이 없는 무작위 숫자로 변환

익명화 : 개인 식별 정보를 삭제하거나 알아볼 수 없는 형태로 변환

일반화 : 구체적 값을 더 일반적인 값으로 변환

예: 서울특별시 강남구 신사동 → 서울특별시 / 1987년생 → 1980년대생
★ 29번 함정
마스킹 ≠ 삭제
마스킹 = 가리기·변환 / 실제 삭제 = 데이터값 삭제
