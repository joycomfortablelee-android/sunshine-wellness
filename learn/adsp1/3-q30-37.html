30. 빅데이터 활용의 3대 필수 요소

다음 중 빅데이터 활용의 3대 필수 요소로 가장 적절한 조합은?
① 데이터, 기술, 인력
② 데이터, 인력, 도구
③ 데이터, 기술, 도구
④ 기술, 인력, 프로세스
정답 ① 데이터, 기술, 인력

해설

빅데이터 활용에는 분석할 데이터, 데이터를 저장·처리·분석하는 기술, 그리고 결과를 해석하고 활용하는 인력이 핵심적으로 필요합니다.

보기판단오답 해설
① 데이터, 기술, 인력정답빅데이터 활용의 핵심 3요소를 모두 포함한다.
② 데이터, 인력, 도구오답기술이 빠져 있다. 도구는 기술을 구현하거나 활용하는 수단이다.
③ 데이터, 기술, 도구오답인력이 빠져 있다. 분석 설계와 해석을 담당하는 사람이 필요하다.
④ 기술, 인력, 프로세스오답가장 기본적인 데이터가 빠져 있다. 프로세스는 보조적 요소다.
암기: 빅데이터 3대 요소 = 데이터 + 기술 + 사람 → 재료 + 조리기술 + 요리사

31. 에너지 분야 분석 애플리케이션

다음 중 에너지 분야의 일차원적 분석 애플리케이션으로 옳은 것은 무엇인가?
① 공급사슬 최적화, 수요예측
② 트레이딩, 공급·수요 예측
③ 일정 관리, 수익 관리
④ 가격 계획 최적화, 생산능력 계획
정답 ② 트레이딩, 공급·수요 예측

해설

에너지 분야에서는 가격 변동성과 시장 불확실성을 다루는 트레이딩(Trading), 그리고 발전 및 생산계획의 기초가 되는 공급·수요 예측이 대표적인 분석 영역입니다.

보기판단오답 해설
① 공급사슬 최적화, 수요예측오답수요예측은 관련되지만 공급사슬 최적화는 제조·유통·물류 분야의 대표 사례에 더 가깝다.
② 트레이딩, 공급·수요 예측정답에너지 가격변동 분석과 수요·공급 예측은 에너지 분야의 핵심 분석 영역이다.
③ 일정 관리, 수익 관리오답항공·호텔·관광서비스 등 예약과 수익을 관리하는 서비스 분야에 더 가깝다.
④ 가격 계획 최적화, 생산능력 계획오답주로 제조·생산관리 분야에서 활용되는 분석 사례다.
암기: 에너지 = 가격이 변한다 + 얼마나 필요할지 예측한다 → 트레이딩 + 공급·수요 예측

32. 업무 영역과 분석 사례 연결

다음 중 업무 영역과 분석 사례의 연결이 부적절한 것은?
① 마케팅 관리 - 소비자 구매 패턴 분석
② 재무 관리 - 예산 및 비용 추적
③ 공급체인 관리 - 공급자 신뢰도 평가
④ 인력 관리 - 직원 근무 시간 집계
정답 ④ 인력 관리 - 직원 근무 시간 집계

해설

직원 근무 시간을 단순히 합산하는 것은 기록·집계에 가깝습니다. 분석이라고 하려면 이직 가능성 예측, 인력 배치 최적화, 성과 분석처럼 데이터를 통해 새로운 판단을 해야 합니다.

보기판단해설
① 마케팅 관리 - 소비자 구매 패턴 분석적절고객 행동 데이터를 분석하여 마케팅 전략과 상품 추천에 활용한다.
② 재무 관리 - 예산 및 비용 추적적절재무 상태와 비용 통제를 위해 활용된다.
③ 공급체인 관리 - 공급자 신뢰도 평가적절납품, 품질, 거래이력을 바탕으로 공급망 위험을 관리한다.
④ 인력 관리 - 직원 근무 시간 집계부적절단순한 시간 합산은 분석이라기보다 기록·집계 업무에 가깝다.
핵심 구분: 집계 = 몇 시간 일했나? / 분석 = 누가 이직할까? 어디에 인력을 더 배치할까?

33. 데이터 사이언스의 개념

다음 설명에 맞는 ( )에 공통적으로 들어갈 용어는 무엇인가?

( )(이)란 데이터로부터 의미있는 정보를 추출해 내는 학문으로, 통계학과는 달리 정형 또는 비정형을 막론하고 다양한 유형의 데이터를 분석 대상으로 한다. 또한 분석에 초점을 두는 데이터 마이닝과는 달리 ( )(은)는 분석뿐만 아니라 이를 효과적으로 구현하고 전달하는 과정까지 포함하는 포괄적인 개념이다.
① 데이터 분석 (Data Analytics)
② 데이터 사이언스 (Data Science)
③ 기계학습 (Machine Learning)
④ 인공지능 (Artificial Intelligence)
정답 ② 데이터 사이언스 (Data Science)

해설

데이터 사이언스는 정형·비정형 데이터를 모두 다루며 데이터 수집 → 분석 → 모델링 → 구현 → 결과 전달까지 포괄하는 개념입니다.

보기판단오답 해설
① 데이터 분석오답분석 과정 자체에 더 초점을 두므로 구현과 전달까지 포괄하는 데이터 사이언스보다 범위가 좁다.
② 데이터 사이언스정답다양한 유형의 데이터에 대한 분석, 구현, 전달까지 포함한다.
③ 기계학습오답데이터로부터 패턴을 학습하는 분석 방법·기술로, 데이터 사이언스 전체보다 범위가 좁다.
④ 인공지능오답인간의 지능적 활동을 컴퓨터로 구현하려는 보다 넓은 기술영역으로 문제의 설명과 직접 일치하지 않는다.
암기: 데이터 분석 = 분석 / 데이터 마이닝 = 패턴 발견 / 데이터 사이언스 = 분석 + 구현 + 전달

34. 데이터 사이언티스트의 하드 스킬

데이터 사이언티스트에게 요구되는 역량 중 ‘하드 스킬(Hard Skill)’에 해당하는 것은?
① 데이터 분석 기술
② 커뮤니케이션 능력
③ 협업 능력
④ 문제 해결 능력
정답 ① 데이터 분석 기술

해설

하드 스킬은 구체적인 직무 수행에 필요한 기술적이고 측정 가능한 지식과 능력입니다. 통계, Python, R, SQL, 머신러닝과 같은 데이터 분석 기술이 여기에 해당합니다.

보기판단오답 해설
① 데이터 분석 기술정답기술적이고 측정 가능한 직무 역량이다.
② 커뮤니케이션 능력오답분석 결과를 다른 사람에게 전달하는 대인관계·소통 능력으로 Soft Skill이다.
③ 협업 능력오답팀원 및 타 부서와 함께 일하는 역량으로 Soft Skill이다.
④ 문제 해결 능력오답이 문제의 분류에서는 상황 판단과 문제 정의에 관련된 Soft Skill로 본다.
암기: Hard Skill = 컴퓨터에게 보여줄 수 있는 기술 / Soft Skill = 사람과 일할 때 필요한 능력

① 팀 간 협력과 커뮤니케이션 능력
② 명확하고 설득력 있는 데이터 스토리텔링

④ 빅데이터에 대한 이론적 지식

①②③은 데이터를 실제 업무에서 활용하고 전달하는 실무·소프트 역량의 성격이 강하지만, ④는 빅데이터의 개념과 원리에 관한 전문·기술 지식입니다.

④ 빅데이터에 대한 이론적 지식전문·기술 지식나머지 세 보기와 달리 이론적·전문적 지식에 해당한다.
암기: ① 협업 · ② 전달 · ③ 통찰 제공 = 업무 활용 역량 / ④ = 이론 지식

36. 전략적 통찰력을 위한 분석

다음 중 전략적 통찰력을 얻기 위해 분석을 사용하는 방법으로 부적절한 것은?
① 조직의 비전을 이해하고 분석에 이를 반영한다.
② 데이터 기반 의사결정을 통해 객관적 판단을 내린다.
③ 사업 상황을 확인하기 위해 사업 내부의 문제들을 집중하여 분석을 이용한다.
④ 핵심가치와 연관된 분석 지표를 설계하고 지속적으로 관리한다.
정답 ③ 사업 내부의 문제들에 집중하여 분석을 이용한다

해설

전략적 분석은 조직의 비전, 핵심가치, 장기목표, 데이터 기반 의사결정처럼 전체적이고 장기적인 관점에 초점을 둡니다. 특정 사업 내부 문제에만 집중하는 것은 운영적·단기적 문제 해결에 더 가깝습니다.

보기판단해설
① 조직의 비전을 이해하고 반영적절전략은 조직이 장기적으로 어디로 갈 것인지와 연결되어야 한다.
② 데이터 기반 의사결정적절감보다 데이터를 활용해 객관적인 전략적 판단을 내린다.
③ 사업 내부 문제 집중부적절특정 내부 문제의 단기 해결은 운영적 분석에 더 가깝다.
④ 핵심가치와 연관된 지표 관리적절KPI 등과 핵심가치를 연결하면 전략 실행 여부를 지속적으로 확인할 수 있다.
암기: 전략 = 전체·장기 / 운영 = 부분·단기

37. 데이터 기반 가치 패러다임의 변화

빅데이터의 발전은 정보 가치 창출의 과정을 바꾸고 있다. 다음 중 데이터 기반 가치 패러다임의 변화를 올바르게 나열한 것은?
① 연결(Connection) → 디지털화(Digitalization) → 에이전시(Agency)
② 디지털화(Digitalization) → 연결(Connection) → 에이전시(Agency)
③ 에이전시(Agency) → 연결(Connection) → 디지털화(Digitalization)
④ 연결(Connection) → 에이전시(Agency) → 디지털화(Digitalization)
정답 ② 디지털화 → 연결 → 에이전시

해설

데이터 기반 가치 패러다임은 먼저 현실의 정보를 디지털화하고, 만들어진 데이터들을 연결한 뒤, 연결된 데이터를 바탕으로 시스템이 스스로 판단·행동하는 에이전시 단계로 발전합니다.

Digitalization
데이터로 만든다
→
Connection
데이터를 연결한다
→
Agency
시스템이 판단·행동한다
보기판단오답 해설
① 연결 → 디지털화 → 에이전시오답데이터를 연결하려면 먼저 현실 정보가 디지털 데이터로 전환되어 있어야 한다.
② 디지털화 → 연결 → 에이전시정답정보를 데이터로 만들고, 데이터를 연결한 뒤, 시스템이 자율적으로 판단·행동하는 순서다.
③ 에이전시 → 연결 → 디지털화오답에이전시는 가장 발전된 단계이므로 데이터 생성과 연결보다 먼저 올 수 없다.
④ 연결 → 에이전시 → 디지털화오답디지털화가 선행되어야 연결과 에이전시 기능이 가능하다.
암기: 데이터로 만든다 → 데이터를 연결한다 → 시스템이 행동한다
