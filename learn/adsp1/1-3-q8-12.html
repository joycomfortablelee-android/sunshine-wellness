② NoSQL = 모양이 다른 카드 상자 🗂️

모든 정보를 꼭 똑같은 칸에 맞출 필요가 없습니다. 데이터의 종류와 쓰임에 따라 더 유연한 방식으로 담을 수 있습니다.

③ 그러면 왜 MySQL이 정답일까요?

MySQL은 ‘반듯한 표’를 중심으로 데이터를 관리하는 RDBMS입니다. 반면 MongoDB, HBase, Couchbase는 이 문제에서 NoSQL 데이터베이스로 분류됩니다. 따라서 “NoSQL이 아닌 것”을 찾으면 ③ MySQL입니다.

1
문제에서 “NoSQL이 아닌 것”을 찾으라고 했는지 확인합니다.
2
MySQL을 보면 먼저 “표와 관계 중심의 관계형 DB”를 떠올립니다.
3
MongoDB · HBase · Couchbase는 NoSQL 쪽에 두고, MySQL만 반대편에 둡니다.
딱 한 문장으로: “MySQL = 관계형 DB(RDBMS) → NoSQL이 아니다.”
그림의 ⑤ ‘NoSQL & SQL’ 중 NoSQL 부분이 Q10과 직접 연결됩니다. 오른쪽 설명에서 “표처럼 정리하는 RDBMS”와 “유연하게 담는 NoSQL”을 먼저 구분한 뒤 문제를 풀어보세요.

① RDBMS = 관계형 DBMS

Relational Database Management System · 관계형 데이터베이스 관리 시스템

표(Table)와 표 사이의 관계(Relation)를 중심으로 관리합니다. 이 문제 범위에서는 아래 다섯 개를 한 묶음으로 기억하면 됩니다.

Oracle
MySQL

② ODBMS = 객체지향 DBMS

Object-Oriented Database Management System · 객체지향 데이터베이스 관리 시스템

프로그램에서 사용하는 객체(Object) 개념을 중심으로 데이터를 저장·관리합니다. 이름 자체에 Object 힌트가 보이는 경우가 많습니다.

ObjectDB → 이름에 바로 Object가 보임 → 객체지향 DBMS
db4o → database for objects → 4 = for, o = objects
“Object가 보이면 객체형”
ObjectDB · db4o → ODBMS

시험장에서 3초 풀이

  1. ObjectDB, db4o가 보이면 → 먼저 객체지향 DBMS 칸에 넣습니다.
  2. Oracle, MySQL, SQL Server, PostgreSQL, DB2는 → 관계형 DBMS 묶음으로 기억합니다.
  3. 결국 문제는 “어느 묶음에 속하느냐”만 확인하면 됩니다.
한 줄 암기: “오–마–마–포–디는 관계형, Object 친구들은 객체형.”
개념 연결: RDBMS의 R은 Relational(관계형), ODBMS의 O는 Object-Oriented(객체지향)를 뜻합니다.
주의: 이 암기법은 첨부된 학습 범위의 대표 제품을 빠르게 구분하기 위한 시험용 기억법입니다.

DDL

Data Definition Language
데이터 정의어
데이터를 담을 ‘틀’을 만들거나 바꾸거나 없애는 명령어입니다.

DML

Data Manipulation Language
데이터 조작어
만들어진 틀 안의 실제 데이터 내용을 조회·추가·수정·삭제하는 명령어입니다.
SELECT데이터 조회하기
INSERT새 데이터 넣기
UPDATE데이터 수정하기
DELETE데이터 삭제하기

DCL

Data Control Language
데이터 제어어
누가 무엇을 할 수 있는지를 통제하고, 그림에서는 작업의 확정·취소 명령도 함께 제시합니다.
GRANT권한 주기
REVOKE권한 회수하기
COMMIT작업 확정하기
ROLLBACK작업 되돌리기
DDL = 서랍장 만들기서랍의 칸과 구조를 정한다.
DML = 서랍 속 물건 다루기찾고, 넣고, 바꾸고, 뺀다.
DCL = 서랍 사용 통제누가 열 수 있는지 권한을 정한다.
한 줄 암기: DDL = 틀 · DML = 내용 · DCL = 통제
※ 이 화면은 첨부된 그림의 분류를 기준으로 설명했습니다. 그림에서는 SELECT를 DML에, COMMIT·ROLLBACK을 DCL에 함께 제시하고 있습니다.
시험에서 가장 빠른 구분: CREATE가 보이면 DDL / SELECT·INSERT·UPDATE·DELETE가 보이면 DML / GRANT·REVOKE가 보이면 DCL
Q11 연결: UPDATE · SELECT · INSERT · DELETE는 모두 DML. CREATE만 구조를 만드는 DDL이다.

정답 ① ERP
ERP(Enterprise Resource Planning)는 재무·인사·생산·구매·재고 등 기업의 자원을 통합적으로 관리하여 경영 효율성을 높이는 정보시스템이다.
약어는 “무엇을 통합·관리하는가?”로 구분
ERP Enterprise Resource Planning 전사적 자원 관리 회사 전체의 인사·회계·생산·구매·재고 등을 하나로 통합 관리
EAI Enterprise Application Integration 기업 애플리케이션 통합 회사 안의 서로 다른 시스템·프로그램을 서로 연결
CRM Customer Relationship Management 고객 관계 관리 고객 정보·구매 이력·상담 기록 등을 관리
RFID Radio Frequency Identification 무선 주파수 식별 전파로 태그를 읽어 상품·사람·물건 등을 자동 식별·추적
한눈에 암기: ERP = 회사 전체 · EAI = 시스템 연결 · CRM = 고객 · RFID = 무선 태그
문제 키워드: “기업 전체 + 경영 자원 + 통합” = ERP
빠른 구분: 고객 = CRM / 시스템 연결 = EAI / 태그·추적 = RFID
