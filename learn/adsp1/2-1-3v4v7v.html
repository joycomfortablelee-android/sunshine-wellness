빅데이터의 이해｜3V → 4V → 7V

시험에서는 “빅데이터가 무엇인가?”보다 어떤 관점의 정의인지, V가 무엇을 의미하는지를 비교하는 문제가 자주 출제됩니다.

출제 포인트
2025년에는 관련 문항이 2문제 출제. 정의의 관점과 3V·4V·7V의 차이를 구분해 두는 것이 핵심입니다. ※ 원문 OCR의 ‘3W’는 문맥상 3V로 보는 것이 타당합니다.

빅데이터 정의는 ‘범위’가 점점 넓어진다

  • 데이터의 양이 많아짐
  • 형태가 다양해짐
  • 생성·처리 속도가 빨라짐

DATA + TECH

처리·분석 기술까지 포함

  • 대규모 데이터 처리
  • 분석기술 및 아키텍처
  • 고속 수집·발굴·분석
핵심: 기술 변화
넓은 범위의 정의
DATA + TECH + PEOPLE

3V · 4V · 7V를 관광 사례로 완전히 이해하기

구분 쉽게 말하면 관광 사례
3V 데이터가 많고·다양하고·빠르다 관광객의 검색기록, 예약정보, 위치정보, SNS 사진·후기 등이 엄청나게 많이, 다양한 형태로, 실시간 생성됨
4V 그 데이터를 활용해 가치를 만든다 데이터를 분석해서 “이 관광객에게 어떤 숙소·맛집·관광지를 추천하면 예약할 가능성이 높은가?”를 예측
7V 가치뿐 아니라 데이터가 믿을 만한지·정확한지·언제까지 쓸 수 있는지까지 본다 가짜 리뷰인지, 위치정보가 정확한지, 3개월 전 숙박가격을 지금도 써도 되는지 등을 점검

1. 3V = “데이터 자체가 어떤가?”

예를 들어 안동 관광 플랫폼이 있다고 해보겠습니다.

Volume 볼륨 · 양/규모
하루에 관광객 10만 명이 검색·예약·결제·이동 기록을 남깁니다.
“데이터가 엄청 많다.”
핵심 질문
데이터가 얼마나 많은가?
Variety 버라이어티 · 다양성
데이터가 한 종류가 아닙니다.
숙박 예약 데이터 카드 결제 데이터 GPS 위치 데이터 SNS 글 관광객 사진·영상 블로그 후기
“숫자만 있는 게 아니라 글·사진·영상·위치정보까지 다양하다.”
핵심 질문
데이터 형태가 얼마나 다양한가?
Velocity 벌라서티 · 속도
관광객이 지금 어디에 있는지, 어떤 숙소를 검색하는지 데이터가 계속 실시간으로 들어옵니다.
“데이터가 매우 빠르게 생성되고 처리된다.”
핵심 질문
얼마나 빠르게 들어오고 처리되는가?

정리: 3V는 데이터의 성격 자체를 설명합니다.

2. 4V = “그래서 이걸 어디에 쓰는데?”

3V에 Value(가치)를 더합니다.

관광객 A의 데이터

20대 안동 방문 카페 검색이 많음 한옥 숙소 검색 야간관광 검색
플랫폼이 분석 후 판단합니다.
“이 관광객에게 하회마을 + 한옥숙박 + 월영교 야경 + 카페를 추천하자.”

관광객은 원하는 정보를 쉽게 얻고, 관광사업자는 예약을 더 받을 수 있습니다.

3V는 “데이터가 많다”까지, 4V는 “그 데이터로 돈이나 편익을 만든다”까지입니다.

3. 7V = “그 데이터, 진짜 믿어도 돼?”

여기서부터는 데이터 품질과 관리가 중요해집니다.

Veracity 버래서티 · 진실성/신뢰성
어떤 식당의 별점이 4.9점인데, 리뷰 100개 중 60개가 광고업체가 만든 가짜 리뷰라면?
“이 데이터가 믿을 만한가?”
가짜 리뷰인가? 조작된 SNS 게시물인가? 중복 데이터인가?

“이 데이터가 분석 목적에 맞게 정확한가?”
위치가 정확한가? 나이가 잘못 입력되지 않았는가? 숙박일자가 정확한가?

7V 영어 의미 · 한글 발음 · 핵심 질문

7V 영어 의미 한글 의미 영어 발음 핵심 질문
Volume amount of data 데이터의 양·규모 볼-륨 데이터가 얼마나 많은가?
Variety different types of data 데이터의 다양성 버-라이-어-티 데이터 형태가 얼마나 다양한가?
Velocity speed of data generation and processing 데이터의 생성·처리 속도 벌-라-서-티 데이터가 얼마나 빠르게 들어오고 처리되는가?
Value useful value created from data 데이터가 만들어내는 가치 밸-류 이 데이터로 어떤 편익이나 이익을 만들 수 있는가?
Veracity trustworthiness of data 데이터의 진실성·신뢰성 버-래-서-티 이 데이터를 믿을 수 있는가?
Validity whether data is valid and appropriate 데이터의 유효성·정확성 벌-리-더-티 이 데이터가 분석 목적에 맞고 정확한가?
Volatility how quickly data changes / how long it remains useful 데이터의 변동성·휘발성 발러-틸-러-티 이 데이터는 얼마나 빨리 변하며 언제까지 유효한가?
3V = 많고(Volume), 다양하고(Variety), 빠르다(Velocity)
4V = 거기에 가치(Value)를 만든다.
7V = 그리고 믿을 수 있는지(Veracity), 유효한지(Validity), 얼마나 빨리 변하는지(Volatility)까지 본다.
Veracity“믿어?”
Validity“맞아?”
Volatility“안 변했어?”

대표 정의 비교: 무엇에 초점을 두는가?

McKinsey (2011)
일반적인 데이터베이스 소프트웨어로 저장·관리·분석할 수 있는 범위를 넘어서는 규모의 데이터
초점: 데이터 규모
IDC (2011)
다양한 대규모 데이터에서 저렴한 비용으로 가치를 추출하고, 초고속 수집·발굴·분석을 지원하는 차세대 기술 및 아키텍처
초점: 기술·비용·분석
Mayer-Schönberger & Cukier
대용량 데이터로 새로운 통찰과 가치를 추출하고, 시장·기업·시민·정부의 관계 등 여러 영역에 변화를 가져오는 것
초점: 가치·사회적 변화

McKinsey = “너무 커서 기존 DB로는 어렵다”

시험에서 ‘데이터의 규모’를 묻는 표현이 나오면 McKinsey 정의와 가장 가깝습니다.

IDC = “기술과 아키텍처로 빠르고 저렴하게 가치 추출”

초고속 수집·발굴·분석, 차세대 기술, 아키텍처, 비용이 핵심어입니다.

Mayer-Schönberger & Cukier = “새로운 통찰과 변화”

데이터 규모 자체보다 새로운 가치와 사회·조직의 변화에 더 넓게 초점을 둡니다.
