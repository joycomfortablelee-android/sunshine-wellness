LECTURE NOTE 01

12개 도시를 보는 공통 렌즈

발표를 다시 외우는 자료가 아니라, 서로 비교하면서 기억하는 강의노트

공통 공식지역 관광문제 → 스마트 기술·데이터 → 서비스·플랫폼 → 관광객 행동 변화 → 지역 가치 → 운영·지속가능성

A. 모든 도시에서 반드시 찾을 7가지 질문

학생이 던질 질문

B. 공통 틀은 같게, 발표의 차이는 남긴다

약 70% 공통
  • 같은 질문 순서
  • 도시 간 비교 가능
  • 학기말 12장만 펼쳐도 복습 가능
약 30% 고유
  • 발표자가 선택한 분석 렌즈
  • 특이한 도식·사례·비판 관점
  • “이 발표가 특히 본 것” 박스로 보존
읽는 법: 도시 이름을 외우기보다 “문제–기술–경험 변화”의 연결을 찾는다.
