오늘은 데이터 마이닝, 텍스트 마이닝, 머신러닝, 딥러닝을 한 번에 구분해보겠습니다. 먼저 크게 보면 데이터에서 패턴을 찾는 쪽과, 컴퓨터가 데이터를 학습하는 쪽으로 나눌 수 있습니다. 중요한 것은 이 네 개가 완전히 따로 떨어진 개념이 아니라 실제 분석에서는 서로 겹쳐 사용된다는 점입니다.
오늘은 네 가지 개념을 따로 외우기보다 서로 어떻게 연결되는지부터 보겠습니다. 왼쪽은 데이터에서 패턴을 찾는 관점이고, 오른쪽은 컴퓨터가 데이터를 보고 규칙을 학습하는 관점입니다. 실제 분석에서는 이 두 영역이 자주 함께 사용됩니다.

Text Mining
텍스트 마이닝		글·문서·리뷰 같은 비정형 텍스트에서 정보를 발견데이터 마이닝의 텍스트 분야
Machine Learning
머신러닝		컴퓨터가 데이터로부터 규칙을 학습학습 방법
Deep Learning
딥러닝		여러 층의 인공신경망을 이용하는 머신러닝머신러닝의 하위 분야
핵심: 데이터 마이닝과 텍스트 마이닝은 “무엇을 분석하고 무엇을 발견하는가”에 가깝고, 머신러닝과 딥러닝은 “어떻게 학습시킬 것인가”에 가깝습니다.
네 개념을 가장 쉽게 구분해보겠습니다. 데이터 마이닝은 많은 데이터에서 의미 있는 패턴을 찾는 분석 과정이고, 텍스트 마이닝은 그중에서 글이나 리뷰 같은 텍스트를 대상으로 합니다. 머신러닝은 컴퓨터가 데이터에서 규칙을 학습하는 방법이고, 딥러닝은 그 머신러닝 중에서도 여러 층의 신경망을 사용하는 방식입니다.
이 네 가지는 역할로 나누면 훨씬 쉽습니다. 데이터 마이닝은 패턴을 찾는 것, 텍스트 마이닝은 텍스트를 분석하는 것, 머신러닝은 데이터를 통해 규칙을 학습하는 것, 딥러닝은 그 학습을 여러 층의 신경망으로 하는 것이라고 기억하면 됩니다.

Text Mining → 데이터 마이닝 중에서도 텍스트를 대상으로 하는 분석

AI → ML → DL은 비교적 명확한 포함관계이고, Data Mining ↔ Machine Learning은 실제 분석에서 많이 겹칩니다.
포함관계는 여기서 꼭 기억해 주세요. 인공지능 안에 머신러닝이 있고, 머신러닝 안에 딥러닝이 있습니다. 반면 데이터 마이닝과 머신러닝은 완전히 상하관계라기보다 실제 연구에서 서로 많이 겹칩니다. 그래서 하나의 연구에 데이터 마이닝과 머신러닝이 동시에 등장할 수 있습니다.
AI 안에 머신러닝이 있고, 머신러닝 안에 딥러닝이 있다는 관계는 비교적 분명합니다. 반면 데이터 마이닝과 머신러닝은 완전히 따로 떨어진 개념이라기보다 실제 분석에서 목적과 방법으로 서로 겹쳐서 사용된다고 이해하면 좋습니다.

3. 서로 만나는 지점

1 / 1
예: 호텔 리뷰 10만 건 분석 — 분석 목적과 방법을 함께 보기
분석 사례 분류 왜 이렇게 분류하는가? 대표 방법 / 프로그램
리뷰에서 자주 등장하는 단어 찾기 텍스트 마이닝 단어의 빈도와 중요도를 계산하는 작업으로, 별도의 학습 모델이 꼭 필요하지 않습니다. 빈도분석, TF-IDF
Orange, KH Coder, Python
리뷰를 긍정 / 부정으로 자동 분류 텍스트 마이닝 + 머신러닝 사람이 붙인 긍정·부정 정답(label)을 바탕으로 컴퓨터가 분류 규칙을 학습합니다. Logistic Regression, SVM
Orange, Python
BERT를 이용해 감성분석 텍스트 마이닝 + 딥러닝 BERT가 Transformer 기반의 다층 신경망을 사용하여 문장과 문맥 관계를 학습하기 때문입니다. BERT, KoBERT, KLUE-BERT
Python, Hugging Face, PyTorch
고객 데이터를 군집화하여 관광객 유형 발견 데이터 마이닝 + 머신러닝 정답 없이 데이터의 유사성을 학습해 비슷한 고객을 자동으로 묶는 비지도학습이기 때문입니다. K-means, Hierarchical Clustering
Orange, SPSS, Python
같은 “감성분석”이라도 사용하는 알고리즘에 따라 달라집니다. Logistic Regression·SVM을 쓰면 머신러닝, BERT·Transformer를 쓰면 딥러닝입니다.

기억: 머신러닝은 데이터에서 규칙을 학습하고, 딥러닝은 그 학습을 다층 인공신경망으로 수행합니다.
호텔 리뷰 10만 건을 분석한다고 생각해봅시다. 단어 빈도만 보면 텍스트 마이닝이고, 긍정과 부정을 자동으로 분류하도록 학습시키면 머신러닝이 들어갑니다. BERT로 문맥까지 학습하면 딥러닝이고, 고객을 비슷한 특성끼리 묶으면 비지도 머신러닝입니다. 즉 분석 목적과 사용하는 알고리즘을 함께 봐야 정확히 구분할 수 있습니다.
같은 호텔 리뷰라도 무엇을 하느냐에 따라 분석 이름이 달라집니다. 단어 빈도를 보면 텍스트 마이닝이고, 긍정과 부정을 자동 분류하면 머신러닝이 결합됩니다. BERT를 사용하면 Transformer 기반의 다층 신경망을 쓰기 때문에 딥러닝이라고 부릅니다.

4. 왜 이것은 텍스트 마이닝인가?

1 / 1
리뷰에서 자주 등장하는 단어 찾기

분석 논리

컴퓨터가 정답을 학습하거나 신경망을 훈련할 필요 없이, 텍스트 안의 단어 빈도와 중요도를 계산합니다.

호텔 리뷰
→
단어 분리
→
빈도 / TF-IDF
→
핵심 단어

예: 친절, 청결, 위치, 조식, 소음

분석 프로그램

Orange → Text Add-on
KH Coder
Python → pandas / scikit-learn
R → tidytext
빅카인즈 → 키워드·연관어 분석
학생에게: “단어가 몇 번 나왔는가?”를 보는 것은 기본적으로 텍스트 마이닝입니다.
리뷰에서 어떤 단어가 많이 나왔는지만 보는 경우를 생각해보겠습니다. 여기서는 컴퓨터가 정답을 학습할 필요가 없습니다. 단어를 나누고, 몇 번 나왔는지 혹은 얼마나 중요한지 계산하면 됩니다. 그래서 대표적인 텍스트 마이닝이라고 볼 수 있고, Orange나 KH Coder, Python 등으로 실습할 수 있습니다.
여기서는 리뷰 안에 어떤 단어가 많이 나오는지, 어떤 단어가 중요한지를 보는 데 초점이 있습니다. 컴퓨터가 정답을 학습하는 과정이 꼭 필요한 것은 아니기 때문에 기본적으로 텍스트 마이닝이라고 보면 됩니다.

머신러닝인 이유

사람이 일부 리뷰에 긍정 / 부정 정답(label)을 붙여주면 컴퓨터가 그 예시에서 분류 규칙을 학습합니다.

리뷰 + 정답
→
학습
→
분류 규칙
→

대표 알고리즘: Logistic Regression, SVM, Random Forest, Naive Bayes

분석 프로그램

Orange → Logistic Regression / SVM / Random Forest
Python → scikit-learn
R → caret / tidymodels
RapidMiner
Orange 예시 흐름 File → Corpus → Preprocess Text → Bag of Words → Logistic Regression / SVM → Test & Score → Predictions
이번에는 리뷰를 긍정과 부정으로 자동 분류한다고 해보겠습니다. 사람이 일부 리뷰에 긍정 또는 부정이라는 정답을 붙여주고, 컴퓨터가 그 예시를 통해 분류 규칙을 학습합니다. 이것이 지도학습입니다. Logistic Regression이나 SVM 같은 알고리즘을 사용하면 전형적인 머신러닝 분류 문제가 됩니다.
사람이 먼저 일부 리뷰에 긍정과 부정이라는 정답을 붙여주면 컴퓨터가 그 예시를 보고 분류 규칙을 배웁니다. 그리고 새로운 리뷰가 들어왔을 때 어느 쪽에 가까운지 예측합니다. 이렇게 정답을 보고 배우는 방식이 지도학습입니다.

6. 왜 BERT 감성분석은 딥러닝인가?

단어를 숫자 벡터로 바꾸고 별도의 분류 알고리즘이 학습합니다.

BERT 딥러닝

문장
→
Transformer
→
BERT
→
긍정·부정

BERT는 여러 층의 Transformer 신경망을 이용해 문맥 관계를 학습합니다.

예: “호텔은 정말 좋았는데 다시 가고 싶지는 않다.”
단어 빈도만 보면 “좋았다”가 강하게 보일 수 있지만, BERT는 문장 전체의 문맥을 고려하도록 설계된 딥러닝 모델입니다.

대표 모델

BERT · KoBERT · KLUE-BERT · KoELECTRA · RoBERTa

대표 프로그램

Python + Hugging Face Transformers
PyTorch / TensorFlow
Google Colab
BERT도 긍정과 부정을 분류할 수 있지만, 앞의 방법과 내부 구조가 다릅니다. BERT는 Transformer 기반의 여러 층 신경망을 이용해 단어 하나가 아니라 문장 안의 문맥 관계까지 학습합니다. 그래서 같은 감성분석이라도 BERT를 사용하면 딥러닝이라고 부릅니다. Python과 Hugging Face, PyTorch를 함께 사용하는 경우가 많습니다.
감성분석 자체가 곧 딥러닝이라는 뜻은 아닙니다. 같은 감성분석이라도 Logistic Regression이나 SVM을 쓰면 머신러닝이고, BERT처럼 Transformer 기반의 여러 신경망 층을 쓰면 딥러닝입니다. 결국 어떤 모델을 사용했는지가 기준입니다.

7. 왜 고객 군집분석은 머신러닝인가?

1 / 1
정답 없이 비슷한 고객을 스스로 묶는 비지도학습

머신러닝인 이유

“이 고객은 어떤 유형이다”라는 정답을 미리 주지 않습니다.

숙박비
체류일
식음료 지출
관광활동
→
유사도 계산
→
Cluster 1·2·3

대표 알고리즘: K-means, Hierarchical Clustering, DBSCAN

분석 프로그램

Orange → K-Means / Hierarchical Clustering
SPSS → K-Means / 계층적 군집분석
Python → scikit-learn
R → cluster / factoextra
연구자는 분석 결과를 보고 사후에 “고소비 장기체류형”, “저비용 단기체류형”처럼 군집의 의미를 해석합니다.
고객 군집분석은 정답을 미리 주지 않는다는 것이 핵심입니다. 숙박비, 체류일, 관광활동 같은 특성을 보고 비슷한 고객끼리 자동으로 묶습니다. 그래서 비지도학습에 해당하고, K-means가 대표적인 방법입니다. 분석이 끝난 뒤 연구자가 각 군집의 특징을 보고 고소비형, 장기체류형처럼 이름을 붙입니다.
군집분석은 미리 정답을 주지 않고 고객들의 특성이 얼마나 비슷한지를 보고 자동으로 묶습니다. 그래서 비지도학습에 해당합니다. 분석이 끝난 뒤에는 연구자가 각 군집의 특징을 보고 장기체류형이나 고소비형처럼 의미를 붙이게 됩니다.

8. 분석 목적과 분석 방법을 구분하자

1 / 1
가장 중요한 개념 구분
질문 분석 성격 방법 프로그램
어떤 단어가 많이 나왔나? 텍스트 마이닝 빈도, TF-IDF Orange, KH Coder, Python
이 리뷰는 긍정인가 부정인가? 텍스트 마이닝 + 머신러닝 Logistic, SVM Orange, Python
문맥까지 이해해서 감성을 판단할까? 텍스트 마이닝 + 딥러닝 BERT, Transformer Python, Hugging Face, PyTorch
비슷한 관광객을 자동으로 묶을까? 데이터 마이닝 + 머신러닝 K-means Orange, SPSS, Python
중요: “감성분석 = 딥러닝”이 아닙니다.
감성분석은 분석 목적이고, Logistic Regression을 쓰면 머신러닝, BERT를 쓰면 딥러닝입니다.
여기서 가장 중요한 구분은 분석 목적과 분석 방법입니다. 예를 들어 감성분석은 목적이고, 그 목적을 Logistic Regression으로 수행하면 머신러닝, BERT로 수행하면 딥러닝입니다. 따라서 감성분석 자체가 곧 딥러닝이라는 뜻은 아닙니다. 어떤 알고리즘을 사용했는지를 반드시 확인해야 합니다.
여기서 가장 중요한 것은 목적과 방법을 구분하는 것입니다. 감성분석은 무엇을 알고 싶은지에 대한 목적이고, Logistic Regression이나 SVM, BERT는 그 목적을 해결하기 위해 선택하는 방법입니다. 이 둘을 나눠 생각하면 개념이 훨씬 정리됩니다.

이 단원을 마친 뒤 학생이 할 수 있어야 하는 것
① 개념 구분
데이터 마이닝, 텍스트 마이닝, 머신러닝, 딥러닝의 차이를 설명할 수 있다.
② 포함관계 이해
AI → Machine Learning → Deep Learning의 관계를 설명할 수 있다.
③ 분석 목적과 방법 구분
감성분석·군집분석 같은 분석 목적과 BERT·SVM·K-means 같은 분석 방법을 구분할 수 있다.
④ 사례 판단
관광 리뷰·고객 데이터를 보고 적절한 분석 유형을 선택할 수 있다.
⑤ 프로그램 연결
Orange, SPSS, Python, Hugging Face 등이 어떤 분석에 적합한지 설명할 수 있다.
⑥ 결과 해석
분류·군집·감성분석 결과를 관광 의사결정과 연결하여 해석할 수 있다.

이 단원에서는 용어를 외우는 것보다 실제 사례를 보고 어떤 분석에 해당하는지 설명할 수 있는 것이 중요합니다. 관광 데이터 상황을 보고 적절한 분석 방법과 프로그램까지 연결할 수 있으면 핵심을 이해한 것입니다.

12. 반드시 기억할 것

1 / 1
시험·발표·실습 전에 확인할 핵심 목록
1. 데이터 마이닝은 데이터에서 패턴과 지식을 발견하는 분석 활동이다.
2. 텍스트 마이닝은 리뷰·뉴스·SNS 등 비정형 텍스트를 분석한다.
3. 머신러닝은 데이터로부터 규칙을 학습하는 방법이다.
4. 딥러닝은 머신러닝의 하위 분야이며 다층 신경망을 사용한다.
5. AI → Machine Learning → Deep Learning은 비교적 명확한 포함관계다.
6. 감성분석은 분석 목적이다. 방법에 따라 머신러닝도, 딥러닝도 될 수 있다.
7. Logistic Regression·SVM은 대표적인 전통적 머신러닝 분류 방법이다.
8. BERT는 Transformer 기반 딥러닝 모델이다.
9. K-means는 정답 없이 유사한 대상을 묶는 비지도학습이다.
10. 실제 연구에서는 Text Mining + ML + DL이 서로 결합될 수 있다.
시험이나 실습 전에 이 목록만 다시 보셔도 좋습니다. 특히 감성분석은 목적이고 BERT는 방법이라는 점, K-means는 비지도학습이라는 점, 그리고 BERT는 Transformer 기반 딥러닝이라는 점을 꼭 기억하세요. 실제 분석에서는 여러 방법이 함께 사용될 수 있다는 것도 중요합니다.
여기 있는 내용은 최소한 기억해야 할 핵심입니다. 특히 감성분석은 목적이고 BERT는 방법이라는 점, 그리고 K-means가 정답 없이 묶는 비지도학습이라는 점은 꼭 기억해 두면 좋습니다.

이 표는 오늘 배운 내용을 한 장으로 압축한 것입니다. 개념 이름만 보지 말고 핵심 질문, 대표 방법, 프로그램, 관광 사례를 같이 연결해서 보세요. 예를 들어 텍스트 마이닝이라고 하면 리뷰나 뉴스, 머신러닝이라고 하면 분류와 군집, 딥러닝이라고 하면 BERT나 Transformer가 바로 떠오르면 됩니다.
이 표는 지금까지의 내용을 한 번에 정리한 것입니다. 개념 이름만 보지 말고 핵심 질문, 대표 방법, 프로그램, 관광 사례를 함께 보면 실제 분석에서 각각이 어디에 쓰이는지 훨씬 쉽게 연결할 수 있습니다.
