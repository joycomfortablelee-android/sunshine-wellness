09 · 만다라트 — 디자인씽킹 창의성 도구

Mandalart · 3×3 Matrix

아이디어 · 실행계획
개념·키워드절차·사례실습퀴즈강의 활용

01 · 개념과 핵심 키워드

한 문장 핵심 · 한 목표를 8개 영역과 구체 행동으로 확장하기

중앙 칸에 핵심 목표를 두고 주변 8칸에 관련 하위 주제를 배치하는 격자형 사고 도구이다. 하위 주제를 각각 새 3×3 격자의 중심으로 확장하면 8개 영역별 8개 행동, 총 64개 행동 후보를 정리할 수 있다. 81칸은 전체 격자 위치 수이며 서로 다른 81개 행동을 뜻하지 않는다.

02 · 활용 절차와 관광벤처 적용

중앙 목표→8개 영역→하위 격자→중복·누락 확인→선택→실행

01 · 중앙 목표

성과가 관찰 가능한 핵심 목표를 하나 쓴다.

관광 적용 · 지역 관광객이 체험 예약을 쉽게 하도록 돕기

02 · 8개 영역

목표에 필요한 서로 다른 영역을 주변에 놓는다.

관광 적용 · 고객조사 / 정보 / 예약 / 결제 / 파트너 / 홍보 / 운영 / 평가

03 · 하위 격자

각 영역을 별도 격자 중앙에 넣고 8개 행동 후보를 만든다.

관광 적용 · 예약 → 시간대, 인원, 취소, 확인, 알림, 오류복구, 대기, 접근성

04 · 중복·누락 확인

같은 행동을 합치고 영역의 균형을 확인한다.

관광 적용 · 예약 알림과 운영 알림은 담당·목적을 구분

05 · 선택

중요도·실행가능성으로 각 영역의 상위 행동을 고른다.

관광 적용 · 시간대 선택과 예약확인 화면부터 개발

06 · 실행

행동을 담당자·기한·지표로 변환한다.

관광 적용 · 팀원 A / 1주 / 예약 완료율 80% 목표 가설
도구 선택 시 주의 · 마인드맵이 자유로운 가지 구조인 반면 만다라트는 고정 격자로 균형과 실행계획을 돕는다.

03 · 학생 실습 워크시트

자신의 관광창업 아이디어에 적용하세요. 모든 항목은 직접 입력할 수 있습니다. 브라우저가 허용하면 입력이 자동 저장되며, 텍스트 파일로 내보낼 수 있습니다.

자동 3×3 만다라트 미리보기

04 · 학습 확인 퀴즈

만다라트에서 8개 하위 영역을 각각 8개 행동으로 확장하면 행동 후보는?

정답을 선택하면 해설이 표시됩니다.

05 · 교수자 강의 활용

디자인씽킹 연계: 아이디어 · 실행계획 단계에서 우선 활용. 앞 단계에서 얻은 사용자 증거를 입력으로 삼고, 도출한 결과는 다음 단계의 실험 가설로 연결한다.

20분 팀 활동 (권장)

3분 문제 정의 → 8분 도구 적용 → 5분 대안 비교 → 4분 발표
