01 · ERRC — 디자인씽킹 창의성 도구

Eliminate · Reduce · Raise · Create

아이디어 · 가치제안
개념·키워드절차·사례실습퀴즈강의 활용

01 · 개념과 핵심 키워드

한 문장 핵심 · 경쟁자가 제공하는 가치요소를 다시 설계하기

블루오션 전략의 Four Actions Framework를 실행하는 가치혁신 도구이다. 업계의 관행적 경쟁요소 중 불필요한 것은 제거하고 과도한 것은 줄이는 한편, 고객이 실제로 중요하게 느끼는 요소는 높이고 새로운 가치를 창조한다. 단순 비용절감이나 기능 추가가 아니라 고객가치와 비용 구조를 동시에 검토한다.

제거 Eliminate: 없앨 요소감소 Reduce: 기준보다 낮출 요소증가 Raise: 기준보다 높일 요소창조 Create: 업계에 없던 가치가치혁신 Value Innovation

E 제거

중복 가입 → 없애기

R 감소

긴 설명 → 핵심만

R 증가

다국어 정보 → 강화

C 창조

일정·이동 동행 안내 → 신규 가치

02 · 활용 절차와 관광벤처 적용

고객과 비교 대상 정의→제거 E→감소 R→증가 R→창조 C→가치곡선·검증

01 · 고객과 비교 대상 정의

고객군과 기존 대안 2~3개를 정하고 인터뷰·후기에서 가치요소를 뽑는다. 가격, 접근성, 예약, 정보, 체험을 같은 기준으로 비교한다.

관광 적용 · 개별 외국인 관광객의 안동 역사관광 예약 경험

02 · 제거 E

고객이 낮게 평가하며 운영비를 유발하는 요소 중 없애도 되는 것을 고른다. 필수 안전·법적 의무는 제거하지 않는다.

관광 적용 · 중복 회원가입 절차 제거

03 · 감소 R

기존 서비스가 과잉 제공하는 요소를 줄이고 줄일 수준을 정한다.

관광 적용 · 긴 설명문을 3줄 핵심 요약으로 줄이기

04 · 증가 R

고객 불편을 직접 해소하는 요소를 기존보다 높인다.

관광 적용 · 다국어 환승 안내와 업데이트 빈도 높이기

05 · 창조 C

현재 대안에 부족한 새로운 경험을 제안한다.

관광 적용 · 일정·교통·현장 해설을 연결하는 여행 동행 안내

06 · 가치곡선·검증

각 요소의 제공수준을 1~5로 비교하고 개발비·고객 반응을 검증한다. 높은 가치와 낮은 비용의 가설을 기록한다.

관광 적용 · 예약완료율과 정보 탐색시간을 기존 방식과 비교
도구 선택 시 주의 · SCAMPER가 개별 아이디어의 변형에 유용하다면 ERRC는 경쟁 대안과 고객가치 전체의 재설계에 초점을 둔다.
