2. Python 데이터분석 관련 자격증

자격증 정식 명칭 수준 Python 데이터분석 연관성 자격 성격
PCED Certified Entry-Level Data Analyst with Python 입문 ★★★★★ 국제 민간자격
PCAD Certified Associate Data Analyst with Python 중급 ★★★★★ 국제 민간자격
PCEP Certified Entry-Level Python Programmer 입문 ★★★ 국제 민간자격
ADsP 데이터분석 준전문가 입문~중급 ★★★ 국내 데이터 자격
빅데이터분석기사 Big Data Analysis Engineer 중급 이상 ★★★★★ 국가기술자격

PCED

Certified Entry-Level Data Analyst with Python으로, Python을 활용한 입문 데이터분석 자격에 가장 가깝습니다.

데이터 이해→ Python 기초→ 데이터 불러오기→ 정리·전처리→ 기초 분석→ 결과 설명·보고
ADsP: “데이터 분석 방법을 알고 있는가?”
PCED: “Python을 이용해 데이터를 다루는 기본 능력이 있는가?”

PCAD

PCED 다음 단계로, Python 기반 데이터분석을 좀 더 본격적으로 다룹니다.

데이터 수집→ 전처리→ Python→ SQL→ 통계분석→ 모델링→ 시각화

주요 범위에는 pandas, NumPy, 통계, SQL, 선형회귀·로지스틱회귀, 훈련/테스트 데이터 분할, 과적합, Matplotlib 등이 포함됩니다.

PCEP

Python 프로그래밍 기초 자격으로, 변수·자료형·리스트·딕셔너리·조건문·반복문·함수·예외처리 등을 평가합니다. 데이터분석 자격증은 아니므로 데이터분석 목적이라면 PCEP보다 PCED가 더 직접적입니다.

3. ADsP 시험 성격

ADsP는 데이터 분석의 이론·개념·통계적 사고를 보는 입문형 자격입니다.

과목문항 수문항 비중성격
데이터 이해1020%개념·암기
데이터분석 기획1020%개념·방법론
데이터분석3060%통계·분석 핵심

총 50문항, 90분, 실기 없음. 2024년부터 단답형이 폐지되어 현재는 전 문항 객관식입니다.

현실적인 준비기간

대상예상 공부기간
통계·연구 경험 있음1~2주
비전공자·노베이스3~4주

위 준비기간은 공식 기준이 아니라 시험 범위와 일반적인 학습량을 고려한 현실적 추정치입니다.

4. 사회조사분석사 2급

사회조사분석사 2급은 설문조사 · 조사방법론 · 통계분석 · SPSS · 사회과학 연구에 강한 국가기술자격입니다.

필기

과목문항 수
조사방법과 설계30
조사관리와 자료처리30
통계분석과 활용40

총 100문항, 150분

실기

구분내용배점/시간
필답형설문작성, 조사방법론, 서술형60점 / 2시간
작업형통계 프로그램을 활용한 자료처리 및 분석40점 / 약 2시간
ADsP: 공부 → 필기 한 번 → 합격
사회조사분석사 2급: 필기 공부 → 필기 합격 → 실기 공부 → 필답형 + 작업형 → 최종합격

현실적인 공부기간

구분통계·연구 경험 있음처음 공부
필기1~2주3~4주
실기2~3주3~5주
전체 공부량3~5주6~9주

공부시간과 실제 자격 취득까지의 달력상 기간은 다릅니다. 필기와 실기 시험일정 사이 간격 때문에 최종합격 발표까지는 수개월이 걸릴 수 있습니다.
