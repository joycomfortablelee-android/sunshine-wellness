수식보다 먼저 뜻을 기억하세요.
연속형 예측Continuous prediction

가격·매출·방문객 수처럼 숫자 자체를 예측하는 문제예요.

실제값 yActual value

실제로 관측된 정답이에요. 예: 실제 방문객 12명.

예측값 ŷPredicted value

모델이 예상한 숫자예요. 예: 방문객 10명으로 예측.

오차 e = y − ŷPrediction error

정답과 예측의 차이예요. 12 − 10 = +2입니다.

절댓값 |e|Absolute value

방향은 무시하고 거리만 봐요. +3과 −3은 모두 3이에요.

제곱 e²Squared error

오차를 자기 자신과 곱해요. 3² = 9로 큰 실수를 강조해요.

평균 · nMean · sample size

전체를 더하고 데이터 개수 n으로 나눠요. 이 문제에서 n = 3.

오차 상쇄Error cancellation

+3과 −3을 더하면 0이 돼요. 실제로 틀렸어도 부호가 서로 지울 수 있어요.

백분율 오차Percentage error

실제값에 비해 몇 %나 틀렸는지를 나타내요. 실제값 0에서는 MAPE 계산에 주의해요.

오차가 커지면, 제곱 면적은 얼마나 더 빨리 커질까?

아래 슬라이더를 움직여 보세요. 같은 오차를 MAE는 가로 칸의 길이로, MSE는 정사각형의 면적으로 다룹니다.

16
MAE에서 사용하는 |오차|3칸

크기가 3인 오차는 길이 3칸

MSE에서 사용하는 오차²9칸

크기가 3인 오차는 면적 3 × 3 = 9칸

오차가 3이면 절댓값은 3, 제곱값은 9입니다. 큰 오차일수록 제곱값이 더 빠르게 증가합니다.
※ 길이와 면적은 서로 다른 표현입니다. 이 그림은 같은 오차를 다루는 방식의 차이를 설명하며, MAE 수치와 MSE 수치를 같은 단위로 직접 비교하는 뜻은 아닙니다.

각 지표의 핵심 질문

SSE · 오차 제곱을 총 얼마만큼 쌓았나?

AE · 평균적으로 낮게 또는 높게 예측하나?

MSE · 큰 실수에 더 강하게 벌점을 주면?

유사한 지표 구별하기

MAE · 실제값과 보통 얼마나 떨어져 있나?

RMSE · 큰 실수를 강조하면서 원래 단위로 보면?

MAPE · 실제값의 몇 % 정도를 틀렸나?

시험 암기: MSE = 제곱 → 평균 / RMSE = MSE → 제곱근 / MAE = 절댓값 → 평균. 모든 경우에 값이 무조건 작을수록 좋은 것은 아닙니다. 예를 들어 AE는 0이라도 큰 양·음 오차가 상쇄됐을 수 있습니다.

4컷 개념 이야기 · 왜 '제곱한 뒤 평균'일까요?

1컷 · 예상하기
“10개일 줄 알았는데 실제로는 12개였네!”

실제값 12, 예측값 10이라서 오차는 +2.

2컷 · 부호 확인
“둘째는 3개나 더 예상했어!”

25 − 28 = −3. 부호가 달라도 모두 예측의 실수.

3컷 · 모두 제곱
“2², (−3)², 2² = 4, 9, 4!”

제곱하면 음수도 양수로 바뀌며 큰 오차가 더 커짐.

4컷 · 평균으로 정리
“총 17점을 3개로 나눠!”

오차제곱합 17 ÷ 관측치 3 = MSE 5.67.

기억할 문장: MSE는 실제값과 예측값을 빼고 → 제곱하고 → 더한 뒤 → 데이터 개수로 나눕니다.
