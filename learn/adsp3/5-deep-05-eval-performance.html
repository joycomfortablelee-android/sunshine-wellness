재현율(Recall): 실제 구매자 중 얼마나 찾았나?
분모 = 실제 Positive = TP + FN
정밀도(Precision): 구매한다고 예측한 사람 중 실제 몇 명?
분모 = 예측 Positive = TP + FP
시험 포인트 FP = 제1종 오류(Type I), FN = 제2종 오류(Type II)로 연결할 수 있습니다(음성을 귀무상태로 둘 때). FPR = 1 − 특이도입니다.

해석 상위 10% 고객은 전체 고객을 무작위로 뽑았을 때보다 약 4.57배 높은 구매반응률을 보입니다.

상위 20%에만 집중한다면?

74.5%

상위 400명에서 구매자 284명 포착 → 전체 구매자 381명 중 74.5% 확보

상위 20% 누적 반응률 = 284/400 = 71.0% / 누적 Lift = 71.0% ÷ 19.05% ≈ 3.73배

주의: Lift는 0~1의 점수가 아니라 배수입니다. 상위 순위에서 Lift가 높은 편이 바람직하지만, 모든 구간이 반드시 단조 감소할 필요는 없습니다.전체 기준 반응률 = 381 / 2,000 = 19.05%

과소적합과 과대적합: 단순해도, 복잡해도 문제

핵심은 학습 데이터의 점수를 높이는 것이 아니라 처음 보는 데이터에도 통하는 패턴을 배우는 것입니다.

개별 표본까지 외움

07 · TOURISM EXAMPLES 교재 385–390쪽 · PDF 8–13p

관광 실무에 적용하면 지표 선택이 쉬워집니다

같은 “양성 예측”이라도 실제 손실 구조가 다르면 우선 지표가 달라집니다.

교재 개념을 응용한 자체 사례
사례 A · 숙박 노쇼 예측

“노쇼할 고객을 미리 찾는 모델”

Positive = 노쇼 발생

FN(놓침): 실제 노쇼인데 정상 체크인이라고 예측 → 빈 객실 대응 기회 상실.
FP(오경보): 정상 체크인할 고객에게 불필요한 확인 연락.

재현율 우선 여부는 놓친 노쇼의 손실과 불필요한 연락의 비용을 비교하여 결정해야 합니다.

주요 판단: Recall · Precision · 기대비용
사례 B · 관광상품 구매 가능성

“한정된 쿠폰을 누구에게 보낼까?”

Positive = 관광상품 구매

고객 예산이 제한됨: 확률 상위 10%의 반응률과 Lift를 우선 확인.
상위 집단 선택: 실제 구매자를 얼마나 많이 포착했는지 Capture도 검토.

단, 실제 마케팅 증분효과(Uplift)는 Lift와 다릅니다. 구매 가능성이 높아도 쿠폰이 구매를 추가로 유발했는지는 별도 검증이 필요합니다.
