과적합 Overfitting

연습문제의 숫자와 정답까지 외워, 조금 다른 새 문제에는 약해진 상태.

일반화 Generalization

처음 보는 문제나 자료에도 배운 규칙을 잘 적용하는 능력.

정규화 회귀 Regularized Regression

회귀계수가 너무 커지지 않게 벌점을 주어 모형의 복잡성을 조절하는 방법.

회귀계수 Coefficient · β

한 변수가 예측값에 얼마나, 어느 방향으로 관련되는지 나타내는 숫자.

페널티 Penalty

모형이 너무 복잡해지지 않도록 큰 계수에 부과하는 ‘벌점’.

규제 강도 λ Lambda

벌점의 세기를 조절하는 손잡이. 커질수록 계수를 더 강하게 줄이려 함.

릿지 회귀 Ridge · L2

계수의 제곱을 합해 벌점. 대체로 계수를 모두 조금씩 줄임.

라쏘 회귀 Lasso · L1

계수의 절대값을 합해 벌점. 불필요한 변수의 계수가 0이 될 수 있음.

엘라스틱 넷 Elastic Net

L1과 L2를 함께 사용해 계수 축소와 변수 선택을 절충함.

교차검증 Cross-validation

자료를 나누어 여러 번 시험하며 규제 강도와 예측 성능을 살펴봄.

구별! 여기서 ‘정규화’는 회귀계수에 벌점을 주는 규제(Regularization)입니다. 변수의 단위를 맞추는 표준화(Standardization)와는 다른 개념입니다.

04 · OBJECTIVE FUNCTION

정규화의 계산 원리: 오차 + 벌점

정규화는 손실을 작게 만드는 동시에 회귀계수가 과도하게 커지는 것을 억제합니다.

교재 p.310
최소화 문제

일반 회귀 → 정규화 회귀

일반 최소제곱: 예측오차의 제곱합을 작게 합니다.

Loss = (1 / 2n) Σ (yᵢ − ŷᵢ)²

정규화: 여기에 계수의 크기에 따른 벌점을 더합니다.

Objective = Loss + λ × Penalty
λ (람다)는 규제 강도입니다. λ가 0이면 규제하지 않고, 커질수록 작은 계수를 선호합니다.

통상 절편 β₀는 벌점 대상에서 제외합니다. 서로 다른 단위의 변수를 함께 사용할 때는 입력변수를 표준화한 뒤 적용하는 것이 일반적입니다.

직접 조절

λ를 움직이면 계수는 어떻게 바뀔까?

0.75
–Ridge |β| 합계
–Lasso |β| 합계
–Lasso에서 0인 계수
λ의 효과를 계산 중입니다.

아래의 네 계수는 설명을 위해 만든 예시입니다. 표준화되고 서로 직교하는 설명변수(XᵀX/n = I)를 가정해 실제 공식대로 계산합니다.

05 · RIDGE REGRESSION

Ridge 회귀 = L2: 제곱해서 벌점

계수가 클수록 제곱 벌점이 빠르게 커집니다. 일반적으로 모든 계수를 0에 가깝게 줄이지만 정확히 0으로 만들지는 않습니다.

교재 p.310
L2 Penalty

제곱합을 줄이는 규제

minβ [ Loss + (λ / 2) Σ βⱼ² ]
예를 들어 계수가 3이면 제곱 벌점은 9, 계수가 1이면 1입니다. 큰 계수에 더 강한 불이익을 줍니다.

원이 매끈하므로 최적점이 한 축 위(계수 0)에 정확히 놓이도록 유도하는 경향은 상대적으로 약합니다.

계수의 변화

Ridge는 전체 계수를 함께 축소

0.75

최소제곱 계수(규제 없음) OLS

Ridge 적용 후 L2

Ridge는 큰 계수까지 함께 줄입니다.

위의 직교·표준화 가정에서 β̂ⱼ(Ridge) = β̂ⱼ(OLS)/(1+λ)입니다.

06 · LASSO REGRESSION

Lasso 회귀 = L1: 절대값으로 벌점

Lasso는 계수를 0으로 만들 수 있어 변수 선택 효과가 있습니다. 48번 문제의 핵심 개념입니다.

교재 p.310 및 기출 48번
L1 Penalty

절대값 합을 줄이는 규제

minβ [ Loss + λ Σ |βⱼ| ]
계수가 3이면 절대값 벌점은 3, 계수가 −1이면 1입니다. 부호와 관계없이 크기에 벌점을 줍니다.

마름모의 꼭짓점이 축 위에 있으므로 최적점이 꼭짓점에 닿아 일부 계수가 정확히 0이 되기 쉽습니다.

변수 선택 시각화

작은 계수가 0이 되는 모습

0.75

규제 전 OLS

규제 후 Lasso

Lasso는 일부 회귀계수를 정확히 0으로 만듭니다.

위의 직교·표준화 가정에서 β̂ⱼ(Lasso) = sign(β̂ⱼ(OLS)) × max(|β̂ⱼ(OLS)| − λ, 0)입니다.

기출 48번: Lasso에 대한 부적절한 설명

정답을 바로 보지 말고, 4개 선택지 각각이 L1과 L2 중 어디에 해당하는지 생각해 보세요.

제공된 기출 48번
문제 48 · 정답 하나 선택

다음 중 Lasso 회귀모형에 대한 설명으로 부적절한 것은?

문제 직결 이론

두 규제를 먼저 그림으로 구분

L1 = Lasso절대값합 → 0 가능
L2 = Ridge제곱합 → 계수 축소
Lasso : Loss + λ Σ |βⱼ|
Ridge : Loss + (λ/2) Σ βⱼ²
기출 암기 공식: 라쏘 = L1 = 절대값 = 변수 선택 / 릿지 = L2 = 제곱 = 계수 축소

선택지별 해설 (정답 확인 버튼을 누르면 설명이 강조됩니다)

①
표현에 주의가 필요한 선택지 — Lasso의 벌점은 정확히 회귀계수의 절대값에 비례합니다. 원문 표현인 “회귀계수에 비례하여 가중치를 부여”는 엄밀한 정의가 아니므로 오해를 낳을 수 있습니다. 시험의 출제 취지에서는 적절한 것으로 취급합니다.
②
적절 — L1 규제로 일부 계수를 정확히 0으로 만들어 변수 선택 효과가 있습니다.
③
적절 — 벌점의 크기를 조절하는 하이퍼파라미터 λ가 있습니다.
④
부적절 · 정답 — Lasso는 L1을 사용하며, L2는 Ridge가 사용합니다.
정답은 ④. 다만 ①도 기술 방식이 모호하므로 “회귀계수 절대값에 비례하는 페널티를 부여한다”로 고쳐 표현하는 것이 통계적으로 더 정확합니다.
