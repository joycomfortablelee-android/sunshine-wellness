QUESTION 01

진화를 모방한 최적화 탐색 알고리즘

38회 기출
관련 문제
다음 중 생물 진화의 과정을 모방하여 근삿값에 가까운 해답을 도출하는 최적화 탐색 분류 분석 알고리즘은 무엇인가?
① 유전자 알고리즘(Genetic Algorithm)
② 심층 신경망(Deep Neural Network)
③ 의사결정나무(Decision Tree)
④ 랜덤 포레스트(Random Forest)
정답 ①

유전자 알고리즘은 자연 선택과 유전 법칙을 모방하여 최적화 문제를 해결하는 탐색 알고리즘이다. 심층 신경망은 복잡한 데이터 표현을 학습하는 데 사용되며, 의사결정나무와 랜덤 포레스트는 분류와 회귀 문제에 활용되지만 생물 진화 과정을 모방하지 않는다.

핵심 암기 · "생물 진화 모방"이라는 표현이 나오면 유전자 알고리즘

QUESTION 02

데이터 분할 설명으로 부적절한 것

38회 기출
관련 문제
데이터 분할에 대한 설명 중 가장 부적절한 것은 무엇인가?
① 테스트용 데이터와 학습용 데이터는 섞여서는 안된다.
② 학습용 데이터는 모델의 가중치를 조정하는 데 사용된다.
③ 테스트용 데이터는 모델 훈련 중간 모델의 성능 평가에 사용된다.
④ 데이터가 제한적인 경우, K-Fold 교차검증을 통해 다양한 학습-평가 조합을 활용한다.
정답 ③

테스트 데이터는 모델의 최종 평가에 사용되며 성능 평가에 사용되는 데이터는 학습 중간에 사용하는 검증용 데이터이다. 학습용 데이터는 모델 훈련에 사용되고, K-Fold 교차검증은 데이터가 제한적일 때 유용하다.

핵심 암기 · 학습 "도중" 평가 = 검증용 / 학습 "다 끝난 뒤" 최종 평가 = 시험용

QUESTION 03

민감도와 동일한 지표

19회 기출
관련 문제
오분류표(Confusion Matrix)를 사용하여 계산할 수 있는 평가 지표 중 민감도와 동일하며 모형의 완전성(Completeness)을 평가하는 지표는?
① F1 지표
② 정밀도(Precision)
③ 특이도(Specificity)
④ 재현율(Recall)
정답 ④

재현율은 실제로 양성인 데이터 중에서 모델이 양성으로 올바르게 예측한 비율로, 민감도와 동일한 개념이다. 정밀도는 양성으로 예측한 데이터 중에서 실제로 양성인 비율을 나타내며, F1 지표는 정밀도와 재현율의 조화 평균이다. 특이도는 음성인 데이터를 올바르게 음성으로 예측한 비율이다.

핵심 암기 · 민감도 = 재현율(Recall) — 이름이 둘이라 혼동 주의

QUESTION 04

오분류표로 특이도 계산

22회 기출
관련 문제
아래는 오분류표를 나타낸 것이다. 다음 중 특이도(Specificity)는 얼마인가?
실제값 TRUE: 예측 TRUE 30 / 예측 FALSE 70 (합계 100)
실제값 FALSE: 예측 TRUE 60 / 예측 FALSE 40 (합계 100)
① 3/10
② 4/10
③ 13/20
④ 7/11
정답 ②

특이도는 실제 음성(FALSE) 중에서 올바르게 FALSE로 예측한 비율이다. 실제값이 FALSE인 100명 중 모델이 FALSE로 예측한 경우는 40명이므로, 특이도 = 40/100 = 4/10이다.

핵심 암기 · 특이도 = 실제 FALSE행에서 "FALSE로 맞춘 비율"
