핵심 특징: 분할이 간단하고 계산이 빠르지만, 한 번의 분할 결과에 따라 성능 추정이 달라질 수 있습니다. 앞의 3집단 분할 역시 홀드아웃 방식으로 구성할 수 있습니다.

k-Fold 교차검증 k-Fold Cross-Validation

k번 교대 검증

데이터를 k개 구간(Fold)으로 나누고, 매 차례 k−1개는 학습, 1개는 검증에 사용합니다. 각 구간을 한 번씩 검증에 사용합니다.

접기 수 선택행을 누르면 해당 회차 강조
학습 구간 (k−1)검증 구간 (1)
5-Fold: 4개 구간 학습 + 1개 구간 검증을 5번 반복하고 평균합니다.
핵심 특징: 각 관측치를 검증에 활용하므로 데이터를 비교적 효율적으로 활용합니다. k번의 검증 결과를 평균하고, 필요하면 별도로 보관한 독립 시험 데이터로 최종 평가합니다.

🎯 학습 vs 검증 vs 시험

학습은 모형 구축 · 검증은 튜닝·선택 · 시험은 최종 평가. 특히 시험용 데이터는 중간 튜닝에 사용하지 않습니다.

🔁 홀드아웃 vs 교차검증

홀드아웃은 한 번 분할 · k-Fold는 k번 교대 검증 후 평균. 데이터가 제한적이면 교차검증이 유용합니다.

🔐 일반화 성능의 신뢰성

훈련·검증에서의 좋은 성능이 실제 새 데이터 성능을 보장하지는 않습니다. 독립 시험 데이터를 보존하고 평가에 한 번 사용하는 것이 중요합니다.

교재 이해를 위한 보충: ‘학습용 50%·검증용 30%·시험용 20%’는 가능한 분할 예시이며 유일한 비율은 아닙니다. k-Fold 교차검증은 주로 훈련 단계 내부의 모형 선택·성능 추정에 활용되며, 최종 독립 시험 평가와 역할이 구분됩니다.

문제 0517회 기출 · 홀드아웃

다음 중 데이터를 무작위로 두 집단으로 분리하여 실험데이터와 평가데이터로 설정하고 검정을 실시하는 모형 평가방법으로 적절한 것은?

정답 ③ 홀드아웃 방법

무작위로 두 집단으로 분리하고 한 집단으로 학습, 다른 집단으로 성능을 평가하므로 홀드아웃입니다. k-Fold는 k개 구간으로 나눠 순차적으로 검증합니다. ROC 그래프와 이익도표는 모형의 평가·시각화 도구이지 데이터 2분할 방식이 아닙니다.

🔑 암기 단서: '한 번·두 집단 분리' → 홀드아웃.

문제 0638회 기출 · 데이터 역할

데이터 분할에 대한 설명 중 가장 부적절한 것은 무엇인가?

정답 ③ · 가장 부적절한 설명

시험(Test) 데이터는 학습 중간이 아니라 최종 단계에서 독립적인 성능·일반화 능력을 평가할 때 사용합니다. 모형을 튜닝하거나 비교하는 중간 평가는 검증(Validation) 데이터나 교차검증 결과로 수행합니다.

🔑 암기 단서: '훈련 중간 평가' → 검증 / '최종 성능 평가' → 시험.
