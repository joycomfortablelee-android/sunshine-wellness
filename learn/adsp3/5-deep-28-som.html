교재 p.462 · 01 개요와 구성

고차원 데이터를 2차원 지도 위에 배열한다

SOM(Self-Organizing Map)은 Teuvo Kohonen(코호넨)이 개발한 비지도 신경망이다. 유사한 입력값을 지도에서 대체로 가까운 위치에 나타내도록 학습한다.

정의 자기조직화지도란?

고차원 데이터 → 저차원 격자 지도

정답 레이블 없이 데이터의 유사 패턴을 학습하여, 군집 구조를 공간적으로 시각화한다.

입력층 Input Layer (인풋 레이어)

  • 하나의 입력 벡터를 이루는 특성(변수)을 받는다.
  • 뉴런(입력 노드) 수는 일반적으로 입력 변수 수와 같다.
  • 입력 차원이 경쟁층의 각 뉴런과 연결된다.

경쟁층 Competitive Layer (컴페티티브 레이어)

  • 보통 2차원 격자(Grid)에 배치된 뉴런들로 구성.
  • 각 뉴런은 입력과 비교하는 가중치 벡터를 보유.
  • 가장 비슷한 뉴런을 BMU로 선택한다.

SOM 신경망 구조 개념도

Fully Connected
풀리 커넥티드 · 입력 차원마다 경쟁층의 모든 뉴런과 가중치 연결
Topological Map
토폴로지컬 맵 · 비슷한 패턴이 지도상에 이웃하도록 학습

※ 그림의 입력 노드 4개는 구조 설명을 위한 예시입니다. 실제 노드 수는 데이터의 특성 수에 따라 달라집니다.

교재 p.462 · 02 학습 과정 · 인터랙티브 연습

가장 가까운 뉴런을 고른 뒤 이웃까지 함께 학습한다

학습의 핵심은 BMU(Best Matching Unit, 최적 일치 단위)와 그 주변 격자 뉴런의 가중치를 입력벡터 쪽으로 갱신하는 것이다.

SOM의 4단계 학습 암기 순서

1
초기화 · Initialize (이니셜라이즈)경쟁층 뉴런별 연결 가중치 w 설정.
2
거리 계산 · Competition (컴피티션)입력벡터 x와 각 뉴런의 가중치 벡터 사이 거리 계산 → BMU 선택.
3
이웃 갱신 · Cooperation & Adaptation승자와 인접한 뉴런들의 가중치를 입력벡터에 가깝게 조정.
4
반복 · Iterate (이터레이트)다른 입력벡터에 대해 2~3단계를 되풀이하고 학습률·이웃 범위를 보통 점차 축소.

수식으로 한 번만 이해

BMU = arg minj ‖ x − wj ‖

입력 x와 가중치 wj 사이 거리가 가장 작은 j번째 뉴런을 승자로 선택한다.

선택 후 BMU와 이웃 뉴런의 가중치를 갱신한다. 승자만 학습하는 방식이 아니다.

시험 함정 : 경쟁학습의 '승자 독점'은 승자를 선택하는 규칙을 말한다. 전형적인 SOM에서는 주변 뉴런도 업데이트한다.

직접 확인하는 SOM 격자 체험

BMU(승자)이웃 뉴런

구분 핵심 : 입력공간에서의 거리로 승자(BMU)를 선택하지만, 격자상 위치로 어느 이웃 뉴런까지 가중치를 조정할지 정한다.

교재 p.463 · 03 특징과 차이점

SOM을 구별하는 3가지 특징

비지도학습 · 이웃 관계의 대략적 보존 · 경쟁학습이 다른 신경망 접근법과 구분되는 기준이다.

① 저차원 시각화 · Visualization

여러 특성을 가진 데이터를 보통 2차원 격자에 나타내므로, 패턴과 군집 경향을 한눈에 파악할 수 있다.

② 위상 관계 · Topology

입력공간에서 유사한 관측값은 지도 위에서도 대체로 가까운 곳에 대응하도록 학습한다.

※ 유사성이 항상 완벽히 보존된다는 뜻은 아닙니다.

③ 경쟁학습 · Competitive Learning

오차의 역전파 대신 BMU 선택 → 이웃 가중치 갱신을 반복하는 대표적인 비지도 신경망이다.

교재 p.463 · 04 장점·단점과 출제포인트

SOM의 장단점은 해석 용이성과 설정 민감성으로 정리

군집의 전반적인 형태를 보는 데 유용하지만 격자 수와 가중치 초기화에 따라 학습 결과가 달라질 수 있다.

✓ 장점 · Strengths (스트렝스)

✓고차원 데이터 시각화
복잡한 데이터를 2차원 지도로 표시해 이해하기 쉽다.
✓패턴 발견
비슷한 관측값의 분포와 잠재 군집 구조를 탐색한다.
✓레이블 없이 학습
정답이 없어도 자료의 구조를 스스로 조직화한다.
✓역전파 불필요
경쟁학습과 국소적 이웃 갱신으로 학습할 수 있다.
활용 예시 : 관광객의 선호·활동성·소비성향 등을 기반으로 서로 비슷한 관광객 유형을 지도상에 표시.

! 단점 · Limitations (리미테이션스)

!초기값 영향
초기 가중치와 초기 학습률에 따라 결과 차이가 나타날 수 있다.
!격자 크기 선정
경쟁층의 적절한 뉴런 수와 배열을 결정하기 어렵다.
!설정 조정 필요
학습률·이웃 범위·학습 반복 횟수에 따라 품질이 달라진다.
!거리·구조 왜곡 가능
입력공간의 관계를 저차원에 완벽히 보존하지는 못한다.
교재 문장 보완 : 역전파를 사용하지 않아 상대적으로 간단하지만, 모든 상황에서 학습 속도나 실시간 처리가 보장되는 것은 아닙니다.
암기 한 줄“보이기 쉽지만, 시작값과 격자 설정이 중요하다.”

11회 기출 · 48번 클러스터링 방법

고차원 데이터를 이해하기 쉬운 저차원의 뉴런으로 정렬하여 지도의 형태로 형상화하는 클러스터링 방법으로 적절한 것은?

힌트: 고차원 → 저차원 지도

30회 기출 · 49번 경쟁층의 역할

SOM은 비지도 신경망으로 고차원 데이터를 저차원의 뉴런으로 정렬한다. 입력벡터의 특성에 따라 벡터가 한 점으로 클러스터링되는 층은?

힌트: 2차원 격자
해설 포인트 : SOM = 저차원 지도 시각화 + 2차원 격자 경쟁층. 의사결정나무·랜덤포레스트는 일반적으로 지도학습에 활용되는 기법이며, 연관규칙은 항목 간의 공출현 관계를 탐색한다.
