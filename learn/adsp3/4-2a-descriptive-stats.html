QUESTION 01

히스토그램 설명

17회 기출
관련 문제
히스토그램은 표로 되어 있는 도수분포표를 그래프로 나타낸 것이다. 다음 중 히스토그램에 대한 설명으로 부적절한 것은?
① 히스토그램에는 가로축이 계급, 세로축이 도수를 나타낸다. 계급은 보통 변수의 구간이며, 서로 겹치지 않는다.
② 히스토그램은 표본의 크기가 작아도 각 막대의 높이가 데이터 분포의 형상을 잘 표현해낸다.
③ 그래프의 모양이 치우쳐있거나 봉우리가 여러 개 있는 그래프는 비정규 데이터일 수 있다.
④ 봉우리가 여러 개 있는 데이터는 일반적으로 2개 이상의 공정이나 조건에서 데이터가 수집되는 경우 발생한다.
정답 ②

히스토그램은 표본 크기가 충분히 커야 데이터의 분포를 신뢰성 있게 나타낼 수 있으며 표본 크기가 작을 경우 분포의 형상을 왜곡할 가능성이 크다. 나머지 선택지는 히스토그램의 기본 구성 요소와 관찰 가능한 데이터 특성을 정확히 설명하고 있다.

핵심 암기 · 표본이 작으면 히스토그램 모양을 믿지 말 것

QUESTION 02

분포 파악용 R 함수

16회 기출
관련 문제
다음 중 연속형 변수의 경우 4분위수, 최솟값, 최댓값, 중앙값, 평균 등을 출력하고 범주형 변수의 경우 각 범주에 대한 빈도수를 출력하여 데이터의 분포를 파악할 수 있게 하는 함수로 적절한 것은?
① summary 함수
② ddply 함수
③ cast 함수
④ aggregate 함수
정답 ①

summary 함수는 연속형 변수의 경우 최솟값, 최댓값, 중앙값, 평균, 4분위수를 제공하며, 범주형 변수의 경우 각 범주의 빈도수를 출력하여 데이터의 분포를 파악하는 데 유용하다. ddply는 그룹별 요약, cast는 데이터의 재구조화, aggregate는 요약 통계 변환에 쓰이지만 summary처럼 한 번에 여러 정보를 주지는 않는다.

핵심 암기 · 변수 하나 빠르게 훑을 때는 summary()부터
CONCEPT 03

상자수염그림(Box Plot) 읽는 법

3 / 3
상단 수염 ─┬─ ← Q3 + 1.5×IQR 이내 최댓값 │ ┌──┴──┐ ← Q3 (제3사분위수, 상위 25%) │ ─── │ ← 중앙값(Median) ≠ 평균 └──┬──┘ ← Q1 (제1사분위수, 하위 25%) │ 하단 수염 ─┴─ ← Q1 − 1.5×IQR 이내 최솟값

박스 가운데 선은 "평균"이 아니라 "중앙값(Median)"이다 — 가장 흔히 틀리는 포인트.

QUESTION 03

Box Plot 설명

28회 기출
관련 문제
아래의 box plot에 대한 설명 중 적절한 것은 무엇인가?
① box plot에서 나타나는 가운데 선은 평균이다.
② box plot의 네모박스 내의 가장 아래와 위는 각각 Q3, Q2이다.
③ box plot의 상단 수염을 벗어나는 값이 Q3 + 1.5×IQR 보다 작으면 이상치라고 할 수 있다.
④ box plot에서 약 0.5 이후 값들은 데이터의 50%이다.
정답 ④

박스 플롯에서 중앙값 이후 값들은 데이터의 상위 50%를 나타내고 가운데 선은 평균이 아니라 중앙값(Median)을 나타내며 박스의 하단은 1사분위(Q1), 상단은 3사분위(Q3)를 나타낸다. 이상치는 Box plot 상단 수염을 벗어나는 값으로 Q3 + 1.5×IQR(사분위범위)보다 큰 값이다.

핵심 암기 · 박스 하단=Q1, 상단=Q3, 가운데 선=중앙값(평균 아님)
