QUESTION 01

데이터 처리 구조

18회 기출
관련 문제
아래의 그림은 데이터 처리 구조를 나타내고 있다. 그림에 대한 설명으로 잘못된 것은?
① 데이터를 분석에 활용하기 위해 데이터 웨어하우스와 데이터 마트에서 데이터를 가져온다.
② 신규시스템이나 DW에 포함되지 않은 데이터는 기존 운영시스템(Legacy)에서 직접 데이터를 가져와 DW와 전처리 없이 바로 결합하면 된다.
③ ODS는 운영데이터저장소로 기존 운영시스템의 데이터가 정제된 데이터이므로 DW나 DM과 결합하여 분석에 활용할 수 있다.
④ 스테이징 영역에서 가져온 데이터는 정제되어 있지 않기 때문에 데이터를 전처리해서 DW나 DM과 결합하여 사용한다.
정답 ②

데이터 웨어하우스(DW)와 데이터 마트(DM)는 분석에 활용하는 저장소이고 ODS는 정제된 운영 데이터 저장소로 DW·DM과 결합해 쓸 수 있다. 스테이징 영역의 데이터는 정제되지 않은 원시 데이터라서 전처리를 거쳐야 하며, 기존 운영시스템(Legacy)의 데이터 역시 일반적으로 정제되어 있지 않아 전처리 없이 바로 DW와 결합하는 것은 부적절하다.

핵심 암기 · Legacy·Staging = 원시 데이터(전처리 필요) / ODS·DW·DM = 정제된 데이터
CONCEPT 02

시각화와 공간분석

2 / 5
시각화 (Visualization)가장 낮은 수준의 분석이지만 복잡한 분석보다 더 효율적일 때가 많다. 대용량 데이터를 다루는 빅데이터 분석에서는 필수. 워드클라우드·SNA·Polygon·Heatmap·Mosaic Graph 등이 최근 발전된 형태다.
공간분석 (GIS)공간적 차원과 관련된 속성을 지도 위에 시각화하는 분석. 크기·모양·선 굵기 등으로 속성을 구분해 인사이트를 얻는다. 도시계획·환경과학·공공건강 등에서 활용.

QUESTION 02

시각화의 발전된 형태

19회 기출
관련 문제
최근 시각화 기법의 활용이 높아지면서 데이터의 특성을 파악하는 데 많은 기여를 하고 있다. 다음 중 최근의 시각화의 발전된 형태가 아닌 것은?
① 텍스트 마이닝에서의 워드클라우드를 통한 그래프화
② SNA(Social Network Analysis)에서 집단의 특성과 관계를 그래프화
③ 통계소프트웨어의 기초통계정보를 엑셀에서 그래프화
④ Polygon, Heatmap, Mosaic Graph 등의 그래프 작업
정답 ③

통계소프트웨어의 기초통계정보를 엑셀에서 그래프화하는 방법은 과거의 단순한 시각화 방법이다. 워드클라우드, SNA 그래프, Polygon·Heatmap 등은 현대적인 시각화 기법으로 활용된다.

핵심 암기 · 엑셀 기초 그래프 = 전통적 방식 / 워드클라우드·SNA·Heatmap = 최근 발전된 시각화

QUESTION 03

EDA의 정의

9회 기출
관련 문제
데이터가 가지고 있는 특성을 파악하기 위해 해당 변수의 분포 등을 시각화하여 분석하는 분석방식은 무엇인가?
① 전처리분석
② 탐색적자료분석(EDA)
③ 공간분석
④ 다변량분석
정답 ②

EDA는 데이터의 분포와 특성을 이해하기 위해 시각화를 활용하는 방식이다. 전처리분석은 데이터 정제를, 공간분석은 지리적 데이터를, 다변량분석은 변수 간 상관관계 분석에 집중하므로 정답이 아니다.

핵심 암기 · EDA = 변수 분포·특성을 시각화로 먼저 들여다보는 단계

QUESTION 05

빈칸 채우기

44회 기출
관련 문제
다음 빈칸에 들어갈 적절한 내용은 무엇인가?
탐색적 데이터 분석은 데이터를 이해하고 데이터를 시각화하여 초기 단계에서 (   )을(를) 파악하기 위해 수행됩니다.
① 데이터의 특성과 관계
② 미래의 경향
③ 모델의 정확도
④ 프로젝트의 비용
정답 ①

탐색적 데이터 분석(EDA)은 본격적인 통계 분석이나 모델링 이전에 데이터를 다양한 방식으로 살펴보고 시각화하여 데이터에 대한 초기 이해를 높이는 활동이다. 주요 목적은 데이터의 특성(분포, 이상치 등)과 변수 간의 관계(상관관계, 패턴)를 파악하고, 이를 통해 분석의 방향을 설정하고 적절한 분석 기법을 모색하는 것이다.

핵심 암기 · EDA의 산출물은 "모델"이 아니라 "데이터에 대한 이해와 방향"
