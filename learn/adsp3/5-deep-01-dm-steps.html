시험에서 가장 헷갈리는 단계 비교

② 데이터 준비 = 데이터를 확보하고 깨끗하게

여러 원천에서 자료를 모으고 접근환경·품질·충분한 데이터량을 확보합니다.

③ 데이터 가공 = 분석할 수 있는 형태로

모형의 목적변수를 정의하고 소프트웨어에 적용할 수 있도록 데이터 형식을 바꿉니다.

암기 공식　목적 설정 → 데이터 준비 → 데이터 가공 → 기법 적용 → 검증
PROCESS 01–02

먼저 왜 분석하는지 정하고 데이터를 확보한다

이해관계자의 합의, 전문가 참여, IT 부서 협의, 품질 관리가 중요한 단계
02 / 06
01
WHY & WHAT

목적 설정

🎯
  • 무엇을 왜 하는지 명확한 분석 목적을 설정합니다.
  • 목적은 모든 이해관계자가 이해하고 동의할 수 있는 수준으로 정의해야 합니다.
  • 전문가가 참여하여 목적에 맞는 모형과 필요한 데이터를 정의합니다.
분석 과제이해관계자 합의모형 구상
핵심 질문: “어떤 문제를 해결하려고 하는가?”
02
COLLECT & CLEAN

데이터 준비

🗃️
  • 고객정보·거래정보·상품 마스터정보·웹로그·소셜 네트워크 데이터 등 자료를 활용합니다.
  • IT 부서와 접근 및 일정을 협의하고, 운영시스템 부하를 줄이도록 필요시 별도 서버에 저장합니다.
  • 데이터를 정제하여 품질을 보장하고 필요시 보강하여 충분한 양을 확보합니다.
수집IT 협의정제·보강
핵심 질문: “분석에 필요한 믿을 만한 데이터가 있는가?”
구분 포인트　고객 데이터 수집, 결측값 정제, 업무 서버 부하 관리 → 2단계 데이터 준비. 목적변수 정의, 도구용 형태 변환 → 3단계 데이터 가공.
PROCESS 03–04

데이터를 가공하고 목적에 맞는 기법을 적용한다

목적변수를 정의하는 단계와 분석 알고리즘을 실행하는 단계를 구분하세요.
03 / 06
03
TRANSFORM

데이터 가공

🛠️
  • 모델링 목적에 따라 목적변수(종속변수, 예측 대상)를 정의합니다.
  • 필요한 데이터를 데이터 마이닝 소프트웨어가 처리할 수 있는 형식으로 가공합니다.
기출 핵심: “목적변수 정의 + 분석용 형식 변환” = 데이터 가공
04
MODEL

기법 적용

🧠
  • 1단계에서 설정한 목적에 적합한 데이터 마이닝 기법을 선택합니다.
  • 선택한 기법을 실제 데이터에 적용해 필요한 정보·패턴·예측 결과를 추출합니다.
분류예측군집연관분석

데이터 가공 예시 · 관광고객의 이탈 여부 예측 (설명용 예시)
고객 방문기록거래·이용 정보

PROCESS 05

검증을 거쳐 실제 업무 성과로 연결한다

추출한 정보를 검증하고, 최적 모형을 선정한 뒤 업무 적용과 투자 성과를 확인합니다.
04 / 06
05
TEST & DEPLOY

검증

✅
  • 데이터 마이닝으로 추출된 정보가 타당하고 유용한지 검증합니다.
  • 테스트 데이터와 과거 데이터 등을 활용해 비교·평가하고 최적의 모형을 선정합니다.
  • 검증 후 IT 부서와 협의해 결과를 일상적인 업무에 적용합니다.
  • 보고서를 작성하고 추가수익·투자대비성과(ROI) 등을 바탕으로 기대효과를 전달합니다.
검증 단계는 “평가하고 끝”이 아니라 “검증 → 업무 적용 → 성과 공유”까지 포함

검증 이후의 활용 흐름

1
정보·모형 검증
테스트 및 과거 데이터를 사용한 결과 확인
2
최적 모형 선정
후보 중 목적에 적합한 모형 선택
3
업무 적용 협의
IT 부서와 운영 과정에 분석결과 연결
4
성과 보고
추가수익, ROI 등으로 효과 설명
📊모형의 신뢰성과거·테스트 데이터로 검증
🔗현업 활용분석 결과를 업무 프로세스에 연결
💰투자 대비 성과ROI와 추가수익으로 효과 공유
APPLIED EXAMPLE

관광업 사례로 5단계 연결하기

관광 플랫폼에서 고객의 이탈 가능성을 예측하는 상황을 가정한 학습용 예시입니다.
05 / 06

✈️ 사례: 관광 서비스 고객 이탈 예측

이용 중단 가능성이 높은 고객을 파악하여 맞춤형 유지 활동에 활용하기

🧳📱
01 · 목적 설정

누가 이탈할까?

고객 이탈 가능성을 예측해 고객 유지 전략을 수립할 수 있도록 분석 목적을 정합니다.

02 · 데이터 준비

정보 모으기

예약 기록, 앱 방문 이력, 구매정보 등을 확보·정제하고 IT 부서와 데이터 접근을 조율합니다.

03 · 데이터 가공

이탈여부 정의

이탈여부를 목적변수로 정하고 방문횟수·예약간격 등을 모형 입력 형식으로 만듭니다.

04 · 기법 적용

분류 모형 실행

예: 로지스틱 회귀 또는 의사결정나무로 고객의 이탈 가능성을 예측합니다.

05 · 검증

성능과 성과 확인

테스트 데이터로 평가한 뒤 활용 여부를 결정하고, 실제 성과·ROI를 확인합니다.

개념 연결: ① 목적을 정하는 것은 목적 설정, ② 데이터를 확보하고 정제하는 것은 데이터 준비, ③ 이탈 여부를 목적변수로 설정하는 것은 데이터 가공, ④ 분류 모형을 실행하는 것은 기법 적용, ⑤ 테스트 결과로 최적 모형을 고르고 업무에 활용하는 것은 검증 단계입니다.
주의: 예시의 변수와 기법은 이해를 돕기 위한 구성입니다. 구체적인 이탈 정의·기간·모형 선택은 실제 분석 목적과 데이터에 따라 달라집니다.

18회 기출 · 4지선다

데이터 마이닝 단계 중, 모델링 목적에 따라 목적변수를 정리하고 필요한 데이터를 데이터 마이닝 소프트웨어에 적용할 수 있도록 준비하는 단계는 무엇인가?

정답을 선택해 보세요.　핵심 단서는 “목적변수”와 “소프트웨어에 맞는 형식”입니다.
② 데이터 준비와의 차이여러 원천에서 데이터를 확보하고, IT 부서와 협의하며 정제·보강하는 더 넓은 과정입니다.
③ 데이터 가공의 결정적 단서목적변수 정의와 분석 소프트웨어에 적용 가능한 형태로의 가공입니다.
