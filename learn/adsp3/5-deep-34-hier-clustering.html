LESSON 01 · 02/07

계층적 군집분석의 두 가지 방향

계층적 군집분석(Hierarchical Clustering)은 결합하는 방식과 나누는 방식 모두를 포함합니다.

교재 p.452

① 병합형 · Agglomerative (어글로머러티브)

ABCD→ABCD→ABCD

데이터 n개를 각각 독립된 군집으로 시작합니다. 가까운 군집끼리 차례대로 합쳐 최종적으로 군집 1개가 됩니다.

n개→n−1개→…→1개

② 분할형 · Divisive (디바이시브)

ABCD→ABCD→ABCD

모든 데이터를 포함하는 1개의 군집에서 시작합니다. 군집을 반복적으로 분할하여 최종적으로 n개까지 나눌 수 있습니다.

1개→2개→…→n개

시험에 나오는 구분표

비교 기준병합형 (Agglomerative)분할형 (Divisive)
출발점관측치 각각을 별도 군집으로 설정전체 관측치를 하나의 군집으로 설정
진행가까운 군집끼리 합침하나의 군집을 둘 이상으로 나눔
군집 수감소 (n → 1)증가 (1 → n)
기억 단서Bottom-up / 상향식 / 합병Top-down / 하향식 / 분리
핵심 암기 — “계층적 = 무조건 n개부터 시작”은 틀립니다. 그것은 병합형에만 해당합니다. 분할형은 1개 군집에서 시작합니다.
LESSON 02 · 03/07

병합형 계층적 군집화의 4단계

교재의 ‘계층적 군집 절차’는 구체적으로 병합형 알고리즘의 진행 과정을 설명합니다.

교재 p.452
1

개별 군집 정의

관측치 A, B, C, D를 각각 하나의 군집으로 보고 n개에서 시작.

2

군집 간 거리 계산

관측치 또는 군집들 사이의 거리를 계산하여 거리행렬 작성.

3

최소 거리 군집 결합

가장 가까운 두 군집을 하나로 병합하고 거리행렬을 갱신.

4

반복·덴드로그램

군집이 하나가 될 때까지 ②–③ 반복하고 트리로 시각화.

개체가 단계적으로 결합되는 예

위 도식의 병합 순서는 이해를 위한 가상 예시입니다. 실제 병합 순서는 사용한 거리와 연결법에 따라 달라집니다.

거리행렬이 바뀌는 이유

군집 A와 B를 합쳤다면, 새 군집 {A,B}와 다른 군집 C 사이의 거리를 다시 정의해야 합니다.

최단연결법: min(d(A,C), d(B,C))

최장연결법: max(d(A,C), d(B,C))

평균연결법: 군집 간 모든 쌍 거리의 평균

즉, 연결법(Linkage)이란 군집끼리의 거리를 어떤 규칙으로 정의할지를 정하는 방법입니다.
기출 암기 순서 — 개별 군집 설정 → 거리행렬 계산 → 가장 가까운 군집 병합 → 거리행렬 갱신·반복 → 덴드로그램
LESSON 03 · 04/07

연결법 5가지 비교 · 거리 정의가 다르다

두 군집 A·B 사이의 거리를 최소·최대·평균·중심·제곱합 증가량 중 무엇으로 볼 것인가?

교재 p.452–454

① 최단연결법 Single Linkage

min { d(a,b) }

두 군집의 개체 쌍 중 가장 가까운 거리를 사용.

시험 단서: 사슬 현상(Chaining), 고립 개체

② 최장연결법 Complete Linkage

max { d(a,b) }

두 군집의 개체 쌍 중 가장 먼 거리를 사용.

시험 단서: 상대적으로 조밀한 군집

③ 평균연결법 Average Linkage

mean { d(a,b) }

군집 간 모든 개체 쌍 거리의 평균을 사용.

시험 단서: 전체 쌍 평균 · 계산 부담

④ 중심연결법 Centroid Linkage

d(μA, μB)

두 군집의 중심점(평균 벡터) 간 거리 사용. 병합 후 중심은 개체 수를 고려한 가중평균.

시험 단서: 군집 중심 ↔ 개체 간 최단거리와 구별

⑤ 와드연결법 Ward Linkage

min ΔWSS

두 군집을 합칠 때 군집 내 제곱합(WSS)이 증가하는 정도가 가장 작은 병합을 선택.

시험 단서: 군집 내 편차 제곱합 · 정보 손실 최소화

헷갈리기 쉬운 3가지

Single = 최소값(min) · Complete = 최대값(max)

Average = 개체 쌍의 평균 · Centroid = 중심 간 거리

Ward = 단순한 두 군집의 거리 평균이 아니라 병합 후 WSS 증가량

최단연결법은 가까운 개체들이 줄줄이 이어져 길쭉한 사슬 모양을 형성할 수 있습니다.
와드연결법에서 ‘정보 손실 최소화’는 일반적으로 군집 내 제곱합의 증가 최소화로 이해하면 정확합니다.
시험 한 줄 암기 — 최단=min │ 최장=max │ 평균=mean │ 중심=centroid │ Ward=ΔWSS 최소
LESSON 04 · 05/07

같은 데이터, 다른 거리 계산

설명용 1차원 예시로 연결법별 계산 규칙을 직접 확인합니다. 버튼을 누르면 계산 근거가 바뀝니다.

개념 적용 실습 · p.452–454

두 군집의 구성

A1B2C5D8
군집 G₁={1,2}군집 G₂={5,8}

군집 G₁: A=1, B=2 | 군집 G₂: C=5, D=8
개체 간 거리는 1차원 유클리드 거리 |x−y|

군집 간 개체 쌍 거리행렬

C = 5D = 8
A = 147
B = 236

A–C=4, A–D=7, B–C=3, B–D=6 (모두 실제 거리)

연결법을 눌러 선택해 보세요

최단연결법 · Single Linkage
3
min(4, 7, 3, 6) = 3. 가장 가까운 쌍은 B–C.
중심·Ward 추가 계산 — G₁ 평균 1.5, G₂ 평균 6.5 → 중심 간 거리 5. Ward의 제곱합 증가량은 (2×2)/(2+2) × 5² = 25입니다. 주의: Ward의 25(ΔWSS)는 다른 연결법의 거리값과 직접 비교하면 안 됩니다.

주의: 이 수치들은 교재에 실린 원래 거리행렬을 복원한 값이 아닌 독립적인 설명용 예시입니다.

LESSON 05 · 06/07

덴드로그램 · 절단 높이로 군집 수 결정

수평선을 긋고, 선이 교차하는 독립적인 가지를 세면 해당 높이의 군집 수가 됩니다.

교재 p.454–455
60
INTERACTIVE CLUSTER CUT

현재 군집 수

3 개
현재 절단 높이에서 서로 연결된 개체 묶음
{A, B}{C}{D, E, F}

높이 60의 해석

A–B, D–E–F는 이미 병합되었지만 C는 아직 독립적입니다. 따라서 군집은 {A,B}, {C}, {D,E,F}의 3개입니다.
높이 ↑ → 군집 수 ↓
높이 ↓ → 군집 수 ↑
병합형 덴드로그램을 위아래로 절단해 비교하면 됩니다.

군집 수를 세는 방법

① 원하는 높이에서 수평선을 긋기 → ② 수평선과 만나는 서로 다른 수직 가지 세기 → ③ 그 개수를 군집 수로 판단

시험 출제 주의

높이 60에서 3개는 사용자가 제공한 33회 기출 해설의 결과이기도 합니다. 다만 위 그림은 원 기출 그래프가 아니라 동일한 결과를 보여주는 설명용 도식입니다.

두 군집에 속한 개체 간 거리 중 가장 먼 거리를 군집 간 거리로 정의하는 방법은?

병합형 / 분할형병합형: n → 1
분할형: 1 → n
