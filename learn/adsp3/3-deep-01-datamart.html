03 · 가장 중요한 비교 개념

요약변수 vs 파생변수

자료를 묶어 집계한 값인가, 분석자가 규칙과 의미를 설계한 값인가?

교재 pp. 221–222

같은 거래 기록에서 두 종류의 변수를 만들기

① 원본 구매 기록

고객구매일금액
A10/0120,000원
A10/0540,000원
A10/1350,000원
→

② 고객 A의 분석용 변수

변수값분류
총 구매금액110,000원요약
구매 횟수3회요약
우수고객 여부예파생

예시 규칙: 총 구매금액 ≥ 100,000원이면 ‘우수고객=예’로 지정(교육용 가상 기준).

Summary Variable

요약변수 · 모아서 계산

20,000 + 40,000 + 50,000
= 110,000원

합계·평균·횟수·최댓값처럼 자료를 일정 기준으로 집계합니다.

Derived Variable

파생변수 · 규칙을 설계

총 구매액 ≥ 100,000원?
→ 우수고객 = 예

분석 목적에 맞는 조건·함수·업무 지식으로 새 의미를 부여합니다.

주의할 점: 두 범주는 일부 중첩될 수 있습니다. 시험에서는 집계 중심은 요약변수, 분석자가 의미를 정의하는 규칙 중심은 파생변수로 구분합니다. 파생변수는 타당성 검토가 중요합니다.

04 · R 실습: 데이터 형태 변환

melt()와 cast()는 무엇을 하나요?

넓은 표 ↔ 긴 표. 데이터를 녹이고(melt), 형태를 다시 만드는(cast) 원리입니다.

교재 p. 222

직접 눌러보며 표 형태 비교하기

넓은 표 · 과목이 여러 열에 있음

학생국어수학
가7080
나90100

💧 melt() · 열을 행으로

‘국어’, ‘수학’이라는 두 점수 열을 과목(variable)과 점수(value) 열에 모아 세로로 늘어놓습니다.

long <- reshape2::melt(scores, id.vars = "학생")

🧱 dcast() · 행을 열로

학생별·과목별 점수를 다시 열로 펼칩니다. 여러 값이 모이면 평균 같은 집계 함수도 사용합니다.

wide <- reshape2::dcast(long, 학생 ~ variable, value.var = "value")
패키지 구분: 원문의 reshape에는 melt(), cast()가 있고, 실습 코드의 dcast()는 주로 reshape2 패키지에서 사용합니다. 시험 포인트: melt는 길게, cast는 원하는 차원으로.

07 · R 실습: 빠른 데이터 처리

data.table은 큰 데이터도 효율적으로 다룹니다

짧은 표현으로 행을 선택하고, 계산하고, 그룹별 결과를 만듭니다.

교재 p. 223

가장 중요한 구문 · DT[i, j, by]

📌

i · 행

어떤 행을 선택할까?
customer == "A"

🧮

j · 계산·열

어떤 값을 만들까?
sum(amount)

🗂️

by · 그룹

무엇을 기준으로 묶을까?
customer

🧑‍💻 코드 두 줄로 이해하기

library(data.table) DT <- as.data.table(purchase) DT[, .(total = sum(amount), count = .N), by = customer]

⚡ 왜 유용할까요?

효율적인 그룹 연산과 메모리 활용을 지원하여 큰 표를 다루는 데 유용합니다.

key(키)는 정렬·조인·검색에 도움을 주는 기능이지만, 모든 작업에서 키 설정이 필수인 것은 아닙니다.

시험 핵심: data.table = 데이터프레임과 유사한 형태 + 효율적인 계산 + DT[행, 열/계산, 그룹]

핵심: DW가 큰 창고라면 DM은 필요한 자료를 모아둔 목적별 공간.

31회 기출 · 문제 1 / 3

다음 중 데이터 웨어하우스의 하위 집합으로, 특정 사용자 그룹이 관심을 갖는 데이터를 제공하기 위해 구성된 작은 규모의 데이터 저장소는 무엇인가?

📚 상세 해설 · 정답 ② 데이터 마트

정답 이유: 특정 사용자·부서·주제에 집중한 비교적 작은 분석용 저장소를 데이터 마트라고 합니다. DW의 하위 집합으로 만들어지는 경우가 많습니다.

  • ① 데이터 레이크: 원시·반정형·비정형을 포함한 다양한 형식의 데이터를 저장하는 저장소입니다.
  • ③ 데이터베이스: 데이터를 체계적으로 저장·관리하는 일반적 개념으로, 특정 사용자용 DW 하위 집합을 가리키지 않습니다.
  • ④ 데이터 파이프라인: 데이터를 추출·전송·변환하는 처리 흐름입니다. 저장소 자체가 아닙니다.

암기 장치: “특정 사용자 그룹” + “작은 저장소” → 데이터 마트.

기출 02 · 9회

새로운 의미를 부여하는 변수

단순 집계인지, 분석자가 만든 분류·규칙인지 판별해 보세요.

교재 p. 224
📘 관련 이론 먼저 보기 · 요약변수 vs 파생변수
구매기록2만 · 4만 · 5만
→
총액 11만원요약변수 · 합계
→
우수고객 = 예파생변수 · 기준 부여

핵심: 합계는 요약, “10만 원 이상이면 우수고객”이라는 의미·규칙을 붙이면 파생.

9회 기출 · 문제 2 / 3

아래 정의가 가리키는 데이터 마트의 구성요소로 가장 적절한 것은?
“특정한 의미를 갖는 작위적 정의에 의한 변수로, 사용자가 특정 조건을 만족하거나 특정 함수에 의해 값을 만들어 의미를 부여한 변수”

📚 상세 해설 · 정답 ② 파생변수

정답 이유: 파생변수(Derived Variable)는 기존 정보에 분석 목적에 따른 규칙, 함수, 지식 등을 적용하여 새로운 의미를 담도록 만든 변수입니다.

  • ① 반응변수: 설명변수의 영향을 받는 결과 변수(종속변수)를 뜻합니다.
  • ③ 설명변수: 결과를 설명하거나 예측하는 데 사용되는 변수(독립변수)를 뜻합니다.
  • ④ 요약변수: 합계·평균·횟수처럼 원본 기록을 일정 기준에 따라 집계한 값입니다.

암기 장치: “사용자가 조건을 정한다” + “의미를 부여한다” → 파생변수.

🎞️ 문제 해설 4컷
🧾
① 구매내역 3개영수증이 그대로 있어요.
➕
② 합계 계산11만 원을 구했어요. 이것은 요약!
🏷️
③ 기준을 적용10만 원 이상이면 우수고객이라고 정해요.
✅
④ 의미가 만들어짐우수고객 여부는 파생변수!
기출 03 · 29회

데이터를 다양한 차원으로 변환하는 패키지

melt·cast를 떠올리며 답을 선택하세요.

교재 p. 224
📘 관련 이론 먼저 보기 · melt & cast
넓은 데이터학생·국어·수학
melt →
긴 데이터학생·과목·점수
cast →
새로운 가로 표학년별 평균 등

핵심: 데이터 구조를 분석에 맞게 길게 펼치거나, 다시 기준별로 열을 만드는 기능.

29회 기출 · 문제 3 / 3

변수를 조합해 변수명을 만들고, 변수들을 시간·상품 등의 차원에 결합해 다양한 요약변수와 파생변수를 쉽게 생성하여 데이터 마트를 구성할 수 있는 R 패키지는 무엇인가?

📚 상세 해설 · 정답 ② reshape

정답 이유: reshape 패키지는 melt()·cast()를 사용하여 데이터의 긴/넓은 형태를 바꾸고, 원하는 차원으로 결합·집계하는 데 활용합니다. 유사한 이름의 reshape2 패키지에서는 dcast()도 사용합니다.

  • ① ETL: Extract–Transform–Load(추출–변환–적재)의 작업 과정이지, 문항에서 묻는 R 패키지 이름이 아닙니다.
  • ③ OLAP: 다차원 분석 방식·기술 개념으로, 여기서 묻는 패키지 이름이 아닙니다.
  • ④ rattle: R을 기반으로 한 데이터 마이닝 GUI 도구로, melt·cast 중심의 패키지가 아닙니다.

암기 장치: 녹이기 melt + 형태 만들기 cast = reshape 계열.
