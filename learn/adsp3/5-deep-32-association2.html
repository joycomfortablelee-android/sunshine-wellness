CONCEPT 01

항목집합과 최소 지지도

연관규칙은 수많은 품목 조합 중 ‘충분히 자주 등장하는 조합’을 찾습니다.
교재 p.473

🧩 꼭 알아야 할 용어

1
항목집합 (Itemset, 아이템셋)하나 이상의 상품으로 이루어진 집합. 예: {우유, 빵}
k
k-항목집합 (k-itemset)항목을 정확히 k개 포함한 집합. 예: {우유, 빵}은 2-항목집합
%
지지도 (Support, 서포트)전체 거래 중 특정 항목집합이 등장한 거래의 비율
≥
최소 지지도 (Minimum Support)빈발항목집합으로 인정하기 위해 정해 놓는 지지도 기준
✓
빈발항목집합 (Frequent Itemset)최소 지지도 이상을 만족하는 집합. 1-빈발항목집합은 항목 1개짜리 빈발집합

📈 왜 조합을 줄여야 할까?

전체 품목이 n개라면 가능한 품목 부분집합과 연관규칙 수는 빠르게 증가합니다.

공집합을 제외한 항목 부분집합

2n − 1
n = 4일 때 15개

서로 겹치지 않는 선행·후행 항목의 규칙

3n − 2n+1 + 1
n = 4일 때 50개

⚠️ 계산 부담의 의미

  • 품목 수가 증가하면 탐색할 후보 조합이 기하급수적으로 늘어납니다.
  • 처리 시간, 메모리 사용량 및 시스템 부하가 커질 수 있습니다.
  • 대용량 분석이 원천적으로 불가능한 것은 아닙니다. 알고리즘과 시스템에 따라 처리 가능 범위가 달라집니다.
공식의 ‘전체 연관규칙 수’는 선행부와 후행부가 모두 비어 있지 않고, 서로 겹치지 않는 경우를 센 값입니다.
ALGORITHM 01 · APRIORI (에이프라이오리)

Apriori: 최소 지지도로 후보를 제거한다

자주 나오지 않는 조합은 더 큰 조합의 후보에서 제외하는 것이 핵심입니다.
교재 p.473

🔢 4단계 분석 절차

1최소 지지도 설정예: 전체 5건 중 40% 이상(2건 이상)을 빈발로 간주
21-빈발집합 도출각 품목의 빈도를 세어 기준 미달 품목을 제거
32-항목 후보 생성남은 품목끼리 결합하고 지지도를 재계산
4k-항목집합 반복3개·4개 이상으로 확장하며 기준 미달 후보 제거
Apriori 성질: 어떤 항목집합이 빈발하지 않으면, 이를 포함하는 더 큰 집합도 빈발하지 않습니다.

🛒 작은 거래 데이터로 이해하기

거래구매 품목
T1우유, 빵, 계란
T2우유, 빵
T3우유, 기저귀
T4빵, 기저귀
T5우유, 빵, 기저귀
① 1-항목집합우유 4건 · 빵 4건 · 기저귀 3건 유지
계란 1건 제거
② 2-항목집합우유+빵 3건
우유+기저귀 2건
빵+기저귀 2건 유지
③ 3-항목집합{우유, 빵, 기저귀}는 1건(20%) → 최소 지지도 40% 미달 → 제거
주의: 빈발항목집합을 찾는 과정과 그 집합에서 신뢰도 등의 기준으로 최종 연관규칙을 생성·선별하는 과정은 구별해야 합니다.
ALGORITHM 02 · COMPARISON

Apriori vs. FP-Growth

후보를 반복 생성하는 방식과 거래를 트리로 압축해 탐색하는 방식의 차이
교재 p.473–474

① Apriori

후보 생성·검사
1-빈발집합
→
2-후보 검사
→
3-후보 검사

최소 지지도 이하의 불필요한 후보를 제거하면서 빈발항목집합을 단계적으로 확장합니다.

② FP-Growth (에프피 그로스)

트리 압축·패턴 탐색
거래 스캔
→
FP-Tree 구축
→
분할·패턴 탐색

후보 항목집합을 명시적으로 생성하지 않고 FP-Tree(Frequent Pattern Tree)에 거래의 공통 패턴을 압축해 빈발패턴을 찾습니다.

③ FPV · 교재의 최근 동향

교재는 FPV를 활용한 메모리 효율 개선과 SKU(Stock Keeping Unit, 재고관리단위) 수준 분석 사례를 소개합니다.

FPV의 정확한 풀네임·구현 방식과 ‘3세대’ 호칭은 제공된 발췌문만으로 확인할 수 없으므로 보편적 표준 명칭으로 단정하지 않습니다.
APPLICATION · REAL-WORLD USE

연관성분석은 어디에 활용할까?

상품 추천·교차판매·진열 배치, 그리고 다른 추천 방식과의 차이
교재 p.473–474

🛍️ 장바구니 분석 (Market Basket Analysis)

우유와 빵 동시 구매
→
함께 구매할 상품 추천

상품의 동시 구매 관계를 찾아 교차판매(Cross-selling)와 묶음 추천, 매장 상품 배치에 활용합니다.

예시: IF–THEN 연관규칙

IF 우유 구매 → THEN 빵 구매 가능성

‘함께 구매하는 경향’은 인과관계를 의미하지 않습니다.

🕒 순차패턴 분석 (Sequential Pattern Analysis)

먼저 A 구매
→
나중에 B 구매 경향

구매의 시간적 순서를 고려합니다. A를 샀지만 아직 B를 사지 않은 고객에게 B를 추천할 수 있습니다.

🔍 두 가지 추천 방식 구분

C
콘텐츠 기반 필터링 (Content-Based Filtering)내가 선호한 아이템과 속성·내용이 비슷한 아이템을 추천
예: 역사 여행 콘텐츠를 읽으면 비슷한 문화유산 여행 추천
U
협업 필터링 (Collaborative Filtering)여러 이용자의 평가·행동 패턴을 활용해 추천
예: 나와 취향이 비슷한 여행객이 예약한 체험 추천
A
연관규칙 기반 추천 (Association Rule-Based)함께 발생하는 상품·행동의 규칙으로 추천
예: 항공권+숙박을 구매한 고객에게 공항교통권 제안

Apriori 순서

다음 단계의 순서를 교재 기출의 선택지 기준으로 고르세요.
가: 최소 지지도 설정 / 나: 3개 품목집합 / 다: 빈발집합 반복 탐색 / 라: 2개 품목집합 / 마: 개별 품목 탐색
