02 / BOOTSTRAP 📖 교재 5장 · 426쪽

붓스트랩이란? 복원추출!

원본에서 한 번 뽑은 관측치를 다시 뽑을 수 있습니다.
원본 학습데이터 (N = 6)
ABCDEF

추출 원리

추출 방식무작위 복원추출
기본 예시의 표본 크기원본과 동일한 6개
중복 출현가능
선택되지 않는 관측치가능
버튼을 누를 때마다 새로운 표본 3개 생성
각 표본은 6번 추출하지만, 같은 관측치가 여러 번 포함될 수 있습니다.

배깅은 이런 표본마다 모델을 학습시키므로 서로 조금씩 다른 예측을 얻습니다.

시험 함정: 붓스트랩은 비복원추출(X)이 아닙니다. 원본 표본 크기와 동일하게 뽑더라도 서로 다른 관측치가 6개 모두 포함된다는 뜻은 아닙니다.

04 / BAGGING CHARACTERISTICS 📖 교재 5장 · 425–426쪽

배깅의 특징과 시험 함정

불안정한 모델(예: 의사결정나무)을 여러 번 결합할 때 효과적일 수 있습니다.
왜 분산이 줄어들까?
한 그루의 예측은 흔들려도
여러 그루의 평균은
상대적으로 안정될 수 있다.
과적합 위험을 완화할 수 있지만, 항상 성능이 좋아지는 것은 아닙니다. 기본 모델의 품질·오류 간 상관성 등에 따라 달라집니다.
1

트리의 가지치기

고전적 배깅 예시에서는 깊게 성장한 의사결정나무를 자주 활용합니다. 단, 모든 배깅에 필수인 것은 아닙니다.

2

모델 학습 관계

개별 모델을 대체로 독립·병렬적으로 학습할 수 있습니다.

3

랜덤포레스트와 관계

랜덤포레스트는 붓스트랩 표본화 + 분할 시 변수 무작위 선택을 결합한 대표적인 트리 앙상블입니다.

교재의 “Breiman(1994)” 표기는 검증이 필요합니다. 대표적인 배깅 원전 Bagging predictors의 출판연도는 1996년입니다.
05 / VOTING 📖 교재 5장 · 426쪽

하드 보팅 vs 소프트 보팅

같은 3개 모델이라도 결합 규칙에 따라 결론이 달라질 수 있습니다.
모델 1

A 예측

A 확률51%
B 확률: 49%
모델 2

A 예측

A 확률52%
B 확률: 48%
모델 3

B 예측

B 확률99%
A 확률: 1%
HARD VOTING

A 2표 vs B 1표 → 최종 A

각 모델의 최종 범주를 세어서 다수결로 결정합니다. 개별 확률의 크기는 직접 비교하지 않습니다.

SOFT VOTING

A 평균 34.7% vs B 평균 65.3% → 최종 B

각 모델의 예측확률을 평균하여 확률이 가장 높은 범주를 선택합니다. 가중평균도 가능합니다.

주의: 소프트 보팅은 분류에서 확률을 평균하는 방법입니다. 연속형 종속변수는 여러 회귀모형의 예측값 평균으로 결합합니다. 서로 같은 개념이 아닙니다.
