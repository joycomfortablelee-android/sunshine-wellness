07 · VARIABLES / VECTORS교재 pp.203–204

변수는 이름표, 벡터는 값의 묶음

R은 이름표를 붙여 데이터를 저장하고 여러 값을 벡터 하나로 관리할 수 있습니다.

변수(variable): 값을 담는 이름

name <- "Jane" visitors <- c(10, 20, 30, 40, 50) class(name) # "character" class(visitors) # "numeric"

대입연산자 <-는 오른쪽 값을 왼쪽 이름에 저장합니다. =도 가능한 맥락이 있지만 초보 단계에서는 <-를 권장합니다.

벡터(vector)의 그림

visitors <- c(10,20,30,40,50)
10
20
30
40
50

한 이름 visitors 아래 숫자 5개가 차례로 묶였습니다. visitors[2]는 두 번째 값인 20입니다. R의 인덱스는 1부터 시작합니다.

✅ 사용할 수 있는 변수명

x · abc_1 · efg.2 · .sample

영문자 또는 조건에 맞는 마침표로 시작할 수 있습니다.

❌ 일반적인 변수명 규칙 위반

1a (숫자로 시작) · .3 (점 뒤 숫자) · x-y (하이픈은 뺄셈 연산자로 해석)

벡터 하나로 통계량을 계산하기

방문객 수 5개의 값을 바꾸면 평균·표본분산·표본표준편차가 어떻게 달라질까요?

이 그래프는 입력값의 상대적 크기를 비교하며, 이 수업의 예제 계산은 브라우저에서 미리 보여주는 방식입니다.

실시간 결과 해석

30총합 ÷ 자료 개수
30정렬 시 가운데 값
150값 모두 더하기
250편차 제곱합 ÷ (n−1)
15.811분산의 제곱근
5자료의 원소 개수

R 코드

x <- c(10, 20, 30, 40, 50) mean(x) # 30 var(x) # 250 (표본분산) sd(x) # 15.81139... length(x) # 5

log(x)

자연로그(기본 밑 e)

cov(x,y)

표본 공분산

cor(x,y)

상관계수

sum(x)

10 · R CODE READING교재 p.199

교재의 Animals 예제, 코드로 읽기

기본 R 문법이 실제 통계분석 코드에 어떻게 연결되는지 봅니다.

# MASS 패키지 데이터 사용 library(MASS) data(Animals) # 체중(body)이 뇌 무게(brain)와 # 어떤 관련이 있는지 로그 회귀 fit <- lm( log(brain) ~ log(body), data = Animals ) plot(log(Animals$body), log(Animals$brain)) abline(fit, lty = "dotted")

코드 해부도

lm( y ~ x, data = … )
y = log(brain)설명할 결과변수
x = log(body)설명변수

② 19회 기출문제

2. R에서 새로운 패키지를 설치 및 사용하고자 할 때 명령어와 순서로 적절한 것은?

정답 ① · 일반적인 설치 문법과 로드 순서를 모두 만족합니다.

① 정답: 보편적인 사용 예

install.packages("dplyr")
library(dplyr)

② 오답: 통상적 설치 표현이 아님

install.packages(dplyr)
library("dplyr")

①이 가장 적절한 이유: install.packages()에 일반적으로 문자열 패키지명을 넘겨 설치하고, 그 다음 library()로 불러옵니다.

②의 함정: library("dplyr") 자체는 정상적인 R 문법입니다. 문제는 install.packages(dplyr)가 일반적인 초보 학습 문맥에서 문자값으로 정의되지 않은 객체를 참조한다는 점입니다. 미리 그 이름의 문자열 객체가 정의되어 있다면 작동할 수 있으므로 ‘어떤 경우에도 불가능’하다고 이해하면 안 됩니다.

③·④의 함정: 새로 설치해야 하는 패키지를 먼저 library()로 로드하려는 순서가 뒤바뀌었습니다.
