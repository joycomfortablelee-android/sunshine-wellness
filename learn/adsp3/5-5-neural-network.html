QUESTION 01

가중치의 역할

43회 기출
관련 문제
인공신경망 모형에서 가중치의 역할로 가장 적절한 것은?
① 데이터 차원 증대
② 입력 신호 강도 조절
③ 모형 복잡도 감소
④ 결과 데이터 크기 조절
정답 ②

가중치는 입력 신호의 중요도를 학습하는 과정에서 조절되며, 각 입력 노드의 영향을 반영하여 결과를 도출하는 데 핵심적인 역할을 한다. 나머지 선택지들은 가중치의 역할과는 무관하며, 데이터 차원 증대나 모형 복잡도 감소는 다른 기법에 해당한다.

핵심 암기 · 가중치(Weight) = 입력 신호의 "중요도·강도" 조절

QUESTION 02

무작위 노드 제거로 일반화 성능을 높이는 기법

38회 기출
관련 문제
전체 신경망 노드 중 무작위로 노드를 선정해 다수의 모형을 구성하여 학습하고 각 모형의 결과를 결합해 예측 및 분류하는 기법은?
① 부스팅(Boosting) 기법
② 드롭아웃(Dropout) 기법
③ 결정 트리(Decision Tree) 기법
④ 아다부스팅(Adaboosting) 기법
정답 ②

드롭아웃은 학습 과정에서 무작위로 일부 노드를 제거하여 과적합을 방지하고, 모델의 일반화 성능을 향상시키는 기법이다. 부스팅, 결정 트리, 아다부스팅은 양상블 학습 기법에 해당하며, 드롭아웃과는 다른 방식이다.

핵심 암기 · 드롭아웃 = 신경망 "내부" 노드를 랜덤하게 끄는 과적합 방지 기법
