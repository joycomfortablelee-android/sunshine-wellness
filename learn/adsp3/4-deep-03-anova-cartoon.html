1. 개요 · 핵심 원리p.275

분산분석은 집단 간 차이와 집단 내부의 들쭉날쭉함을 비교합니다.

예를 들어 A·B·C 세 반의 평균 시험점수가 정말 다른지 알고 싶을 때, 반별 평균 차이가 학생들의 점수 편차에 비해 충분히 큰지 살펴봅니다.

1-14지선다

세 반의 평균점수가 서로 얼마나 다른지를 나타내는 것은?

집단 간 변동은 각 집단의 평균과 전체 평균 사이의 차이를 나타냅니다. 반면 집단 내 변동은 같은 반 학생들끼리 점수가 얼마나 퍼져 있는지 보여 줍니다.

1-24지선다

반별 점수 퍼짐이 동일한 상황에서 반 평균 사이의 차이가 더 커진다면?

집단 내 평균제곱(MSW)이 일정하고 집단 간 평균제곱(MSB)이 커지면, F = MSB ÷ MSW이므로 F값이 커집니다.

＋ 이 이론의 문제 직접 적기
입력 내용은 이 브라우저에서 자동 저장을 시도합니다.
1. 개요 · 분석 명칭 구분p.275

변수가 몇 개인지 보면 분석 이름이 정해집니다.

독립변수(요인)는 영향을 살펴볼 분류 기준, 종속변수(반응값)는 비교할 결과입니다.

분석 이름 정하기 · 변수가 몇 개인지 세면 이름이 쉬워져요.

암기 팁: 독립변수(요인)는 그룹을 나누는 기준, 종속변수는 평균을 비교할 결과예요.

③ ANOVA 유형 선택일원 · 이원 · 다원배치
별도 갈림길분석하려는 종속변수가 2개 이상이면 다변량 분산분석 MANOVA를 고려합니다. (독립변수 개수에 따라 단순히 정해지는 것이 아닙니다.)
독립 1개 · 종속 1개

일원배치
One-Way ANOVA

한 가지 분류 기준에 따른 평균 비교
예: 학급별 시험점수 비교
독립 2개 · 종속 1개

이원배치
Two-Way ANOVA

두 요인 및 그 상호작용 분석 가능
예: 학급 × 수업방식별 점수
독립 3개 이상 · 종속 1개

다원배치
Multi-Way ANOVA

여러 요인의 주효과·상호작용
예: 학급 × 방식 × 학습시간
종속 2개 이상

다변량
MANOVA

서로 관련된 여러 결과변수 비교
예: 시험점수 + 만족도 함께 분석

시험에서 헷갈리는 독립변수 / 종속변수

독립변수 · Independent variable
학급 A / B / C

어느 반에 속하는지, 즉 집단을 나누는 기준입니다.

종속변수 · Dependent variable
시험 점수 (점)

어떤 값의 평균을 비교할지, 즉 결과를 나타내는 수치입니다.

※ 이 장에서는 요인은 범주형, 종속변수는 연속형인 전형적인 ANOVA를 설명합니다. 요인이 2개 이상이라고 해서 MANOVA가 되는 것은 아닙니다.

2. 일원배치 분산분석 · 원리p.275

일원배치 ANOVA: 세 반 평균이 모두 같을까?

🟨 초등학생도 이해하는 4컷 만화
귀무가설과 F검정 · “모두 같은가?”를 먼저 물어봐요.
1
👩‍🏫
먼저 가정! “A반, B반, C반의 평균은 모두 같다.” 이것이 귀무가설이에요.
2
🔍
이제 자료를 보고 반끼리 차이가 반 안의 퍼짐보다 큰지 살펴봐요.
3
➗
그래서 F = 집단 간 평균제곱 ÷ 집단 내 평균제곱을 계산해요.
4
🚦
F가 크고 p값이 작으면 “모두 같다고 보기 어렵다!”고 판단해요.
p < .05 이면 보통 기각
중요: ANOVA가 유의하다고 해서 모든 반이 전부 다르다는 뜻은 아니에요. 적어도 한 집단이 다르다는 뜻이에요.
귀무가설 H₀

모든 집단의 모집단 평균이 같다

H₀: μA = μB = μC

세 반이 실제로는 같은 평균을 가진다고 가정합니다.

대립가설 H₁

적어도 한 집단의 평균이 다르다

H₁: 모든 μ가 같지는 않다

모든 쌍이 각각 달라야 하는 것은 아닙니다.

F-검정, 왜 분산을 나눌까?

F = 집단 간 평균제곱 (MSB) / 집단 내 평균제곱 (MSW)
F ≈ 1평균 차이가 크지 않아 보임

일반적으로 집단 내 변동과 비슷한 크기

F가 큼집단 간 차이가 상대적으로 큼

귀무가설을 의심할 근거가 커질 수 있음

p-value유의수준 α와 비교

예: p < .05이면 H₀ 기각

주의F값이 얼마나 커야 하는지는 자유도에 따라 달라집니다. 따라서 F값만으로 무조건 기각하지 않고, p-value 또는 해당 자유도의 임계값을 확인합니다.

일원배치 ANOVA를 적용할 때 기본적으로 살펴볼 가정

① 관측치 독립성
한 학생의 점수가 다른 학생의 점수에 독립적으로 관측되는지
② 오차의 정규성
각 집단의 오차(또는 잔차)가 대체로 정규분포를 따르는지
③ 등분산성
집단별 오차 분산이 같은지
실무 보충집단별 표본 수는 서로 달라도 됩니다. 다만 등분산성이 크게 위배될 때는 Welch ANOVA 같은 대안을 검토합니다.

세 집단의 일원배치 분산분석에서 귀무가설(H₀)은?

귀무가설은 μA = μB = μC입니다. 대립가설은 적어도 하나의 집단 모평균이 다르다는 뜻이지, 모든 집단이 각각 달라야 한다는 뜻은 아닙니다.

3-24지선다

ANOVA 결과가 p = .03, 유의수준 α = .05일 때 적절한 결론은?

p(.03) < α(.05)이므로 모든 모평균이 같다는 귀무가설을 기각합니다. 어떤 쌍이 다른지는 별도의 사후검정으로 확인합니다.

SS → df → MS → F
공식 읽기 팁: B는 Between(집단 간), W는 Within(집단 내)예요. 그래서 MSB와 MSW를 나누면 “반끼리 차이 / 반 안의 퍼짐”이 됩니다.

위 표는 이전 장의 슬라이더와 연동됩니다. 숫자는 고정된 교재 자료가 아니라 원리 설명을 위한 가상 예제입니다.

집단 간 변동: SSB
SSB = ∑i=1k ni(x̄i − x̄)2

각 집단 평균과 전체 평균의 거리. 차이에 집단 표본수 ni를 반영합니다.

집단 내 변동: SSW
SSW = ∑i=1k ∑j=1nᵢ (xij − x̄i)2

각 관측값과 자기가 속한 집단 평균의 거리입니다.

전체 변동: SST
SST = ∑i=1k ∑j=1nᵢ (xij − x̄)2

각 관측값과 전체 평균의 거리이며 SST = SSB + SSW입니다.

MSB = SSB / (k−1)
MSW = SSW / (N−k)
F = MSB / MSW
기호 정리k: 집단 수 / ni: i집단의 관측치 수 / N = Σni: 전체 관측치 수 / x̄i: i집단 표본평균 / x̄: 총평균 / xij: i집단 j번째 관측치. B = Between, W = Within.

집단 수 k = 3, 전체 관측치 수 N = 15이면 올바른 자유도는?

집단 간 자유도는 k − 1 = 2, 집단 내 자유도는 N − k = 12, 전체 자유도는 N − 1 = 14입니다.

5-24지선다

SSB = 80, dfB = 2, SSW = 120, dfW = 12일 때 F값은?

MSB = 80 ÷ 2 = 40, MSW = 120 ÷ 12 = 10이므로 F = 40 ÷ 10 = 4입니다. SS에서 df를 나누어 MS를 얻고, 그다음 두 MS를 나눕니다.

ANOVA에서 유의한 차이를 확인한 뒤 ‘어느 두 집단’이 다른지 알고 싶다면?

전체 F검정은 최소한 하나의 모평균 차이가 있다는 결론에 해당합니다. 어느 집단 쌍이 다른지 확인하려면 Tukey HSD 등의 사후검정을 검토합니다.

다음 중 ANOVA 결과 해석으로 옳은 것은?

유의한 ANOVA는 모든 모평균이 동일하지 않다는 것을 의미합니다. 모든 쌍에서 차이가 난다는 뜻은 아니며, 유의하지 않다고 동일함이 증명되는 것도 아닙니다.
