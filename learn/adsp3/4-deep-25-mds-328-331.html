02 · 시작하기 p. 328

다차원 데이터를 눈에 보이는 지도로!

다차원척도법(Multidimensional Scaling, MDS)은 대상 사이의 가까움·멀어짐을 2차원 또는 3차원에 표현하는 방법입니다.

개념 그림 · 여러 특성 → 한 장의 관계 지도
한 문장 핵심: “묶는 것보다, 서로 어떤 위치 관계인지 보여준다.”

기본 그림에서 확인할 내용

  • MDS의 목적을 설명하고 군집분석과 구별한다.
  • 유클리드 거리로 대상 간 비유사성을 계산한다.
  • Stress 값이 지도 표현의 오차를 뜻함을 설명한다.
  • 계량적·비계량적 MDS의 차이를 비교한다.
  • 기출 60번을 이론적으로 근거를 들어 해결한다.
시험 포인트 · MDS = 거리 구조의 시각화 / 군집분석 = 그룹 분류

※ 본 교안의 개념도·표본 점 좌표는 이해를 위한 예시입니다. 실제 데이터에 대한 추정 결과와 구별해 제시합니다.

05 · 대상 간 거리 p. 328

유클리드 거리 = 점 사이의 직선거리

B점을 마우스나 손가락으로 움직여보세요. 수평·수직 차이와 직선거리가 함께 변합니다.

움직이는 좌표 평면
가로 차이 Δx세로 차이 Δy직선거리 d

피타고라스 정리를 이용

d(A,B) = √[(x₂−x₁)² + (y₂−y₁)²]

두 대상의 변수값을 좌표로 보면, 각 변수의 차이 제곱을 더한 후 제곱근을 구합니다.

가로 차이 |Δx|4
세로 차이 |Δy|3
거리 = √(4² + 3²) = 5.00

두 변수 이상일 때도 같은 원리로 각 차원의 차이 제곱을 합합니다. 변수의 단위·범위가 많이 다르면 표준화 여부를 검토해야 합니다.

06 · 적합도: Stress p. 328

Stress가 작을수록 원래 거리관계를 잘 표현

2차원에 억지로 줄이면 원래 거리와 표현된 거리가 달라질 수 있습니다. 그 차이를 나타내는 적합도 지표가 Stress입니다.

원래 거리와 지도에서 표현된 거리의 차이
원래 거리 D지도 표현 거리 d
26%
예시 Stress ≈ 0.10

Stress 해석 기준 · 교재의 경험적 분류

0
완벽0~0.05
매우 좋음0.05~0.10
만족0.10~0.15
보통0.15 이상
나쁨
Stress ≈ √[Σ(Dᵢⱼ − dᵢⱼ)² / ΣDᵢⱼ²]
  • Dᵢⱼ: 원래 데이터의 비유사성 또는 거리
  • dᵢⱼ: 저차원 지도에서의 두 점 사이 거리
  • 오차가 작다 → Stress가 작다 → 표현의 왜곡이 작다
자주 나오는 판단: Stress가 작을수록 적합도가 높다.

※ 위 그래프는 개념 학습용이며 실제 MDS 최적화 결과가 아닙니다. Stress에는 Stress-1, S-Stress 등 여러 정의가 있고, 비계량 MDS에서는 단조변환된 비유사성을 사용하기도 합니다. 절단 기준도 자료·차원·표본 수에 따라 달라지므로 절대적 합격선은 아닙니다.

07 · 계량적 다차원척도법 (Metric MDS) p. 329

거리의 수치적 크기를 가능한 한 보존

구간척도·비율척도 기반의 비유사성 자료에서 활용하며, 실제 거리 차이를 공간 안에 표현하려 합니다.

유럽 도시 거리의 2차원 배치 · 개념도
실제 좌표를 그릴 때 거리의 크기가 중요합니다. 두 도시가 멀수록 점도 멀리 놓이도록 시도합니다.

교재 예시 · cmdscale()

  • 데이터: 유럽 21개 도시 간 도로 거리(eurodist)
  • 분석: cmdscale()로 2차원 좌표 추정
  • 그림: 좌표별 도시 이름을 표시
R 코드 · 실행 가능한 수정 예시
data(eurodist)  # datasets 패키지 기본 데이터
loc <- cmdscale(eurodist, k = 2)
plot(loc[, 1], -loc[, 2], type = "n",
     asp = 1, main = "Metric MDS",
     xlab = "Dimension 1", ylab = "Dimension 2")
text(loc[, 1], -loc[, 2],
     labels = rownames(loc), cex = 0.7)
abline(h = 0, v = 0, lty = 2)

코드 검토: eurodist는 datasets 기본 데이터입니다. 원문에서 잘못 인식된 y <— 2] 등의 기호를 수정했습니다. 두 번째 좌표의 부호 반전은 화면의 상하 방향을 바꾸는 표시 선택이며 점 간 거리를 바꾸지 않습니다.

08 · 비계량적 다차원척도법 (Nonmetric MDS) pp. 329–330

거리의 정확한 값보다 가까움의 순서를 보존

순서척도 또는 상대적인 유사성 순위가 핵심일 때 유용합니다.

예시 · 거리 값이 달라져도 ‘순서’는 그대로
원래 비유사성 값
AB = 2
AC = 5
BC = 9
AB 가장 가까움BC 가장 멂
2차원 표현 거리
AB = 1.4
AC = 3.6
BC = 4.2
AB 가장 가까움BC 가장 멂
값은 달라도 순위는 동일: AB < AC < BC
이것이 비계량적 MDS의 핵심 직관입니다.

위 세 쌍의 숫자는 순위 비교용이며, 실제 2차원에서 구현한 좌표·모형 결과를 의미하지 않습니다.

교재 예시 · isoMDS()

  • 데이터: 스위스 47개 지역 자료 swiss
  • 입력: 변수로부터 계산한 거리행렬
  • 분석: 단조변환으로 비유사성의 순위를 보존하도록 배치
R 코드 · 비계량적 MDS
library(MASS)      # isoMDS 함수
 data(swiss)       # datasets의 기본 데이터
swiss.x <- as.matrix(swiss[, -1])
swiss.dist <- dist(scale(swiss.x))
set.seed(42)
swiss.mds <- isoMDS(swiss.dist, k = 2)
plot(swiss.mds$points, type = "n",
     main = "Nonmetric MDS")
text(swiss.mds$points,
     labels = seq_len(nrow(swiss.x)), cex = 0.7)
abline(h = 0, v = 0, lty = 2)

이 예시는 변수의 단위 차이를 완화하기 위해 scale()을 추가한 학습용 코드입니다. isoMDS는 MASS 패키지 함수이며, swiss 데이터 자체는 datasets에 속합니다.

09 · Sammon mapping p. 330

가까운 점들의 거리를 더 민감하게 보존하려는 방법

Sammon 매핑은 작은 원래 거리에 더 큰 가중치를 주는 비선형 차원 축소 방법입니다.

거리 손실의 중요도가 왜 다를까요?
Sammon은 비계량적 MDS와 동의어가 아닙니다. 작은 거리를 중시하는 별도의 비선형 거리 보존 방식입니다.

교재 예시 · sammon()

  • 원래 거리가 작은 관측치 쌍에서의 상대적인 오차를 특히 중요하게 반영합니다.
  • 입력은 dist() 형태의 거리 정보입니다.
  • isoMDS: 순서 보존 / sammon: 작은 거리 오차에 가중치를 둔 거리 보존
R 코드 · Sammon mapping
library(MASS)
data(swiss)
swiss.x <- as.matrix(swiss[, -1])
swiss.sammon <- sammon(
  dist(scale(swiss.x)), k = 2)
plot(swiss.sammon$points, type = "n",
     main = "Sammon Mapping")
text(swiss.sammon$points,
     labels = seq_len(nrow(swiss.x)), cex = 0.7)
abline(h = 0, v = 0, lty = 2)

교재에서 isoMDS와 함께 소개되더라도 Sammon 매핑을 단순히 “순위만 보존하는 비계량적 MDS”로 외우면 부정확합니다.
