문제 7번 보기
📘 문제 7번 정답 · 상세 해설펼치기

정답 ② 1/5

먼저 양성(TRUE)을 기준으로 TP=30, FP=170, FN=70, TN=40을 확인합니다. 정밀도는 30/(30+170)=3/20, 재현율은 30/(30+70)=3/10입니다. 두 지표의 조화평균을 계산하면 F1 = 2 × (3/20 × 3/10) ÷ (3/20 + 3/10) = 1/5입니다.

💡 학습 포인트　분모에서 정밀도는 ‘예측 TRUE 전체’, 재현율은 ‘실제 TRUE 전체’입니다.

정답 ② 검증용 데이터 (Validation Data)

정답은 검증용 데이터(Validation Data)입니다. 학습용 데이터로 가중치와 계수를 학습하고, 검증용 데이터의 결과를 바탕으로 하이퍼파라미터와 모델 구성을 조정합니다. 테스트 데이터는 이러한 선택이 끝난 후 최종 일반화 성능을 확인하는 데 사용하며, 조정에 반복 사용하면 평가가 낙관적으로 치우칠 수 있습니다.

💡 학습 포인트　학습(모형 추정) → 검증(선택·조정) → 시험(최종 확인) 순서로 기억하세요.

정답 ① 덴드로그램 (Dendrogram)

덴드로그램은 관측치가 어떻게 단계적으로 묶이는지 나타내는 계층적 군집분석의 도구입니다. ROC, 누적 이익 도표 및 PR 곡선은 분류모형의 판별력이나 상위 대상자 선별 성능 등을 살펴보는 데 활용할 수 있습니다.

💡 학습 포인트　덴드로그램은 ‘군집 형성 과정’, ROC·PR·이익도표는 ‘분류 성능’을 떠올리세요.

정답 ② 이익도표 (Lift Chart)

이 문항이 의도한 정답은 이익도표(Lift Chart)입니다. 예측확률 순으로 고객을 정렬하고 분위(예: 10개 등급)별 반응률·반응검출율·향상도(Lift)를 비교합니다. 혼동행렬은 등급별 반응이 아니라 실제 분류값과 예측 분류값의 교차 빈도를 보여줍니다.

💡 학습 포인트　문항의 표현이 다소 넓습니다. 시험에서는 “예측점수 기준 등급·반응률·리프트”를 단서로 구분하는 것이 정확합니다.

📘 문제 11번 정답 · 상세 해설펼치기

정답 ④ 재현율 (Recall)

재현율(Recall)=민감도(Sensitivity)=TPR(True Positive Rate)입니다. 실제 양성인 사례(TP+FN) 중 올바르게 양성으로 예측한 TP의 비율이므로 TP/(TP+FN)으로 계산합니다. 양성 사례를 놓치지 않는 능력을 평가합니다.

💡 학습 포인트　“실제 양성 중 잡아낸 비율” = Recall = Sensitivity.

문제 12번 보기

정답 ② 특이도 (Specificity)

특이도(Specificity)=TN/(TN+FP)로, 실제 음성(Negative) 사례 중 음성으로 정확히 예측한 비율입니다. 민감도는 실제 양성에서 양성을 맞힌 비율이라는 점에서 서로 구분해야 합니다.

💡 학습 포인트　“실제 음성 중 음성으로 맞힌 비율” = Specificity.
※ 문제 10의 교재 표현은 다소 포괄적입니다. 등급(분위)별 반응·향상도를 보는 이익도표와 실제값×예측값을 교차시키는 혼동행렬을 구분해 학습하세요.

보충설명 ② · ROC/AUC · PR 곡선 · 이익도표

기출 9 · 10번 연결 · 교재 p.386–389

① ROC 곡선 · Receiver Operating Characteristic

x축 FPR = FP/(FP+TN), y축 TPR = TP/(TP+FN). ROC 곡선은 분류 임계값을 여러 수준으로 바꾸어 만듭니다. AUC는 곡선 아래 면적으로, 일반적으로 클수록 구분력이 높습니다.

※ 모양은 이해를 위한 예시이며, 기출 7번 혼동행렬만으로 계산한 ROC가 아닙니다.

② 정밀도–재현율 곡선 · Precision–Recall

재현율을 높이려 할 때 정밀도가 어떻게 변하는지 보여줍니다. 특히 양성 사례가 드문 클래스 불균형 상황에서 ROC와 함께 확인할 가치가 있습니다.

※ 이 그래프 역시 설명용 예시입니다. 곡선을 구하려면 다양한 임계값의 예측점수가 필요합니다.

③ 이익도표 · Lift Chart

전체 고객 2,000명, 구매자 381명이라는 교재 예시를 사용합니다. 예측확률이 높은 순서로 상위 200명을 선정했더니 실제 구매자가 174명이었습니다.

🔍 차이를 구분하는 표

혼동행렬하나의 임계값에서 실제·예측 분류의 교차 빈도 (TP/FP/FN/TN)
ROC · AUC임계값 변화에 따른 TPR과 FPR의 관계, 전반적 분리 능력
PR 곡선재현율(Recall)과 정밀도(Precision)의 관계
이익도표예측점수 순위/등급별 반응률과 Lift, 마케팅 타깃 선별
덴드로그램계층적 군집분석의 합쳐짐·분리됨을 보여주는 도구
⚠️ ROC/AUC 해석 주의: AUC 0.5는 일반적으로 무작위 순위 수준, 1은 완벽한 구분력입니다. 단일 AUC 수치만으로 일반화 성능이나 과대적합 여부까지 단정할 수는 없습니다.

보충설명 ③ · 과대적합과 과소적합 · 검증의 역할

기출 8번 연결 · 교재 p.389–390

① 과소적합 · Underfitting

모형이 너무 단순해 학습 데이터의 구조도 충분히 설명하지 못하는 상태

② 적절한 일반화 · Generalization

관측치의 전반적인 패턴을 학습해 새로운 데이터에도 적용 가능한 상태

③ 과대적합 · Overfitting

학습 데이터의 우연적 변동까지 따라가 새로운 데이터에서 성능이 저하될 수 있는 상태

학습용 데이터
가중치·계수 추정→검증용 데이터
과대·과소적합 점검·조정→시험용 데이터
최종 일반화 성능 평가
🧭 Bias–Variance Trade-off: 복잡도를 높이면 편향은 낮아질 수 있지만 분산이 커져 과대적합 위험이 발생할 수 있습니다. 따라서 검증 성능을 기준으로 적절한 복잡도를 선택합니다.

보충설명 ④ · 클래스 불균형과 시험 함정 정리

교재 p.385–390 핵심 개념 요약

⚖️ 클래스 불균형 · Class Imbalance

전체 1,000명 중 실제 양성 15명, 음성 985명이라고 가정합니다. 모든 사례를 음성으로만 예측해도 정확도는 985/1,000 = 98.5%이지만, 실제 양성 15명은 단 한 명도 찾아내지 못합니다(재현율 0%).

음성 집단98.5%
양성 집단1.5%

이처럼 정확도만 보면 좋은 모형으로 착각할 수 있으므로 재현율·정밀도·F1·PR 곡선 등을 함께 확인합니다.

💡 자주 혼동되는 다섯 가지

민감도 = 재현율실제 양성을 얼마나 잘 찾아내는가?
특이도실제 음성을 얼마나 정확히 판정하는가?
정밀도양성이라고 예측한 값이 얼마나 정확한가?
F1정밀도와 재현율의 조화평균 (0~1)
Lift구간 반응률 ÷ 전체 반응률 (1을 넘을 수 있음)

🧠 FP vs FN

FP: 실제 음성 → 양성이라고 잘못 예측. FN: 실제 양성 → 음성이라고 잘못 예측. (분류 오류를 설명할 때 각각 1종·2종 오류로 연결하기도 합니다.)

🎯 모델 평가의 단계

검증 자료로 모형을 고른 뒤 테스트 자료를 모델 선택에 반복 활용하지 않는 것이 중요합니다. 시험용 데이터는 최종 평가에 남겨둡니다.

📊 정답 공식 우선순위

계산형은 Precision → Recall → F1 순서. 구분형은 실제 양성 / 실제 음성 / 예측 양성 중 무엇이 분모인지 먼저 확인합니다.
