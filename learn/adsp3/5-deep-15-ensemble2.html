02 / ENSEMBLE CONCEPT교재 424–425쪽교재 원문 기반

왜 모델을 여러 개 사용할까?

앙상블(Ensemble)은 여러 개의 기본 예측기(Base Learner)를 결합하는 학습 방법입니다.

🌱

03 / BOOTSTRAP교재 426쪽원문 연계 실습

붓스트랩: 같은 자료를 복원추출

Bootstrap Sampling · 원본 데이터에서 뽑은 자료를 다시 넣고 반복 추출하므로 중복이 발생할 수 있습니다.

① 원본 데이터 7개

ABCDEFG

한 번에 1개를 뽑고, 다시 넣은 후 다음 데이터를 뽑습니다.

붓스트랩 표본은 일반적으로 원본 데이터와 같은 개수로 구성합니다.

② 생성한 붓스트랩 표본

중복

같은 관측치가 여러 번 뽑힐 수 있음

OOB

해당 표본에 선택되지 않은 관측치

≈ 63.2%

원본 표본 크기가 커지면 한 붓스트랩 표본에 포함되는 서로 다른 관측치의 기대 비율

OOB(Out-of-Bag)는 선택되지 않은 관측치를 활용하여 예측 성능을 점검하는 데 사용할 수 있습니다. 63.2%는 큰 표본에서의 근삿값입니다.

05 / BOOSTING교재 428쪽교재 원문 기반

부스팅: 이전 모델의 실수를 보완

Boosting · 약한 학습기를 순차적으로 추가하며 예측오차를 줄여 나갑니다.

MODEL 01첫 번째 학습

기본 예측 및 오차 확인

MODEL 02오차에 집중

이전의 약점을 보완

MODEL 03다시 보완

손실을 더 줄이도록 학습

FINAL최종 결합

가중합 등으로 예측

⚖️

AdaBoost

틀린 관측치의 가중치를 높여 다음 약한 학습기가 어려운 사례에 더 집중하도록 합니다.

오분류 관측치 → 다음 학습에서 비중 ↑
📉

Gradient Boosting

현재 모델의 손실함수를 줄이는 방향으로 새 학습기를 순차적으로 추가합니다.

손실의 음의 기울기 방향 → 개선
핵심 차이 · 배깅은 모델을 병렬로 만들 수 있지만, 부스팅은 일반적으로 이전 단계의 결과가 다음 학습에 영향을 주므로 순차적입니다.
06 / RANDOM FOREST교재 429–431쪽교재 원문 기반

랜덤포레스트 = 배깅 + 변수 무작위 선택

Random Forest · 관측치뿐 아니라 분기 후보 변수까지 무작위로 제한해 서로 다른 의사결정나무를 만듭니다.

원본 자료관측치 + 여러 특성
→

교재 표현 바로잡기 · 랜덤포레스트가 기본적으로 모델별 가중치를 부여해 선형결합하는 것은 아닙니다. 일반적인 랜덤포레스트는 분류 시 투표(또는 확률 평균), 회귀 시 평균을 사용합니다. 위 특성 조합은 원리 설명을 위한 예시입니다.

10 / EXAM CAUTIONS교재 425·429쪽 연계보충 해설

교재 문장에서 주의할 표현 4가지

암기할 때 지나친 일반화와 알고리즘별 차이를 구분하면 시험과 실제 분석에서 모두 유리합니다.

주의 ①

“랜덤포레스트는 가중치 선형결합”

수정: 일반적 랜덤포레스트는 분류 시 투표/확률 평균, 회귀 시 예측값 평균을 사용합니다.

주의 ②

“1-NN은 가장 안정적인 방법”

수정: 1-NN은 표본 변화·잡음·이상치의 영향에 민감할 수 있습니다. 가장 안정적이라고 일률적으로 판단하기 어렵습니다.

주의 ③

“모형 간 독립성이 높을수록 무조건 좋음”

수정: 오차 상관이 낮고 각 모델이 충분한 예측력을 가질 때 결합 이점이 커질 수 있습니다. 다양성만으로는 부족합니다.

주의 ④

“앙상블은 과대·과소적합 해결”

수정: 일반화 성능을 개선할 수 있지만 보장하지는 않습니다. 기법·데이터·하이퍼파라미터에 따라 달라집니다.

실전 답변 · “여러 예측기의 결과를 결합하며, 개별 예측기의 정확성과 오류 간 상관관계를 함께 고려해야 앙상블의 성능 향상을 설명할 수 있다.”
