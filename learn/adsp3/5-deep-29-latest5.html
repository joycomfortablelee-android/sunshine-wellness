01 밀도기반 vs 02 병합적 군집

밀집 영역을 찾는가? 개별 데이터부터 차례로 합치는가?

교재 463–464쪽
01 DBSCAN Density-Based Spatial Clustering of Applications with Noise

점들이 충분히 밀집된 영역을 하나의 군집으로 묶고, 희박한 곳의 점을 잡음(Noise)으로 판정할 수 있습니다.

핵심 파라미터 ε(Eps, 이웃 반경), MinPts(최소 이웃 점 수)
장점 군집 수 K를 미리 정하지 않음 · 임의 모양의 군집 탐지 · 잡음 분리
주의 밀도 차이가 크거나 고차원 데이터에서는 어려울 수 있음
시험 암기 K값 지정 불필요 / 밀도 기반 / 이상치를 잡음으로 처리 가능. 다만 DBSCAN도 ε 안에 있는 점을 판단하기 위해 거리·이웃 개념을 사용합니다.
02 병합적 군집 Agglomerative Hierarchical Clustering

각 관측치를 하나의 군집으로 시작하고, 가장 가까운 군집끼리 반복적으로 병합하여 계층을 형성합니다.

진행 각 점 = 1개 군집 → 유사한 두 군집 병합 → 덴드로그램
연결 기준 최단(Single) · 최장(Complete) · 평균(Average) · Ward 등
특징 덴드로그램을 자르는 높이에 따라 군집 수 선택
주의 대용량에서 계산·메모리 부담이 커질 수 있음
시험 암기 하향식 분할이 아니라 상향식 병합입니다. ‘병합적’은 최신 기술만의 이름이 아니라 계층적 군집의 한 유형입니다.

03 퍼지 군집 vs 04 스펙트럼 군집

한 점이 여러 군집에 얼마나 소속되는가? 데이터의 연결 구조는 어떠한가?

교재 464쪽
03 퍼지 군집 Fuzzy Clustering · Fuzzy C-Means(FCM)

각 점에 특정 군집을 단정하는 대신, 여러 군집에 대한 소속도(Membership)를 부여합니다.

대표 기법 FCM(Fuzzy C-Means)
작동 중심과 거리 등을 고려해 각 군집에 대한 소속도를 갱신
유용한 경우 서로 겹치는 특성을 가진 고객·관광객 세분화
주의 초기값·군집 수 설정에 민감할 수 있고 해석이 복잡
개념 정확성 FCM의 소속도는 반드시 확률모형에서 나온 ‘확률’과 같은 뜻은 아닙니다. 일반적인 FCM에서는 한 점의 군집별 소속도 합이 1입니다.
04 스펙트럼 군집 Spectral Clustering

데이터 사이의 유사도 그래프를 만든 뒤, 행렬의 고유벡터(Eigenvector) 정보를 이용해 군집을 구분합니다.

흐름 유사도 행렬 → 그래프 라플라시안 → 고유벡터 → 군집화
장점 비선형·복잡한 경계의 군집 탐지에 유용
활용 이미지 분할, 네트워크, 복잡한 패턴 인식
주의 행렬 연산 부담, 유사도 구성·군집 수 선택에 민감
시험 암기 그래프 이론 + 고유값·고유벡터. 고유벡터 공간으로 데이터를 표현한 후 K-means 같은 방법으로 최종 군집을 만드는 방식이 흔합니다.

05 PAM — 평균이 아닌 실제 관측치가 중심

PAM은 비계층적·분할형 군집입니다. K-means와의 차이를 정확히 구별하세요.

교재 464–465쪽
05 PAM Partitioning Around Medoids

군집의 대표를 산술평균이 아니라 실제 관측치 중 하나인 메도이드(Medoid)로 선택합니다.

방법 메도이드 후보를 정하고, 군집 내 거리의 합 등을 줄이는 방향으로 대표점을 교체
장점 평균을 활용하는 K-means보다 이상치에 상대적으로 강건
한계 K 지정 필요 · 계산량이 커질 수 있음
시험 암기 PAM = Medoid(실제 데이터 점) / K-means = Mean(산술평균). 메도이드가 이상치의 영향을 줄일 수 있지만 이상치에 완전히 무관한 것은 아닙니다.

DI 군집모형 평가 · Dunn Index

군집 간 거리는 멀고, 같은 군집 내부는 조밀할수록 좋은 군집입니다.

DI = 군집 사이 분리도(최솟값)군집 내부 지름(최댓값)
분자 ↑ 서로 다른 군집이 잘 분리됨
분모 ↓ 동일 군집의 점들이 더 조밀함
따라서 다른 조건이 같다면 DI가 클수록 군집 품질이 더 좋다고 해석
Silhouette Coefficient와 구별
실루엣 계수는 각 관측치의 자기 군집 내 평균거리 a와 가장 가까운 다른 군집까지의 평균거리 b를 이용합니다.
s = (b − a) / max(a, b)
