01 · DEFINITION

인공신경망이란?

Artificial Neural Network: 다수의 뉴런(노드)을 연결해 입력과 출력 사이의 패턴을 학습하는 모형

교재 433–435쪽첨부 PDF 56–58쪽
01 / 개념
🧠

생물학적 영감

뇌의 뉴런·연결이라는 아이디어를 참고합니다. 실제 뇌를 그대로 복제한 모델은 아닙니다.

🔗

수치적 연결

입력값에 가중치(weight)를 곱하고 편향(bias)을 더해 노드에서 계산합니다.

🎯

오차 최소화

예측과 정답의 차이를 손실함수로 평가하고, 학습 과정에서 매개변수를 갱신합니다.

관광 데이터 예시: 예약 취소 여부 예측

입력 변수 X예약일수 · 숙박기간 · 과거취소
→
ANN 학습가중치 × 입력 + 편향
비선형 활성화
→
결과 ŷ취소 확률 0~1
분류 기준으로 최종 판단
분류(Classification)
예약 취소 / 유지, 이탈 / 유지처럼 범주를 예측합니다.
회귀(Regression)
관광객 지출액·방문수요처럼 연속적인 수치를 예측할 수도 있습니다.
시험 핵심: ANN은 지도학습 분류·회귀에 활용되며, 여러 층과 비선형 활성화함수를 통해 복잡한 패턴을 표현합니다.
02 · ARCHITECTURE

입력층 → 은닉층 → 출력층

노드는 정보를 계산하는 단위, 연결선의 가중치는 학습으로 조절하는 수치입니다.

교재 435–437, 441쪽첨부 PDF 58–60, 64쪽
02 / 구조
입력 노드 3개 은닉 노드 4개 출력 노드 2개
입력층 Input Layer

특성값을 받는다

독립변수(설명변수)를 신경망에 전달합니다. 입력층 자체가 항상 복잡한 계산을 하는 것은 아닙니다.

은닉층 Hidden Layer

중간 특징을 학습

가중합과 활성화함수를 통해 데이터의 비선형적 관계를 표현합니다.

출력층 Output Layer

예측값을 만든다

이진분류·다중분류·회귀에 따라 노드 수와 출력 활성화함수가 달라집니다.

암기: 은닉층(Hidden layer)은 중간 계산 단계, 은닉노드(Hidden node)는 은닉층 안의 개별 계산 단위입니다.

아래 값을 움직이면, 가중합과 시그모이드 출력이 즉시 바뀝니다.

03 / 직접 조작
z = w₁x₁ + w₂x₂ + b   →   ŷ = σ(z) = 1 / (1 + e−z)

입력과 가중치 조절

계산 결과

z = 1.2×1.0 + (−0.8)×0.5 + 0.2 = 1.00
시그모이드 출력 σ(z)0.731분류 기준 0.5 적용 시: 1
왜 활성화함수를 사용할까?
단순 가중합 뒤에 비선형 변환을 넣어 신경망이 복잡한 관계를 학습하도록 합니다.
Weight · 가중치

각 입력이 계산에 얼마나 크게 기여하는지 결정하는 학습 매개변수

Bias · 편향

입력의 가중합에 더하는 값으로, 활성화가 일어나는 위치를 조절

Activation · 활성화

가중합을 비선형적으로 변환해 다음 층에 전달

시그모이드는 0~1 사이 값을 출력합니다. 이진분류의 출력층에서 사용할 수 있지만, 모든 층에서 반드시 사용하는 것은 아닙니다.
04 · HISTORY

ANN의 발전: 퍼셉트론에서 딥러닝까지

기본 개념과 역사적 기여를 구분해 이해해 봅시다.

교재 434쪽첨부 PDF 57쪽
04 / 발전사
1943McCulloch & Pitts신경세포의 논리적 계산 모형 제안
1949Hebb연결강도의 학습 원리 제시
1958Rosenblatt퍼셉트론 대표 논문 발표
1969Minsky & Papert단층 퍼셉트론의 표현 한계 분석
1982Hopfield연상기억형 재귀 신경망 연구
1986Rumelhart·Hinton·Williams역전파 학습 방법을 널리 알린 대표 논문
단층 퍼셉트론의 한계

단일 선형 경계만으로는 XOR 분리가 어려움

고전적인 단층 퍼셉트론은 선형 분리 가능한 분류에 적합합니다. 비선형 문제가 왜 어려운지 이해하는 대표 사례가 XOR입니다.

다층 퍼셉트론의 발전

은닉층 + 비선형 활성화 + 역전파

신경망 내부에 표현을 학습하는 은닉층을 두고, 손실에 따른 기울기를 역방향으로 계산해 다층 모형을 효율적으로 훈련합니다.

교재 보완 포인트 · Rosenblatt의 대표 퍼셉트론 논문은 1958년이며, Hopfield의 대표적 업적은 역전파보다 연상기억형 신경망에 관련됩니다. 역전파의 1986년 대표 논문 저자는 Rumelhart, Hinton, Williams입니다.
시험 연결: 퍼셉트론 → XOR 한계 → 다층 구조와 역전파 → 심층 신경망의 흐름으로 기억합니다.

XOR: 왜 은닉층이 필요할까?

XOR(배타적 논리합)는 두 입력이 다를 때 1, 같을 때 0입니다.

x₁x₂정답 y
000
011
101

한 개의 직선으로 두 클래스(0과 1)를 구분할 수 없습니다.

2차원 좌표로 보면?

다층 퍼셉트론의 해결 아이디어

입력 x₁, x₂두 조건의 상태
→
은닉노드 ①OR 특성 추출
은닉노드 ②AND 특성 추출
→
출력 XOROR이면서 AND가 아님

위의 논리 결합은 개념 설명용입니다. 실제 학습에서는 이런 내부 표현을 가중치와 활성화함수로 구현합니다.

정확한 표현: 고전적 단층 퍼셉트론은 XOR를 해결하지 못하지만, 비선형 활성화함수를 가진 다층 퍼셉트론은 해결할 수 있습니다.

06 / 인터랙티브
SIGMOID

시그모이드 함수

σ(z) = 1 / (1 + e⁻ᶻ)

출력값이 0~1입니다. 이진분류의 출력층에서 많이 사용되지만, 입력의 절댓값이 크면 기울기가 작아질 수 있습니다.

선택한 z에서의 출력0.731
개념: 활성화함수의 비선형성이 다층 신경망의 표현력을 높입니다.
함수출력 범위대표적 용도 / 특징
Sigmoid(0, 1)이진분류 출력층, 큰 양·음 입력에서는 포화 가능
Tanh(−1, 1)0을 중심으로 대칭인 변환, 포화 문제 가능
ReLU[0, ∞)은닉층에서 널리 사용, 음수 입력은 0으로 처리
ReLU(z) = max(0, z). 단, ReLU도 항상 최선은 아니며 출력층 함수는 분석 목적에 맞게 선택해야 합니다. (다중분류: Softmax를 자주 사용)

08 / 설계
데이터 입력

수치화와 스케일링

연속형은 원칙적으로 그대로 사용할 수 있으며, 필요하면 표준화합니다. 범주형은 원-핫 인코딩 등의 수치화가 필요합니다.

가중치 초기화

적절한 무작위 초기화

모든 연결을 동일한 0으로 두는 방식은 대칭성 문제를 초래할 수 있습니다. Xavier·He 초기화 등이 대표적입니다.

모형 복잡도

은닉층 수와 노드 수

너무 단순하면 과소적합, 너무 복잡하면 과대적합 가능성이 있습니다. 검증 성능으로 결정합니다.

과소적합 Underfitting

훈련 성능 낮음검증 성능 낮음

복잡한 관계를 충분히 학습하지 못한 상태. 모형 표현력·특성·학습량을 살펴봅니다.

과대적합 Overfitting

훈련 성능 높음검증 성능 상대적 저하

훈련 자료에 지나치게 적응한 상태. 정규화·조기종료·데이터 확보·구조 조절 등을 고려합니다.

교재의 설명과 현대적 실무 권장 비교

교재 표현정확한 이해
입력변수를 구간화하여 범주형으로 이산화항상 필요한 절차가 아닙니다. 연속형 입력은 스케일링해 사용하는 것이 일반적이며, 범주형은 수치 인코딩합니다.
가중치를 0에 가까운 값에서 시작해 높임초기화와 학습 갱신은 별개입니다. 가중치는 양·음 방향 모두 조정되며, 모두 같은 0으로 초기화하는 것은 일반적으로 피합니다.
은닉층은 하나, 노드는 많이 시작해 감소절대 규칙은 아닙니다. 하나의 은닉층도 충분할 수 있지만, 데이터·목적·모형 크기에 맞추어 검증으로 결정합니다.
실무 점검: 훈련/검증/시험 데이터 분리 · 데이터 누수 방지 · 스케일링 · 검증에 따른 하이퍼파라미터 선택

R에서 ANN으로 붓꽃 품종 분류

기본 탑재 데이터 iris와 nnet 패키지로 다중분류를 연습합니다.

09 / 복사 가능
R · nnet · 실행 예제
# install.packages("nnet")  # 최초 1회만 필요하면 실행
library(nnet)
set.seed(123)

# 1. 종별로 훈련 70% / 시험 30% 분할
idx_by_class <- split(seq_len(nrow(iris)), iris$Species)
train_idx <- unlist(lapply(idx_by_class, function(i) {
  sample(i, size = floor(0.7 * length(i)))
}))
train <- iris[train_idx, ]
test  <- iris[-train_idx, ]

# 2. 훈련 데이터 기준으로 표준화 (데이터 누수 방지)
cols <- names(iris)[1:4]
mu <- sapply(train[cols], mean)
sd_v <- sapply(train[cols], sd)
train[cols] <- scale(train[cols], center = mu, scale = sd_v)
test[cols]  <- scale(test[cols], center = mu, scale = sd_v)

# 3. 은닉노드 5개인 단일 은닉층 신경망
fit <- nnet(Species ~ ., data = train,
            size = 5, decay = 0.01,
            maxit = 500, trace = FALSE)

# 4. 시험자료로 예측·평가
pred <- predict(fit, newdata = test, type = "class")
table(실제 = test$Species, 예측 = pred)
mean(pred == test$Species)
