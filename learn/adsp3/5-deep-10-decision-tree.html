노드(Node) 용어

  • 뿌리마디(Root Node): 전체 데이터를 포함하는 시작 마디
  • 부모마디(Parent Node): 분리의 출발점이 되는 상위 마디
  • 자식마디(Child Node): 부모마디에서 나누어진 하위 마디
  • 중간마디(Internal Node): 다시 분리되는 마디(뿌리마디도 자식이 있으면 내부 노드)
  • 끝마디(Terminal / Leaf Node): 추가로 나뉘지 않는 마지막 마디

연결과 깊이

  • 가지(Branch / Edge): 노드를 연결하는 선. 뿌리에서 끝마디까지의 연결 순서를 경로(Path)라고 합니다.
  • 깊이(Depth): 일반적으로 뿌리마디를 0으로 보았을 때 해당 노드까지의 간선 수. 위 예시의 끝마디 깊이는 1입니다.
  • 분기(Split): 한 노드를 조건에 따라 자식마디로 나누는 과정
교재 표현 보완
깊이는 단순히 '중간마디 수'로 정의하기보다 루트부터 해당 노드까지의 경로 길이로 기억하면 정확합니다.

미래 결과 예측

관찰된 규칙으로 구매 여부 또는 매출액을 예측합니다. 분류·회귀 모두 포함
변수 선택

중요한 변수 찾기

여러 후보 중 실제 분리에 활용되는 변수를 살펴봅니다. 단, 한 번의 나무 결과가 변수의 절대적 중요성을 보장하지는 않습니다.
교호작용 · Interaction

조건의 조합 파악

예: 연령에 따라 만족도가 구매에 미치는 영향이 달라지는 규칙을 발견합니다.
구간화 · Discretization

숫자를 규칙으로 나누기

연속형 변수에 기준점을 설정합니다. 예: 만족도 ≥ 4점과 그 미만.

✔ 주요 장점

  • 조건문 형태라 이해와 설명이 쉽다.
  • 연속형·범주형 예측변수를 다룰 수 있다(구현에 따라 전처리 필요).
  • 변수 간 비선형 관계와 교호작용을 규칙으로 표현한다.
  • 표준화가 필수는 아니며 복잡한 가정을 적게 요구한다.
  • 단일 나무는 상대적으로 계산이 간편하고 시각화가 쉽다.

△ 주요 단점과 유의점

  • 나무가 너무 크면 과대적합(Overfitting)이 생긴다.
  • 소량의 데이터 변경으로 분할 구조가 크게 바뀔 수 있다.
  • 축 정렬 분기 때문에 복잡한 결정경계를 표현하기에 비효율적일 수 있다.
  • 탐욕적 분할은 전체 최적해를 보장하지 않는다.
  • 변수 중요도는 계산 가능하지만 상관변수와 분할 편향에 주의한다.
시험·실무 구분 교재에 나오는 “잡음에 민감하지 않다”, “분류 정확도가 높다”는 장점이 항상 성립하는 것은 아닙니다. 단일 나무는 잡음과 작은 표본 변화에 민감할 수 있으므로 교차검증과 가지치기가 중요합니다. 신용평가처럼 이유 설명이 필요한 상황에서는 해석력이, 고객 반응 예측에서는 예측력이 상대적으로 중요할 수 있습니다.

분리규칙과 분리기준 411~412쪽

불순도(Impurity)가 줄어드는 방향으로 데이터를 나눈다

분리규칙(Splitting Rule): 무엇으로, 어디서 나눌까?

연속형 변수
만족도 ≥ 4점 / 만족도 < 4점
수치 기준점(threshold)을 탐색
범주형 변수
{서울, 부산} / {대구, 광주}
범주 집합을 구분(구현별 차이)

이진 분류나무에서 최적 분할은 부모마디 불순도에서 자식마디의 표본비율 가중 평균 불순도를 뺀 값이 최대가 되는 방식으로 선택합니다.

Gini impurity · 지니 불순도

지니 지수

Gini(t) = 1 − Σk pk²
  • 한 범주만 있으면 0 (완전 순수).
  • 두 범주가 50:50이면 0.5 (이진 기준 최대).
  • 작을수록 불순도가 낮습니다.
Entropy · 엔트로피

엔트로피 지수

H(t) = − Σk pk log₂(pk)
  • 한 범주만 있으면 0.
  • 두 범주가 50:50이면 1 bit.
  • 정보이득 = 분리 전 엔트로피 − 가중 평균 분리 후 엔트로피.

정확한 비교 원리: 불순도 감소량

ΔI = I(부모) − [ (nL/n) × I(왼쪽) + (nR/n) × I(오른쪽) ]

위 관광상품 예시의 10명(구매 6, 비구매 4)을 만족도 기준으로 나누면:

부모마디
6명 vs 4명
Gini = 0.48
자식마디 가중 불순도
0.5×0 + 0.5×0.32
= 0.16
불순도 감소량
0.48 − 0.16
= 0.32
꼭 기억! 자식마디 각각의 지니 지수 또는 엔트로피를 무조건 최소화한다는 표현보다, 자식마디의 표본 수를 고려한 가중 평균 불순도를 최소화한다고 설명해야 정확합니다.

정지규칙과 가지치기 412~413쪽

과대적합 방지: 자라기 전에 멈추기 vs 자란 뒤 덜어내기
Pre-pruning · 사전 제어

⛔ 정지규칙(Stopping Rule)

나무를 성장시키는 도중 일정 조건을 만족하면 더 이상 분할하지 않습니다.

  • 최대 깊이에 도달
  • 마디 내 표본 수가 너무 적음
  • 불순도 개선 폭이 너무 작음
  • 마디 자료가 모두 같은 범주

예: maxdepth, minsplit, minbucket

Post-pruning · 사후 가지치기

✂️ 가지치기(Pruning)

상대적으로 크게 성장시킨 나무에서 과도하거나 효과가 약한 하위 가지를 제거합니다.

  • 복잡도 감소로 해석 편의성 개선
  • 과대적합 위험 감소
  • 교차검증으로 크기 선택 가능
  • CART는 비용-복잡도 가지치기 활용

예: R rpart::prune()

비용-복잡도 가지치기(Cost-Complexity Pruning)

Rα(T) = R(T) + α × |Tleaves|

나무의 예측오차(또는 불순도 기반 손실) R(T)에 끝마디 개수에 비례한 복잡도 벌점을 더하여 나무 크기를 제어합니다. α가 커질수록 단순한 나무를 선호합니다.

나무가 너무 클 때
학습자료에 지나치게 맞춤 → 과대적합
나무가 너무 작을 때
중요한 패턴을 놓침 → 과소적합
기출 포인트 21번과 연결 정지규칙도 과대적합 예방에 도움을 주지만, 문제에서 이미 복잡해진 나무의 불필요한 가지를 제거한다고 묻는다면 정답은 가지치기입니다.

R 프로그램 간단 실습 410쪽 iris 예시 확장

iris 데이터로 나무 학습 → 교차검증 기반 CP 확인 → 가지치기 → 정확도 측정

R 코드 · rpart 패키지

# 1. 데이터 및 패키지
# install.packages("rpart")  # 미설치 시 최초 1회
library(rpart)

data(iris)
set.seed(2026)
idx <- sample(seq_len(nrow(iris)), size = 0.7 * nrow(iris))
train <- iris[idx, ]
test  <- iris[-idx, ]

# 2. 분류나무 생성: Species는 범주형 목표변수
fit <- rpart(Species ~ ., data = train, method = "class",
             control = rpart.control(cp = 0.001,
                                     minsplit = 10,
                                     maxdepth = 5))

# 3. 나무 확인
plot(fit, uniform = TRUE, margin = 0.1)
text(fit, use.n = TRUE, cex = 0.8)
printcp(fit)  # 교차검증 오류 및 복잡도 매개변수
plotcp(fit)

# 4. 교차검증 오류가 가장 작은 CP 사용
cp_best <- fit$cptable[which.min(fit$cptable[, "xerror"]), "CP"]
fit_pruned <- prune(fit, cp = cp_best)

# 5. 시험자료 성능
pred <- predict(fit_pruned, newdata = test, type = "class")
confusion <- table(Actual = test$Species, Predicted = pred)
print(confusion)
accuracy <- mean(pred == test$Species)
print(accuracy)

# 최종 나무 시각화
plot(fit_pruned, uniform = TRUE, margin = 0.1)
text(fit_pruned, use.n = TRUE, cex = 0.8)
실습 해석 Species는 품종을 나타내는 범주형 목표변수이며, 나머지 꽃받침·꽃잎 측정값으로 품종을 분류합니다. cp는 CART 나무의 복잡도를 제어합니다. 이 예제는 학습용 무작위 분할이므로 결과 정확도는 실제 실행 환경과 분할에 따라 달라질 수 있습니다.
