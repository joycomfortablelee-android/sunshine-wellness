02

분석 목적에 따른 작업 유형과 기법

Predictive Modeling ↔ Descriptive Modeling

분석의 목적에 따라 미지의 결과를 예측하거나, 데이터의 특징과 관계를 이해·설명합니다. 네 가지 작업 유형을 함께 비교하세요.

🎯예측 모델링Predictive Modeling알려진 결과를 학습하여
새로운 결과 예측
🏷️

분류 규칙Classification

과거 데이터와 정답으로 분류모형을 학습하고 새로운 고객이나 사례의 범주를 예측합니다.

활용: 신용평가 · 우량/불량 고객 판별 · 표적 마케팅
🔍기술 모델링Descriptive Modeling데이터 안의 관계·순서·
집단의 특징 발견
🧩

연관규칙Association

데이터에 함께 등장하는 항목 간 관계를 발견합니다. 예: A 상품 구매 ↔ B 상품 구매.

활용: 교차판매 · 매장 진열 · 사기 탐지
⏱️

연속규칙Sequence / Sequential Pattern

연관규칙에 시간과 순서가 추가됩니다. 구매 이력에 나타난 사건의 선후 관계를 탐색합니다.

활용: 구매 경로 분석 · 고객별 맞춤 마케팅
👥

데이터 군집화Clustering

정답 범주 없이 유사한 레코드끼리 묶어 특징이 비슷한 고객 집단을 도출합니다.

활용: 고객 세분화 · 판촉 및 이벤트 대상 선정
① 분류 vs 군집화

분류는 기존 정답 범주에 배정 / 군집화는 새로운 집단을 발견

② 연관 vs 연속규칙

연관은 함께 발생 / 연속은 발생 순서·시간까지 고려

③ 기법 연결

분류: 의사결정나무·신경망·판별분석 / 군집화: k-Means / 연관: 동시발생 패턴 탐색

문제 0325회 기출 · 목적별 기능

데이터 마이닝의 목적 중 사람, 상품에 관한 이해를 증가시키기 위한 것으로, 데이터의 특징 및 의미를 표현하고 설명하는 기능은 무엇인가?

정답 ① 기술(Description)

기술은 데이터를 요약하고 특징·패턴·의미를 설명하여 사람이나 상품을 이해하는 데 목적이 있습니다. 반면 예측은 미래 값을 전망하고, 추정은 알려지지 않은 값을 산정하며, 분류는 미리 정의된 범주에 사례를 배정합니다.

암기: “데이터를 이해하고 설명” = 기술 / “미래 또는 미지의 결과를 알아냄” = 예측.

문제 0418회 기출 · 추진 단계

데이터 마이닝 단계 중 모델링 목적에 따라 목적변수를 정리하고, 필요한 데이터를 데이터 마이닝 소프트웨어에 적용할 수 있도록 준비하는 단계는 무엇인가?

정답 ③ 데이터 가공

목적변수 정의 + 마이닝 소프트웨어용 형식 변환이 핵심 단서입니다. 2단계 데이터 준비는 원천 데이터를 수집·정제·확보하는 비교적 넓은 과정이고, 3단계 데이터 가공은 실제 모형에 투입하도록 변수와 형식을 조정하는 과정입니다.

암기: “모은다·정제한다” = 준비 / “목적변수·모형 입력 형태로 바꾼다” = 가공.
