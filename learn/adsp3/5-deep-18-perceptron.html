인공신경망의 구조 교재 436쪽

신경망은 여러 뉴런이 연결되어 입력을 출력으로 변환합니다.

📥 신호의 흐름 교재 436쪽

최종 예측
  • 입력 신호는 원자료의 특성값이나 다른 뉴런의 출력입니다.
  • 연결 가중치(weight)는 입력 신호의 영향력을 조절합니다.
  • 출력 신호는 최종 예측값이 되거나 다음 뉴런의 입력이 됩니다.
피드포워드(Feedforward) 신경망: 입력층에서 출력층 방향으로 정보가 전달되는 구조입니다.

🔍 뉴런 한 개를 확대하면? 교재 436쪽

신경망의 뉴런(neuron)은 입력들을 가중합한 뒤 활성화 함수를 적용하는 계산 단위입니다.

02

뉴런의 계산 교재 436쪽

입력값과 가중치가 같아도 편향과 활성화 함수에 따라 최종 출력이 달라집니다.

계산식: 가중합과 활성화 교재 436쪽

z = ∑i=1n wixi + b
y = f(z)
xi · 입력값원자료의 특성 또는 이전 뉴런 출력
wi · 가중치각 입력이 출력에 미치는 상대적 영향
b · 편향(Bias)결정 경계를 이동시키는 항목. 임계값 θ를 쓰면 b = −θ
f · 활성화 함수가중합을 출력값으로 변환
교재의 임계값 출력 설명은 특수한 경우입니다. 부호 활성화 함수를 쓴 단층 퍼셉트론에서는 z ≥ 0이면 +1, z < 0이면 −1로 출력할 수 있습니다. 모든 뉴런이 ±1만 출력하는 것은 아닙니다.

03

단층 퍼셉트론과 XOR의 한계 교재 437쪽

퍼셉트론은 선형 결정 경계를 학습하지만 XOR은 단일 직선으로 분리할 수 없습니다.

📐 단층 퍼셉트론(Single-layer Perceptron) 교재 437쪽

w⊤x + b = 0   ⇔   w⊤x − θ = 0
  • 선형 결합기(Linear Combiner): 입력을 가중합합니다.
  • 하드 리미터(Hard Limiter): 임계값을 기준으로 0/1 또는 −1/+1을 출력합니다.
  • 초평면(Hyperplane): n차원 공간을 둘로 나누는 (n−1)차원 결정 경계입니다.
① 입력

학습데이터의 특징을 받음

② 예측

가중합·임계값으로 분류

③ 갱신

오분류를 줄이도록 가중치 조정

퍼셉트론은 선형 분리 가능한 자료에 적합합니다. XOR처럼 선형 분리 불가능한 문제에는 은닉층과 비선형 활성화가 필요합니다.

🧩 AND · OR · XOR의 차이 교재 437쪽

x₁x₂출력 y

AND: 두 입력이 모두 1일 때만 1을 출력합니다.

🔓 XOR 문제를 어떻게 해결할까? 437쪽 · 보충 설명

단층 퍼셉트론의 결정 경계는 직선(2차원) 하나입니다. XOR에서는 양성(1) 점이 대각선에 놓여 음성(0) 점과 직선 하나로 분리되지 않습니다.

다층 퍼셉트론(MLP)은 은닉층과 비선형 활성화 함수를 활용해 여러 결정 경계를 조합합니다.

XOR을 구현하는 간단한 예
h₁ = ReLU(x₁ − x₂)
h₂ = ReLU(x₂ − x₁)
y = h₁ + h₂
x₁, x₂가 각각 0 또는 1일 때 정확히 XOR 출력을 만듭니다.
04

활성화 함수(Activation Function) 교재 438–439쪽

입력 가중합을 출력값으로 변환하여, 은닉층에 비선형 표현력을 제공합니다.

기초 비교

계단 함수 Step 교재 438쪽

f(z) = 1 (z ≥ 0),   0 (z < 0)

임계값을 기준으로 출력을 갑자기 0 또는 1로 전환합니다. 일반적인 경사하강법 학습에 적합하지 않습니다.

이진 출력미분 곤란
전통적 퍼셉트론

부호 함수 Sign 교재 438쪽

f(z) = +1 (z ≥ 0),   −1 (z < 0)

출력을 +1 또는 −1로 구분합니다. 교재의 임계값 비교 예시와 연결됩니다.

양극성 출력선형 분류
이진 분류 출력층

시그모이드 Sigmoid 교재 438쪽

σ(z) = 1 / (1 + e−z)

0~1 사이로 변환하므로 이진 분류의 확률형 출력에 활용합니다. 큰 |z|에서 기울기가 작아집니다.

범위 (0, 1)기울기 소실 가능
주요 은닉층

ReLU Rectified Linear Unit 교재 439쪽

f(z) = max(0, z)

음수 입력은 0, 양수 입력은 그대로 출력합니다. 양수 영역에서 기울기가 1이라 학습에 유리합니다.

빠른 계산죽은 ReLU 주의
다중 분류 출력층

소프트맥스 Softmax 교재 439쪽

pᵢ = ezᵢ / Σⱼezⱼ

여러 클래스의 점수를 비교 가능한 확률형 값으로 변환하며 출력값의 합은 1입니다.

다중 클래스합계 1
회귀 출력층

선형 함수 Linear 439쪽 · 기출 보기

f(z) = z

입력 점수를 그대로 전달합니다. 연속형 값 예측의 출력층에서 흔히 사용합니다.

회귀출력 범위 제한 없음

시험에서 혼동하기 쉬운 개념 교재 437·439쪽

신경망이 커지거나 층이 깊어질 때 생기는 학습상의 문제를 정리합니다.

⚙️ 하이퍼파라미터와 모델 학습 교재 437쪽

하이퍼파라미터은닉층 수, 뉴런 수, 학습률 등. 설계자 또는 자동 탐색 절차가 선택합니다.
학습 파라미터가중치 w, 편향 b. 데이터를 이용해 학습 과정에서 갱신됩니다.
뉴런이 지나치게 적을 때복잡한 패턴을 충분히 표현하지 못할 수 있습니다(과소적합 위험).
뉴런이 지나치게 많을 때학습 표현력이 커지지만 과적합과 연산 부담이 증가할 수 있습니다.

은닉층이나 뉴런 수가 기본적으로 자동 결정되는 것은 아닙니다. 다만 AutoML 및 신경망 구조 탐색을 사용하면 자동으로 탐색할 수 있습니다.

역전파기울기 계산

역전파(Backpropagation)는 출력층의 손실에 대한 미분 정보를 연쇄법칙으로 앞쪽 층까지 전달해 가중치 갱신에 필요한 기울기를 계산합니다.

기울기 소실(Vanishing Gradient)은 역전파 중 기울기가 작아져 앞쪽 층의 학습이 어려워지는 현상입니다.

ReLU는 양의 입력 영역에서 기울기 소실을 완화하는 데 도움이 되지만 완벽한 해결책은 아닙니다. 음수 영역이 계속 유지되면 죽은 ReLU(dying ReLU) 문제가 발생할 수 있습니다.
