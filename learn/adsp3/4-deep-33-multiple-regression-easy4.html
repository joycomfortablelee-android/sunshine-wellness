EASY 02 / F-통계량

모델 전체 유의성 평가 통계량

2 / 4
출처 · VIF·F검정·회귀진단 개념 + 기출 4문제
QUESTION 02

F통계량 vs t통계량 구분

35회 기출
문제
선형회귀모형에서 모델 전체의 유의성을 평가하는 데 가장 적절한 통계량은 무엇인가?
정답 ①

F통계량은 모든 회귀계수가 0이라는 귀무가설을 한꺼번에 검정해 "모형 전체"의 유의성을 본다. t통계량은 개별 계수, p-value는 판단 기준, AIC는 모형 간 비교 지표다.

핵심 암기 · 전체 = F / 개별 = t / 판단 = p / 비교 = AIC

QUESTION 03

Cook's Distance의 기준값

41회 기출
문제
Cook's Distance에 대한 설명으로 옳지 않은 것은?
정답 ①

Cook's Distance는 보통 1보다 "클" 경우에 영향치(영향력이 큰 관측치)로 간주한다. "작을 경우"라는 설명이 기준을 뒤바꾼 것이라 틀렸다.

핵심 암기 · Cook's Distance > 1 → 영향치로 의심

QUESTION 04

정규성 검정과 무관한 설명 찾기

34회 기출
문제
오차의 정규성은 모델의 신뢰도를 평가하는 데 있어 필수적인 요소이다. 다음 중 잔차 분석의 오차 정규성 검정에 대한 설명으로 옳지 않은 것은?
정답 ④

"정상성"은 시계열분석의 개념이며, 잔차 정규성 검정과는 다른 주제다. "상관계수 높은 독립변수를 제거"도 정규성 검정의 대처법이 아니다 — 서로 다른 개념이 섞인 오답이다.

핵심 암기 · 정규성 확인 = Q-Q Plot · 히스토그램 · Shapiro-Wilk / 정상성은 시계열 이야기
좌우 버튼 · 키보드 ← → · 하단 점을 눌러 화면을 이동할 수 있습니다. 기출38~40(슬라이드)은 이 4문제와 같은 다중공선성·F통계량 개념의 변형이라 중복을 피해 넣지 않았습니다. 영향력 진단(Leverage·DFBETAS·DFFITS)은 개념 카드만 있고 독립된 기출 선택지가 없어 5번째로 추가하지 않았습니다.
