04 · EXPLORATORY DATA ANALYSIS p.194

EDA: 분석하기 전에 데이터를 먼저 살펴보는 과정

탐색적 자료 분석(Exploratory Data Analysis)은 분포·이상치·변수의 관계를 알아내어 다음 분석 방향을 결정하게 돕습니다.

🔬 그래프를 직접 바꿔 보세요
가상의 관광지 방문 시간과 만족도: 점들이 오른쪽 위로 향하는 경향을 보입니다. 상관관계가 곧 인과관계를 뜻하는 것은 아닙니다.
EDA에서 자주 확인하는 4가지
① 분포 · 값이 주로 어디에 모여 있나요?
② 이상치 · 유난히 멀리 떨어진 값이 있나요?
③ 관계 · 두 변수가 함께 움직이나요?
④ 변환·선택 · 분석에 더 적합한 표현이 있을까요?
교재의 EDA 4가지 주제: 저항성 강조, 잔차 계산, 자료변수의 재표현, 그래프를 통한 현시성.
저항성은 극단값의 영향을 덜 받는 관점을, 잔차는 관측값과 예측값의 차이를 뜻합니다.

2. 최근 시각화 기법의 활용이 높아지면서 데이터의 특성을 파악하는 데 많은 기여를 하고 있다. 다음 중 최근의 시각화의 발전된 형태가 아닌 것은?
교재에서 구분하는 기준은 기본 통계치를 단순 차트로 옮긴 사례인지, 데이터의 복잡한 구조·관계·분포를 새로운 방식으로 표현한 사례인지입니다. ③은 전통적 기초 그래프 작성에 가까워 정답입니다.
선택지별 해설
①
워드 클라우드는 텍스트의 단어 빈도나 중요도를 시각적으로 표현하는 기법입니다.
②
SNA 네트워크 그래프는 사람·집단·노드 간 연결 구조를 한눈에 보여줍니다.
③
정답입니다. 기초통계를 엑셀 차트로 표현하는 것 자체는 새로운 시각화 방식이라 보기 어렵습니다.
④
히트맵과 모자이크 그래프 등은 복합적인 데이터 패턴을 전달하는 시각화 방법으로 활용됩니다.

3. 데이터가 가지고 있는 특성을 파악하기 위해 해당 변수의 분포 등을 시각화하여 분석하는 분석방식은 무엇인가?
EDA는 본격적인 모델 구축 전에 자료의 분포, 이상치, 변수 간 관계, 예상하지 못한 패턴 등을 탐색합니다. 여기서 “분포를 시각화해 특성을 파악”한다는 말이 결정적 단서입니다.
선택지별 해설
①
전처리는 결측·중복·형식 문제를 해결하여 분석 가능한 상태로 만드는 과정입니다.
②
정답입니다. 데이터 분포·이상치·관계를 살펴보는 활동이 EDA입니다.
③
공간분석은 지리적 위치와 공간적 관계가 핵심입니다.
④
다변량분석은 복수 변수를 함께 분석하는 넓은 분석 방법군이며, 질문의 직접적 용어는 EDA입니다.

4. 다음은 데이터 마이닝 프로젝트의 단계이다. 이 과정에서 올바른 순서는 무엇인가?
가. 문제 정의　나. 데이터 수집　다. 데이터 전처리　라. 분석 기법 적용　마. 모델 평가
문제를 정한 뒤 필요한 데이터를 수집하고, 결측·이상값을 처리한 다음 분석 기법을 적용합니다. 모델 평가를 마지막에 수행하는 것이 이 문항에서 요구한 기본적인 흐름입니다. 실제 프로젝트에서는 평가 결과에 따라 이전 단계로 돌아가기도 합니다.
선택지별 해설
①
정답입니다. 문제 정의 → 수집 → 전처리 → 분석 → 평가의 순서입니다.
②
수집하기도 전에 수집 데이터의 전처리를 완료할 수는 없습니다.
③
정제되지 않은 데이터를 분석에 먼저 적용하여 전처리와 분석 단계의 순서가 바뀌었습니다.
④
모델을 평가하려면 먼저 분석 기법을 적용하여 모델 또는 결과를 만들어야 합니다.

EDA의 목적

분포 = 값이 어디에 모이나?
이상치 = 유난히 다른 값이 있나?
관계 = 변수들이 함께 움직이나?
세 질문은 데이터의 특성과 관계를 파악
예측·성능평가는 EDA 직접 목적이 아님

5. 다음 빈칸에 들어갈 적절한 내용은 무엇인가?
탐색적 데이터 분석은 데이터를 이해하고 데이터를 시각화하여 초기 단계에서 ( )을(를) 파악하기 위해 수행됩니다.
EDA는 분석 초기의 질문인 “데이터는 어떻게 생겼으며 변수들은 어떻게 연결되는가?”에 답합니다. 미래 예측과 정확도 평가는 다음 분석·모델링 단계에서 수행할 수 있는 작업입니다.
선택지별 해설
①
정답입니다. 분포·이상치·특성·상관관계 등은 EDA의 기본 탐색 대상입니다.
②
미래 경향 예측은 별도의 예측 모형과 검증을 필요로 하며 EDA의 직접 목적은 아닙니다.
③
모델의 정확도는 모델 구축 후 성능평가 단계에서 확인합니다.
④
프로젝트 비용은 관리·계획 정보이며 EDA의 핵심 분석 대상이 아닙니다.
