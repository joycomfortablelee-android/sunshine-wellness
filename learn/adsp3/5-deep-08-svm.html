서포트 벡터 머신
Support Vector Machine

직선을 아무렇게나 긋지 않습니다.
두 집단 사이의 여유 공간(마진)을 가장 크게 만드는 경계를 찾습니다.

5장 정형 데이터 마이닝 · ⑪ 이론정복강의 · SVM
01 / FUNDAMENTAL

SVM은 ‘분류선’을 어떻게 선택할까?

같은 두 집단을 나누는 선은 여러 개입니다. SVM은 여유 폭이 넓은 경계를 선택합니다.

교재 404쪽

❌ 단지 두 집단만 구분하는 경계

집단을 구분할 수는 있지만 일부 점에 너무 가까워 새 데이터의 작은 변화에도 취약할 수 있습니다.

✅ 여유 공간을 최대로 확보한 경계

두 집단에서 경계에 가장 가까운 점을 기준으로 안전한 폭을 넓힙니다.

한 문장 정의 · SVM은 분류 오류와 마진을 고려하여 데이터를 나누는 최적의 결정 경계(Decision Boundary)를 찾는 지도학습 기법입니다. 교재 핵심

① Hyperplane

결정 초평면

두 집단을 나누는 분류 경계입니다. 2차원에서는 선, 3차원에서는 면으로 생각하면 쉽습니다.

“어디에서 A와 B를 나누는가?”
② Support Vector

서포트 벡터

Support Vector

결정 경계에 가장 가까운 데이터 점입니다. 경계의 위치와 방향을 결정하는 핵심 사례입니다.

“경계를 지탱하는 가장 가까운 점은?”
③ Margin

마진

Margin

결정 경계와 가까운 데이터 사이의 여유 거리입니다. 두 마진 경계 사이의 전체 폭도 마진 폭이라고 부릅니다.

05 / KERNEL TRICK

둥근 경계는 어떻게 만들까? 커널 함수

선형 경계로 구분하기 어려운 데이터도, 비선형 커널을 통해 분리할 수 있습니다.

교재 405쪽

📌 같은 데이터를 다른 방식으로 분리

직선 하나로는 가운데 집단과 그 주변을 에워싼 집단을 완전히 구분하기 어렵습니다.

커널 트릭(Kernel Trick)
특징을 고차원으로 실제 계산하여 모두 저장하지 않고도, 그 공간에서의 내적을 커널 함수로 계산해 비선형 경계를 학습합니다.
이해 보충 예시 반지름의 제곱 r² = x₁² + x₂²을 새 특징으로 생각하면, 안쪽과 바깥쪽을 다른 값으로 구분할 수 있습니다. 이는 커널의 원리를 설명하기 위한 예시이며 특정 커널의 실제 계산 과정 전체를 나타내지는 않습니다.

시험 핵심: 커널 함수의 역할은 단순한 차원 축소나 잡음 제거가 아닙니다. 비선형 패턴을 구분하도록 돕습니다.

06 / ADVANTAGES & LIMITATIONS

SVM과 커널 함수의 장점·단점

교재에서 제시한 비교를 구조화했습니다. 성능은 데이터·설정·평가 방법에 따라 달라집니다.

교재 405쪽

✓ SVM의 장점

  • 분류와 예측(회귀)에 활용 가능
  • 저차원과 고차원 데이터에 적용 가능
  • 좋은 분리 경계를 찾으면 예측력이 높을 수 있음
  • 커널 트릭으로 비선형 데이터도 학습 가능
  • 교재는 신경망 대비 과적합 위험이 낮은 편이라고 소개

! SVM의 단점

  • 데이터 전처리와 설정값에 성능이 민감할 수 있음
  • 왜 그 예측이 나왔는지 직관적 해석이 어려움
  • 대규모 데이터에서는 학습 시간과 메모리 부담
  • 커널 선택에 따라 계산량과 결과가 달라질 수 있음

✓ 커널 함수의 장점

  • 직선으로 구분하기 힘든 패턴 학습
  • 고차원 특징을 명시적으로 전부 생성하지 않고 계산 가능

! 커널 함수의 단점

  • 적절한 커널과 하이퍼파라미터 선택 필요
  • 복잡한 커널은 계산 비용과 튜닝 부담이 증가
주의 · “SVM은 언제나 정확하고 과적합이 적다”는 의미는 아닙니다. 실제 성능은 데이터 전처리, 커널, C·γ 설정과 교차검증 결과에 따라 달라집니다. 해석 보충
07 / EXTRA CONTEXT

C와 γ(감마)는 무엇을 조절하나?

교재 405쪽에 언급된 하이퍼파라미터를 이해하기 위한 보충 설명입니다.

교재 405쪽 연계 · 보충
C · 패널티 강도

오분류를 얼마나 강하게 벌점 줄까?

작음큼
해석균형적인 설명용 설정

C가 크면 훈련오류에 엄격해지고, 작으면 오분류를 상대적으로 더 허용하여 넓은 마진을 선호합니다. 다른 조건이 같을 때의 일반적 경향입니다.

γ · RBF 커널의 영향 범위

한 데이터 점이 주변에 얼마나 영향을 줄까?

작음큼
해석균형적인 설명용 설정

γ가 크면 각 점의 영향 범위가 좁아져 경계가 복잡해질 수 있고, 작으면 영향이 넓어져 경계가 부드러워질 수 있습니다. 주로 RBF 커널에 해당합니다.

핵심 기억 C는 오류 벌점, γ는 주변 영향 범위. 모두 정답값이 고정된 것은 아닙니다.
실무 원칙 입력 변수의 스케일을 맞춘 뒤, 검증 데이터 또는 교차검증으로 설정값을 선택합니다.

※ 이 화면의 막대는 설명 문장을 바꾸는 조절기입니다. 실제 SVM 모형을 학습하거나 정확도를 추정하지 않습니다.

SVM에 대한 설명 중 틀린 것은?

정답은 ④입니다. SVM은 데이터 규모, 커널에 따라 계산이 느릴 수 있습니다. ③의 다중 분류는 이진 SVM을 조합하는 방법 등으로 가능합니다.
20회 기출 · 문제 19

SVM의 커널 함수는 어떤 역할을 할까?

정답은 ②입니다. 커널 트릭은 고차원 특징 공간에서의 계산을 이용해 비선형 패턴을 다룹니다. 교재 표현인 ‘차원을 증가시킨다’의 의미를 이렇게 이해하면 정확합니다.
