03 · SIGNIFICANCE TESTS

t 검정과 F 검정은 질문 자체가 다르다

t 검정은 ‘각 변수의 계수가 0인가?’, F 검정은 ‘설명변수 모두의 기울기가 0인가?’를 살펴봅니다.

교재 p.307
개별 회귀계수

t-test · 각 변수의 역할

H₀: βⱼ = 0 / H₁: βⱼ ≠ 0

t = Estimate ÷ Std. Error

예: EngineSize t = 4.305387 ÷ 1.324961 ≈ 3.249 / p = 0.00163

회귀모형 전체

F-test · 전체 설명력 검정

H₀: β₁ = β₂ = β₃ = 0
H₁: 적어도 하나 ≠ 0

F = MSR ÷ MSE

Cars93: F = 37.98, p = 6.746×10⁻¹⁶ → 모형 전체 유의

유의수준 5%에서 판단하는 순서

① 가설 설정H₀: 계수가 0
→
② p-value 확인0.05와 비교
→
③ p < .05H₀ 기각·유의

📘 문제 위 이론 그림 · 주효과(Main Effect)와 상호작용(Interaction)

핵심: F 값에는 방향(+, −) 없음
wage = β₀ + β₁·age + β₂·education + β₃·(age×education) + ε

실제 education은 범주형 변수이므로 기준집단 대비 더미계수 및 상호작용계수들로 표현됩니다.

주효과

5% 유의수준에서 가장 적절하지 않은 설명은?

어떤 표의 열에서 ‘양(+)의 상관’이라는 정보를 얻을 수 있을까요?
출제 의도상 정답 ③

F 및 p-value에는 기울기의 부호가 없습니다.

age:education의 p = 0.0133이므로 5%에서 상호작용이 유의합니다. 그러나 age 계수의 양·음 부호나 상관계수는 제시되지 않으므로 ③은 단정할 수 없습니다.

회귀분석 결과 해석: 마지막 한 장 정리

기출 45~47번에서 반복되는 판단 순서를 5개의 질문으로 기억하세요.

강의 마무리

① 회귀식 종류?

X가 1개면 단순회귀, 여러 개면 다중회귀. 상호작용은 X₁×X₂.

② 계수의 방향?

Estimate의 부호를 본다. F값만으로 +/−를 알 수 없다.

③ 무엇이 유의?

계수별 t/p, 전체 모형 F/p. α와 p를 비교.

④ 설명력은?

R²와 수정 R²를 본다. p가 낮아도 R²는 별도 문제.

⑤ 관측치 수?

잔차 자유도 + 변수 개수 + 1 (절편이 있는 선형모형).

기출 정답 요약

45번③ · n=50
46번③ · 방향 불명
47번③ · 모형 유의

R 실습: 실제 결과 재현

# (1) MASS Cars93: 다중회귀
library(MASS)
fit <- lm(Price ~ EngineSize + RPM + Weight,
          data = Cars93)
summary(fit)
anova(fit)

# (2) 기본 내장 cars: 단순회귀

짧은 최종 확인

“Pr(>F) = 0.0133”5% 유의
“R² = 0.65”65% 변동 설명
“잔차 Df = 48, k=1”n = 50
“p = 0.00456, α = .001”유의하지 않음
기억할 문장
“계수는 방향, t는 개별, F는 전체, R²는 설명력, Df는 개수 복원!”

학습자료의 수치는 사용자 제공 교재 출력에서 옮겼습니다. OCR 오류를 교정했고, 실제 R 패키지 설치 버전에 따라 출력 형식은 다를 수 있습니다. ANOVA 효과의 인과적 해석 및 각 계수의 부호 판단은 별도 검토가 필요합니다.
