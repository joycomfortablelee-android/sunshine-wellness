② 데이터 마트

QUESTION 02

데이터 마트 구성요소

9회 기출
관련 문제
아래의 정의가 가리키는 데이터 마트의 구성요소로 가장 적절한 것은?
특정한 의미를 갖는 작위적 정의에 의한 변수로, 사용자가 특정 조건을 만족하거나 특정 함수에 의해 값을 만들어 의미를 부여한 변수
① 반응변수
② 파생변수
③ 설명변수
④ 요약변수
정답 ②

파생변수는 사용자가 의미를 부여한 새로운 변수이다. 설명변수는 두 변수의 관계를 설명하는 변수이며 이에 반응하는 변수가 반응변수이다. 요약변수는 데이터를 집계한 값이다.

핵심 암기 · 조건·함수로 "새로 만든" 변수 = 파생변수 / "집계해서 종합한" 변수 = 요약변수

QUESTION 03

차원 결합으로 변수를 만드는 패키지

29회 기출
관련 문제
변수를 조합해 변수명을 만들고 변수들을 시간, 상품 등의 차원에 결합해 다양한 요약변수와 파생변수를 쉽게 생성하여 데이터 마트를 구성할 수 있는 R 패키지는 무엇인가?
① ETL
② reshape
③ OLAP
④ rattle
정답 ②

reshape는 R에서 데이터를 긴 형식과 넓은 형식으로 변환하며, 다양한 차원에서 데이터를 결합하거나 요약변수를 생성할 수 있는 패키지이다. 시간·상품 등의 차원을 기준으로 데이터를 조합하고 분석에 적합한 형태로 변환하는 데 유용하다.

핵심 암기 · reshape = melt(녹이기)·cast(틀에 붓기)로 데이터 모양을 바꾸는 패키지
