CART

이진 분리의 대표

Classification And Regression Trees

범주형 목표 → 지니지수
연속형 목표 → 분산 감소

항상 두 개 가지로 분리 (Binary Split)

C4.5 / C5.0

여러 갈래도 가능

범주형 입력변수는 다지분리가 가능하고, 교재는 엔트로피를 주요 개념으로 설명합니다.

CART와 분기 개수 비교가 핵심

CHAID

통계적 유의성 기반

범주형 목표 → 카이제곱
연속형 목표 → F 통계량

일반적 사후 가지치기 대신 성장 중지 기준 활용

ID3

정보이득 최대화

정보 이득(Information Gain)이 가장 큰 특성을 선택합니다.

초기 알고리즘 · 연속형·과적합 대응에 한계

QUEST

선택 편향 완화

통계적 검정을 이용하는 빠르고 편향을 줄인 트리 알고리즘입니다.

Quick, Unbiased, Efficient, Statistical Tree

MARS

구간별 스플라인 회귀

변수의 구간별 관계를 스플라인으로 모델링합니다.

엄밀히는 일반적인 분기형 트리와 다른 회귀 방법

암기 문장 · CART = 지니·분산·이진 / C4.5 = 엔트로피·다지 / CHAID = 카이제곱·F검정 / ID3 = 정보이득 / QUEST = 선택 편향 완화 / MARS = 스플라인.

07 / LEAF NODES

최종 잎노드(Leaf Node) 안에는 무엇이 들어 있을까?

하나의 잎노드에는 관측치가 여럿 들어 있고, 가장 많은 범주가 해당 노드의 예측값이 됩니다.

교재 421–422쪽
Node 2 · n = 34

예측: setosa

setosa 34 · versicolor 0 · virginica 0

길이 ≤ 1.7 → 34/34 모두 setosa

Node 4 · n = 39

예측: versicolor

setosa 0 · versicolor 36 · virginica 3

같은 노드에도 다른 범주 3건이 존재

Node 5 · n = 34

예측: virginica

setosa 0 · versicolor 1 · virginica 33

모든 잎노드가 완벽히 순수할 필요는 없음

교재 R 코드 — 나무 생성

library(party) iris.tree <- ctree(Species ~ ., data=train.data) plot(iris.tree) plot(iris.tree, type="simple")

교재의 2가지 그래프

① plot(iris.tree) : 잎노드에 범주별 비율을 막대그래프로 표시합니다.

② plot(iris.tree, type="simple") : 조건과 예측 범주를 간단히 보여줍니다.

독해 포인트 · 분기 조건은 해당 노드에서 어떤 변수가 대상을 둘로 나누었는가를, 잎노드는 최종 예측 범주를 뜻합니다.
08 / CONFUSION MATRIX

R의 table() 결과로 정확도를 직접 읽자

교재 숫자를 그대로 반영했습니다. 행은 예측값, 열은 실제값이라는 점이 중요합니다.

교재 422쪽
예측 \ 실제setosaversicolorvirginica
table(predict(iris.tree), train.data$Species)
정답 수103
오답 수4
정확도96.26%

정확도 공식

정확도 = 대각선의 합 / 전체 건수
(34 + 36 + 33) / 107 = 96.26%

학습·시험 성능 비교

학습 Training96.26%103 / 107
시험 Test90.70%39 / 43

예시에서 시험 정확도는 학습 정확도보다 낮습니다. 다만 이 차이만으로 과적합이라고 단정할 수는 없습니다.

원문 교차 확인 · OCR 과정에서 행렬 값의 줄맞춤이 틀어질 수 있어 첨부 교재 PDF 422쪽의 실제 표를 기준으로 수치를 확인했습니다. 원문 예시에는 set.seed()가 없어 재실행하면 표가 달라질 수 있습니다.

선택된 경로

왜 어떤 잎노드는 100%가 아닐까?

예를 들어 Start<8.5 구간의 19건은 absent 8건, present 11건입니다. 다수범주인 present를 예측하지만 8건의 오분류가 남습니다.

11 / PAST EXAM QUESTIONS

교재 핵심 기출문제 25번·26번

교재 420·423쪽
41회 기출 · 문제 25 · 교재 420쪽

연속형 목적변수에는 분산 감소, 범주형에는 지니지수를 사용하는 알고리즘은?

정답 ③ CART. 이진 분리를 사용하며 분류에서는 지니지수, 회귀에서는 분산(제곱오차) 감소를 활용합니다.
18회 기출 · 문제 26 · 교재 423쪽

kyphosis 결정나무 결과에 대한 설명 중 부적절한 것은?

정답 ①. 분할은 대체로 자식 마디의 가중 평균 불순도를 줄이는 방향으로 선택합니다. 개별 자식 노드의 불순도가 반드시 단조감소하는 것은 아닙니다.
개념을 정확하게 이해하기 · 교재 해설의 “분할할 때마다 각 마디 불순도가 감소한다”는 문장은 엄밀하게 보면 단순화된 표현입니다. 형제 자식 마디의 가중 평균 불순도와 개별 마디 불순도를 구별해야 합니다.
