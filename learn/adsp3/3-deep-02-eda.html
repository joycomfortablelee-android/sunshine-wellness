THEORY 02 / MISSING VALUES

결측값 — 값이 비어 있는 상황

관측값이 누락되면 분석에 사용 가능한 사례가 줄고, 누락되는 이유에 따라 결과가 편향될 수 있습니다.

교재 p.224

결측값의 표현은 서로 다릅니다

NA R의 결측값

값이 존재하지 않음을 나타내는 대표 기호

"" / Unknown / 999999

원자료에서 누락을 나타낼 수도 있는 표기; 사전 확인·정리 필요

R에서 NULL은 길이가 0인 객체/값의 부재 등으로 쓰이며, NA와 동일한 결측 셀로 단순 취급하지 않습니다. NaN은 계산 결과가 '숫자가 아님'을 뜻합니다.

R에서 기억할 두 함수

is.na(data) # 각 셀별로 결측이면 TRUE complete.cases(data) # 행별로 완전하면 TRUE data[complete.cases(data), ] # 결측 없는 행만 선택

표의 빈칸을 찾아보세요

응답자여행경험만족도연령
complete.cases()는 한 행에 결측값이 하나라도 있으면 FALSE입니다. 반면 is.na()는 각 셀마다 TRUE/FALSE를 반환합니다.
4컷 개념 만화 · “빈칸은 그냥 숫자 0일까?”
01🧑‍🎓📋“만족도가 비어 있네?”
응답하지 않아 값이 빠졌습니다.
02❔0️⃣“0점으로 쓰면 될까?”
0은 실제 점수일 수 있어 임의로 넣으면 안 됩니다.
03🔎💻“NA인지 확인하자!”
is.na()로 빠진 위치를 찾습니다.
04🧠📌“왜 비었는지 먼저!”
누락 원인에 따라 처리 방법을 택합니다.

THEORY 04 / BOX PLOT AND IQR

상자그림으로 이상값 찾기

상자(box)는 가운데 50%의 자료, 상자 안 선은 중앙값, 상자 밖의 점은 이상값 후보를 보여 줍니다.

교재 pp.225–226

직접 바뀌는 상자수염그림

수염의 끝은 IQR 경계 안에 있는 실제 관측값 중 가장 바깥 값입니다. 점은 경계를 벗어난 후보입니다.

상자그림을 읽는 순서

Q1
제1사분위수 · 25%

데이터 약 25%가 이 값 이하입니다.

Q2
제2사분위수 · 중앙값

값을 정렬했을 때 가운데 위치입니다.

Q3
제3사분위수 · 75%

데이터 약 75%가 이 값 이하입니다.

IQR = Q3 − Q1
하한 = Q1 − 1.5×IQR
상한 = Q3 + 1.5×IQR
중요: 일반적인 상자그림에 중앙값은 보이지만 평균은 기본적으로 표시되지 않습니다. 일부 프로그램은 옵션으로 평균 표시가 가능합니다.
4컷 개념 만화 · “키가 아주 큰 친구를 찾는 법”
01🧍🧍🧍“키를 작은 순서로!”
숫자를 정렬합니다.
02📦📏“가운데 절반을 상자에!”
Q1과 Q3 사이가 IQR입니다.
03📏🚧“1.5×IQR 울타리!”
일반적인 이상값 경계를 계산합니다.
04🧍‍♂️🔴“밖에 있네! 왜일까?”
이상값은 검토 대상이지 곧 오류는 아닙니다.

THEORY 06 / BINNING

구간화 — 숫자를 그룹으로 묶기

연봉·나이처럼 연속형 값을 일정 범위의 범주로 바꿔서 비교, 설명, 점수화에 활용합니다.

교재 pp.226–227

구간 수를 직접 변경하세요

5개

예를 들어, 연봉을 구간화한다면?

연봉 72→70~99 구간→범주 코드 B

위는 원리를 설명하기 위한 별도의 가상 예입니다. 구간 경계는 분석 목적과 수치의 단위에 맞게 정해야 합니다.

1
동일폭 구간화

전체 값을 같은 폭으로 나누기

2
동일빈도 구간화

비슷한 개수의 관측값이 들어가도록 나누기

3
의사결정나무 기준

목표값의 분리에 유용한 기준으로 나누기

교재 원문에 제시된 연봉 원자료 수치(70~700)와 구간표(20 미만, 20~40 등)는 단위·표현이 일치하는지 확인이 필요합니다. 이 시각화에서는 이해를 위해 원자료 범위를 기준으로 동일폭 구간을 구성했습니다. 또한 5개 구간은 고정 규칙이 아니며 문제 목적에 따라 적절한 개수를 결정합니다.
