QUESTION 01

학습·검증·시험 데이터의 역할 구분

38회 기출
문제
데이터 분할에 대한 설명 중 가장 부적절한 것은 무엇인가?
정답 ③

학습 "도중"의 성능 점검·조정은 검증용(Validation) 데이터의 역할이다. 테스트용 데이터는 모든 조정이 끝난 뒤 최종 성능만 확인한다.

핵심 암기 · 학습 "도중" 평가 = 검증용 / 학습 "다 끝난 뒤" 최종 평가 = 시험용

QUESTION 03

민감도와 동일한 지표

19회 기출
문제
오분류표(Confusion Matrix)를 사용하여 계산할 수 있는 평가 지표 중 민감도와 동일하며 모형의 완전성(Completeness)을 평가하는 지표는?
정답 ④

재현율(Recall)=민감도(Sensitivity)=TP/(TP+FN). 실제 양성인 데이터 중에서 모델이 양성으로 올바르게 예측한 비율로, 민감도와 같은 개념이다.

핵심 암기 · 민감도 = 재현율(Recall) — 이름이 둘이라 혼동 주의

QUESTION 04

실제 FALSE 중 FALSE로 맞춘 비율

33회 기출
문제
오분류표를 활용하는 평가지표 중 실제값이 FALSE인 관측치에서 예측값이 올바르게 FALSE인 정도를 나타내는 지표는?
정답 ②

특이도(Specificity)=TN/(TN+FP). 실제 음성(Negative) 사례 중 음성으로 정확히 예측한 비율이다. 민감도(실제 양성 중 양성을 맞힌 비율)와 짝지어 구분해서 외운다.

핵심 암기 · "실제 음성 중 음성으로 맞힌 비율" = 특이도

QUESTION 05

오분류표로 특이도 계산

22회 기출
문제
아래는 오분류표를 나타낸 것이다. 다음 중 특이도(Specificity)는 얼마인가?
실제값 TRUE: 예측 TRUE 30 / 예측 FALSE 70 (합계 100)
실제값 FALSE: 예측 TRUE 60 / 예측 FALSE 40 (합계 100)
정답 ②

특이도는 실제 음성(FALSE) 중에서 올바르게 FALSE로 예측한 비율이다. 실제값이 FALSE인 100명 중 모델이 FALSE로 예측한 경우는 40명이므로, 특이도 = 40/100 = 4/10이다.

핵심 암기 · 특이도 = 실제 FALSE행에서 "FALSE로 맞춘 비율"
