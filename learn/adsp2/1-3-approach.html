THEORY 01 · 접근법 선택 기준

하향식 vs 상향식 접근법

1 / 7
분석 과제를 발굴하는 방식은 대상이 명확한지에 따라 달라진다. 대상이 명확하면 체계적으로 문제를 분석하는 하향식, 대상이 불명확하면 데이터를 탐색해 통찰을 끌어내는 상향식이 적합하다.
하향식 접근법 (Top-Down)조직의 비즈니스 목표를 기준으로 분석 과제를 도출하고, 이에 필요한 데이터를 준비하는 방식. 분석 대상이 명확할 때 적합하다.
상향식 접근법 (Bottom-Up)분석 대상이 명확하지 않을 때, 데이터를 기반으로 가능한 모든 방법을 활용해 통찰을 도출하는 방식. Design Thinking 등이 활용된다.

② 하향식 접근법은 조직의 비즈니스 목표를 기준으로 분석 과제를 도출하고, 이에 필요한 데이터를 준비하는 방식이다.
③ 비즈니스 목표와 데이터의 연계성을 파악하여 실질적인 가치를 창출할 수 있는 문제를 정의하는 것이 중요하다.

정답 ①

핵심 암기 · 대상 Known → 하향식 / 대상 Un-known → 상향식

THEORY 03 · 하향식 접근법 ②

체계적 문제 해결 방식이라는 것

3 / 7
하향식 접근법은 각 과정을 체계적으로 단계화하여 주어진 문제에 대한 해법을 찾는 분석 과제 발굴 방식이다. "체계적 문제 해결", "목표 기반 접근법", "점진적 분석 접근법" 같은 표현은 교재가 쓰는 공식 용어가 아니라 하향식 접근법의 속성을 풀어쓴 보기일 뿐이므로 혼동하지 않아야 한다.
하향식 접근법문제를 체계적으로 정의하고 단계별로 해결하는 공식 분석 과제 발굴 방식
상향식 접근법데이터에서 출발해 통찰을 끌어내는 방식 (구조화된 방법론의 이름이 아님)

QUESTION 11

체계적 분석 과제 발굴 방식

35회 기출
관련 문제
주어진 문제에 대한 해법을 찾기 위해 각 과정이 체계적으로 단계화되어 수행하는 분석 과제 발굴 방식은?
① 하향식 접근 방식 (Top-Down Approach)
② 체계적 문제 해결 (Systematic Problem Solving)
③ 목표 기반 접근법 (Goal-Oriented Approach)
④ 점진적 분석 접근법 (Incremental Analysis Approach)
정답 ①

하향식 접근 방식은 문제를 체계적으로 정의하고 해결하는 데 사용된다. 체계적 문제 해결은 구조화된 방법론을 적용하는 문제 해결법이며 목표 기반 접근법은 명확한 목표를 달성하기 위해 작업을 수행하는 방법이다. 점진적 분석 접근법은 분석을 점진적으로 수행해 결과를 축적하는 방식이다.

핵심 암기 · "체계적으로 단계화된 분석 과제 발굴"이라는 표현 = 하향식 접근법
THEORY 04 · 하향식 접근법 ③

각 단계의 정확한 정의

4 / 7

문제 탐색 (Problem Exploration)비즈니스 문제를 폭넓게 식별하는 초기 단계
문제 정의 (Problem Definition)식별된 비즈니스 문제를 데이터의 문제로 변환하여 명확히 정의하는 단계

타당성 검토 (Feasibility Check)경제적·기술적 타당성을 확인하는 마지막 단계

발산·수렴을 반복하는 과제 발굴법

38회 기출
관련 문제
다음 중 상향식 접근방식의 발산단계와 하향식 접근방식의 수렴단계를 반복하여 과제를 발굴하는 방법은 무엇인가?
① 디자인씽킹 (Design Thinking)
② 브레인스토밍 (Brainstorming)
