분석 기획이란 실제 분석을 수행하기에 앞서 분석 과제를 정의하고, 의도한 결과를 도출하도록 관리 방안을 사전에 계획하는 작업이다. 어떤 목표(What)를 왜(Why) 어떤 방식(How)으로 수행할지에 대한 사전 작업으로, 성공적인 분석 결과를 위한 중요한 선행 단계다.

QUESTION 01

분석 기획에 대한 설명

36회 기출
관련 문제
분석 기획에 대한 설명으로 가장 적절하지 않은 것은?
① 분석 결과를 활용할 주요 의사결정 포인트를 식별한다.
② 분석 수행 시 필요한 데이터 소스를 선정하고 우선순위를 설정한다.
③ 성공적인 분석 결과를 도출하기 위한 중요한 사전 작업이다.
④ 상향식 분석은 분석 기획에 앞서 탐색적 데이터 분석을 선행한다.
정답 ④

상향식 접근 방식은 데이터를 중심으로 분석 과제를 발굴하는 과정이며, 분석 기획은 이보다 앞선 단계에서 분석 목표와 전략을 수립하는 작업이다. 따라서 "상향식 분석이 분석 기획에 앞서 탐색적 데이터 분석을 선행한다"는 설명은 순서가 뒤바뀐 오답이다.

QUESTION 02

분석 과제 도출 유형

45회 기출
관련 문제
분석 과제를 정의할 때, 분석 방법은 명확하지만 적용할 대상을 명확히 알지 못하는 경우가 있다. 이러한 상황에서 적합한 분석 과제 도출 유형은 무엇인가?
① 분석(Analysis)
② 최적화(Optimization)
③ 통찰(Insight)
④ 설계(Design)
정답 ③

통찰(Insight) 유형은 분석 방법은 명확하지만 적용 대상이 불명확할 때, 명확한 방법을 통해 데이터에서 패턴이나 숨겨진 관계를 발견하는 데 유용하다. 최적화와 설계는 구체적인 대상과 문제 정의가 먼저 선행되어야 한다.

핵심 암기 · 대상·방법 둘 다 Known=최적화 / 방법만 Known=통찰 / 대상만 Known=솔루션 / 둘 다 Un-known=발견

QUESTION 03

과제 중심적 접근 방식

45회 기출
관련 문제
과제 중심적인 접근 방식의 특징으로 옳지 않은 것은 무엇인가?
① 과제 중심적 접근 방식은 신속한 문제 해결과 빠른 테스트에 중점을 둔다.
② 과제 중심적 접근 방식에서는 장기적인 데이터 분석 역량 강화를 목표로 한다.
③ 과제 중심적 접근 방식은 특정 문제에 대한 해결책을 빠르게 제공하려고 한다.
④ 과제 중심적 접근 방식은 효율성과 속도를 높이기 위해 Quick-Win을 추구한다.
정답 ②

과제 중심적 접근 방식은 특정 문제를 신속히 해결하고 결과를 빠르게 테스트하며 효율성을 높이는 단기적 접근이다(Quick-Win, Speed&Test). 반면 장기적인 데이터 분석 역량 강화는 정확성과 배포를 중시하는 장기적 마스터 플랜 방식의 특징이다. 따라서 ②는 과제 중심적 접근 방식의 특징으로 적절하지 않다.

핵심 암기 · 과제 중심 = Speed&Test·Quick-Win·단기 / 마스터플랜 = Accuracy&Deploy·Long Term·장기
