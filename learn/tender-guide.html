검색어 라이브러리

공고 제목은 표현이 다양하므로 한 문장으로 묶지 말고 각각 검색하는 것이 좋습니다. 검색어를 누르면 복사됩니다.

관광계획·개발

전문 분야

MICE·축제·특구

과업 제목 표현

데이터·조사 방법

공모·실행 연계

나라장터 활용법

세 메뉴를 각각 확인해야 공고를 놓치지 않습니다.

1. 발주계획

발주 → 발주계획 → 용역. 사업명, 예상예산, 발주시기, 수요기관과 담당부서를 먼저 확인합니다.

2. 사전규격

발주 → 사전규격 → 용역. 제안요청서 초안, 과업범위, 기간, 참가자격을 검토합니다.

3. 입찰공고

입찰 → 입찰공고 → 용역. 실제 제출기한, 평가방법, 공동수급, 발표일을 확인합니다.

4. 개찰·계약

개찰결과와 계약현황에서 낙찰기관, 계약금액, 유찰·재공고 여부를 확인합니다.

권장 검색 설정

업무구분용역
검색범위공고명 중심, 필요 시 수요기관 추가
조회기간최근 1개월 또는 3개월
정렬등록일 최신순
업종 참고학술·연구용역 여부와 참가자격을 공고문에서 확인
원문 확인공고문·제안요청서·과업내용서·평가기준표 모두 열람
검색어를 지나치게 길게 결합하면 결과가 줄어듭니다. “웰니스관광”, “관광 육성계획”, “거점 조성”처럼 핵심어를 나누어 반복 검색하세요.

주간 점검 루틴

월요일 또는 주 1회 기준으로 약 20분 내에 확인하는 순서입니다.

1나라장터 발주계획향후 1~3개월 예정 용역사업명·예산·예정월·담당부서
