①

타겟별 수익모델형

B2B · B2C · B2G처럼 고객군을 먼저 나누고, 각 고객군에서 발생하는 판매·대여·구독·수수료 등의 수익원을 표시합니다.

핵심 질문: 누구에게 무엇으로 돈을 받는가?
②

기업 중심 연결형

기업을 가운데 두고 B2B·B2G·B2C를 연결하여, 기업이 제공하는 기능·서비스·가치를 보여줍니다.

핵심 질문: 기업이 누구와 어떤 기능으로 연결되는가?
③

B2G–B2B 공급구조형

공공기관(B2G)에 제공하는 제품·서비스가 어떻게 기업 고객(B2B)으로 연결되고 확장되는지 공급 흐름을 보여줍니다.

핵심 질문: 누구에게 무엇을 공급하고, 고객을 어떻게 확보하는가?
④

복합 수익모델형

판매 · 구독 · 렌탈 · 플랫폼 수수료 · 기술료 · 광고 · 데이터 판매 등 여러 수익원을 동시에 구조화합니다.

핵심 질문: 실제 돈은 어디에서, 어떤 방식으로 발생하는가?
먼저 ① 고객군 → ② 제공가치/상품 → ③ 거래방식 → ④ 수익원 → ⑤ 주수익·부수익 순서로 적은 뒤, 네 가지 표현 방식 가운데 내 사업에 가장 잘 맞는 도식을 골라 그리면 됩니다.

해석과 적용

네 칸을 하나씩 읽는 법

원본은 BM(Business Model)을 네 가지 방식으로 그린 예시 한 장입니다. 아래 표는 네 칸이 각각 무엇을 어떤 식으로 보여 주는지를 자리별로 갈라 놓은 것입니다.

이미지 중심 페이지 — BM 모델 예시 4종

위치BM 구조이미지 내 핵심 내용표현의 특징
좌상단타겟별 수익모델형1차 타겟 B2B / 2차 타겟 B2C / 3차 타겟 B2G고객군과 수익원을 표 형태로 연결
우상단기업 중심 이해관계자형B2B + B2G ↔ 기업 ↔ B2C, A기능·B기능·C기능·D기능기업을 중심으로 양쪽 고객군과 제공 기능을 표현
좌하단B2G–B2B 거래구조형B2G 공공기관 → 서비스·제품 → B2B 기업누구에게 어떤 상품·서비스를 공급하는지 구체적으로 표현
우하단복합 수익모델형B2C 판매·구독 / B2B 판매·렌탈·수수료·기술료·광고·데이터 판매·POC하나의 사업에서 여러 수익원을 동시에 표현

① 좌상단 — 타겟별 BM 모델

BM 모델

1차 타겟 B2B / 2차 타겟 B2C / 3차 타겟 B2G

수익 방식

  • 판매: 제품 1, 제품 2, 제품 3
  • 대여
  • A/S: 유상보수, 하자보수
  • 플랫폼 사용료 / 구독
  • 원자재 거래 수수료

핵심 포인트: 고객(Target)을 먼저 나누고 → 각 고객에게서 어떤 방식으로 수익을 얻는지 보여주는 BM

② 우상단 — 기업 중심 Business Model

왼쪽: B2B + B2G

가운데: 기업

기업을 중심으로 A 기능, B 기능, C 기능, D 기능을 배치

오른쪽: B2C

핵심 포인트: 기업이 어떤 기능 또는 가치를 제공하여 B2B·B2G와 B2C를 동시에 연결하는가를 보여주는 형태

③ 좌하단 — B2G → 상품·서비스 → B2B 모델

B2G 공공기관 → 구독 서비스 / 제조·구독 / 제품 설치 / 메인 제품 판매 / 소모품 판매 / 유지보수 / 컨설팅 → B2B

현재 000,00 확보 / B2B 00업체 및 농장

핵심 포인트: 누구에게 → 무엇을 제공하고 → 현재 어느 정도 고객을 확보했는가까지 한 장에서 보여주는 유형

④ 우하단 — B2C + B2B 복합 수익모델

B2C: 기기 판매, 부가 제품 판매, AI 플랫폼 / 판매, 구독

B2B: 판매, 기기 렌탈, 플랫폼 이용 수수료, 기술료 수익, 광고

추가 수익: 데이터 판매, POC

POC = Proof of Concept, 개념검증

이 그림에서 가장 중요한 흐름

① 누구에게 판매하는가? B2C · B2B · B2G

→ ② 무엇을 제공하는가? 제품 · 서비스 · 플랫폼 · 콘텐츠 · 데이터

→ ③ 어떻게 거래하는가? 판매 · 대여 · 렌탈 · 구독 · 중개

→ ④ 무엇으로 돈을 버는가? 판매수익 · 구독료 · 이용수수료 · 기술료 · 광고료 · 데이터 판매

→ ⑤ 주수익과 부수익은 무엇인가?

예를 들어 관광벤처라면:

외국인 관광객 B2C → 안동 로컬투어 판매 → 투어 판매수익 [주수익]

지역 숙박업체 B2B → 예약 연계 → 중개수수료 [부수익]

지자체 B2G → 관광콘텐츠 개발·운영 → 사업 수행비 [부수익]

② 우상단｜기업 중심 Business Model

중앙: 기업

4개 모델을 한 번에 비교하면

① 타겟별 수익모델형: 누구에게 무엇으로 돈을 받는가?

② 기업 중심 연결형: 기업이 누구와 어떤 기능으로 연결되는가?

③ 공급·거래 구조형: 누구에게 무엇을 공급하는가?

④ 복합 수익모델형: 실제 돈이 어디에서 발생하는가?

관광벤처 사업계획서에는 ①과 ④를 겹쳐 그리는 방식이 가장 잘 맞습니다 — 고객군을 나누고(①), 그 위에 수익원을 여러 개 얹습니다(④).

B2C / B2B / B2G 고객군을 나눈 뒤 → 각 고객에게 제공하는 상품·서비스 → 거래 방식 → 주수익 → 부수익 순으로 그리면 이 이미지와 같은 수준의 BM 구조를 만들 수 있습니다.

바로 쓰는 프레임

바로 쓰는 핵심 프레임

고객군(B2C·B2B·B2G) → 제공가치/상품 → 거래방식 → 주수익 → 부수익

이 순서로 적으면 단순한 아이디어 설명을 넘어 실제 돈의 흐름까지 한 장에 담깁니다. 사업계획서 2-2 사업모델 칸이 이 순서입니다.
