수업 포인트: 문제정의 → 데이터 → 분석 → 시각화 → 정책제안 구조 확인

STEP 3

AI-Hub는 ‘데이터 플랫폼을 찾는 관문’으로 활용

AI-Hub의 외부 데이터 플랫폼 페이지는 여러 전문 데이터 플랫폼을 분야별로 연결해주는 역할을 합니다.

🚍 교통 데이터

이동량, 교통흐름, 접근성, 이동경로 분석

관광 적용: 관광객 이동, 관광버스, 방문 동선

🎭 문화 데이터

문화콘텐츠, 시설, 소비·이용 관련 데이터

관광 적용: 축제, 문화관광, 지역 콘텐츠

🌿 환경·산림 데이터

환경·생태·산림 관련 공간 및 관측 데이터

관광 적용: 생태관광, 산림관광, 지속가능 관광

❤️ 라이프로그·헬스케어

생활·건강·행동 관련 데이터

관광 적용: 웰니스관광, 걷기, 건강관광

🏛 공공데이터

행정·지역·산업 전반의 공공데이터

관광 적용: 정책, 시설, 지역 비교

🤖 AI 학습데이터

텍스트·이미지·음성 등 AI 학습용 데이터

관광 적용: 관광 이미지 분류, 챗봇, 리뷰 분석

한 문장 정리: AI-Hub는 수상작 플랫폼이라기보다, “어디에 어떤 전문 데이터가 있는지 찾아가는 데이터 플랫폼 지도”에 가깝습니다.
AI-Hub 외부 데이터 플랫폼 열기 ↗
STEP 4

학생이 직접 분석할 데이터는 여기서 찾는다

KOSIS
국가승인통계를 활용해 관광, 인구, 지역경제, 여가, 소비 등의 기초 통계를 확인합니다.
예: 지역별 관광수요 비교, 고령인구와 관광시설 분석
공공데이터포털
CSV·Excel·Open API 등 공공기관이 제공하는 원자료를 찾을 수 있습니다.
예: 관광지, 교통, 숙박, 축제, 시설 데이터
빅카인즈
뉴스 빅데이터 기반 검색, 연관어, 관계도, 토픽 분석에 적합합니다.
예: 오버투어리즘, 관광불편, 웰니스관광 담론 분석
AI-Hub
AI 학습데이터와 외부 전문 데이터 플랫폼을 한 곳에서 탐색할 수 있습니다.
예: 관광 이미지·텍스트·음성 AI 분석
중요: “우수작을 보는 사이트”와 “데이터를 내려받는 사이트”는 구분해야 합니다.
