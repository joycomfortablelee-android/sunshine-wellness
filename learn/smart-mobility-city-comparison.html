02 Concept

스마트 모빌리티란 무엇인가?

새로운 차종의 이름이 아니라, 사람의 이동 과정 전체를 데이터와 서비스로 연결하는 교통체계입니다.

Conventional Transport
일반적인 교통
  • 교통수단별로 정보 확인
  • 고정 노선·시간표 중심
  • 서비스마다 예약·결제
  • 이동을 단순한 교통행위로 인식
Smart Mobility
지능적으로 연결된 이동
  • 실시간 경로·혼잡·도착 정보
  • 수요·상황에 따른 운영 최적화
  • 통합 검색과 예약·결제 지향
  • 접근성·안전·지속가능성 중심
핵심 변화: 교통수단 중심(Transport-centered) → 이용자 중심(User-centered)
스마트 모빌리티의 5가지 구성요소 · 카드를 눌러 사례를 확인하세요
EXPLAIN
MaaS · Mobility as a Service (통합이동서비스)

다양한 교통수단의 경로 탐색·예약·결제 등을 디지털 플랫폼에서 연계합니다. 예: HSL 앱, 티머니GO(통합 범위는 서비스마다 다름).

    06 Student Research Lab

    학생 탐구활동: 나만의 도시 평가

    공식자료에서 수집한 근거를 바탕으로 6개 평가영역을 직접 채점해 보세요. 자동으로 보이는 점수는 도시의 객관적 순위가 아닌 학생이 입력한 탐구 결과입니다.

    TASK A · QUALITATIVE EVALUATION

    도시별 이동경험 평가

    점수 기준(예시): 1 = 근거 부족 또는 미흡, 3 = 일부 확인, 5 = 풍부한 근거와 높은 사용자 편의. 척도는 수업용 자체 평가표이며 검증된 학술 척도가 아닙니다.
    TASK B · EVIDENCE & REFLECTION

    점수의 근거를 설명하기

    학생이 직접 입력한 평균
    3.0 / 5.0
    6개 영역의 합계
    18 / 30

    평가를 끝낸 뒤, 한 도시의 강점과 한계를 각각 1가지씩 제시해 보세요.

    정성적 ‘정책 보유’보다 이용자 성과(이동시간·환승 편의·관광 만족도 등)를 입증하는 데이터가 추가되면 평가가 더 탄탄해집니다.
    TASK C · PRESENTATION ROADMAP

    학생 발표를 위한 8장 구성

    1–4장: 문제 정의와 도시 사례
    1. 연구 질문과 도시 선정 이유
    2. 스마트 모빌리티 개념(ITS·MaaS 등)
    3. 도시별 실제 서비스와 공식 출처
    4. 관광객의 이동 시나리오
    5–8장: 비교와 관광적 시사점
    1. 4개 도시 공통지표 비교
    2. 관광객 관점 강점·한계
    3. 국내 적용 아이디어(용인 등)
    4. 결론·한계·참고문헌
