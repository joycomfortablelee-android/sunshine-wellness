CONCEPT 01

노드와 링크 — 네트워크의 두 재료

1 / 12

노드(Node)와 링크(Link)

노드는 네트워크를 이루는 개별 대상(단어·사람·기관 등 하나하나의 점)이고, 링크는 그 대상들 사이의 관계(함께 등장함 · 서로 연결됨)를 나타내는 선입니다.

예: 뉴스 기사에서 "관광·호텔·축제·지역"이라는 네 단어가 서로 함께 등장했다면, 각 단어는 노드가 되고 함께 등장한 관계는 링크가 됩니다.

CONCEPT 02

연결 중심성 — 이웃이 많은 노드

2 / 12

연결 중심성(Degree Centrality)

한 노드에 직접 연결된 링크(이웃)의 수로 중요도를 재는 지표입니다. 연결 중심성이 높을수록 많은 대상과 직접 관계를 맺은 "인기 있는" 노드라고 볼 수 있습니다.

위 그림에서 "호텔"과 "축제"는 각각 3개의 선과 연결돼 있어 "관광"·"지역"(각 2개)보다 연결 중심성이 높습니다.

CONCEPT 03

매개 중심성 — 다리 역할을 하는 노드

3 / 12

매개 중심성(Betweenness Centrality)

다른 두 노드가 서로 연결되는 최단 경로 위에 얼마나 자주 놓이는가를 재는 지표입니다. 매개 중심성이 높은 노드는 이웃 수가 적어도 서로 다른 집단을 이어주는 "다리" 역할을 합니다.

예: "관광"과 "지역"이 직접 연결되지 않고 "호텔"을 거쳐야만 이어진다면, "호텔"의 매개 중심성이 높아집니다 — 연결 중심성과는 다른 질문("이웃이 몇이냐")이 아니라 "다른 노드들 사이를 얼마나 중개하느냐"를 묻는다는 점이 핵심입니다.

CONCEPT 04

CONCOR — 비슷하게 연결된 노드끼리 묶기

4 / 12

CONCOR(CONvergence of iterated CORrelations)

노드들의 연결 패턴(누구와 누구가 연결되어 있는가)이 서로 비슷한 노드들을 하나의 하위집단(블록)으로 묶는 네트워크 군집 기법입니다. 상관계수를 반복 계산해 결국 모든 노드를 1 또는 −1의 상관으로 수렴시키는 방식으로 묶습니다.

예: 빅카인즈·텍스톰의 "관계도"에서 비슷한 색으로 묶인 단어 묶음이 CONCOR로 나눈 하위집단인 경우가 많습니다 — "숙박 관련어 묶음", "축제 관련어 묶음"처럼요.

CONCEPT 05

연관어 분석 vs 관계도(네트워크) 분석

5 / 12

무엇이 다른가

연관어 분석은 「이 검색어와 어떤 단어가 함께 많이 나왔나」를 보는 것 — 중심 단어 하나를 기준으로 주변 단어의 빈도를 봅니다.

관계도(네트워크) 분석은 「등장한 대상들이 서로 어떻게 엮여 있나」를 보는 것 — 단어들 사이의 전체 연결 구조(누가 허브인지, 누가 다리인지, 어떤 하위집단이 있는지)를 봅니다.

빅카인즈 화면으로 비유하면, 연관어 분석은 "관광"이라는 단어 옆에 막대로 늘어선 연관 단어 목록이고, 관계도 분석은 여러 단어가 점과 선으로 서로 얽혀 있는 그림입니다.

CONCEPT 06

어디서 실습하나

6 / 12

실습 도구

빅카인즈에서는 검색어를 넣으면 관계도 그림을 바로 그려 줍니다. 텍스톰에서는 수집한 텍스트를 정제한 뒤 "의미연결망"으로 같은 종류의 그림을 만들 수 있습니다.

두 도구 모두 그림 안의 "큰 점"은 연결 중심성이 높은 단어, "두 덩어리를 이어주는 가는 선 위의 점"은 매개 중심성이 높은 단어로 읽으면 됩니다.

QUESTION 01

노드와 링크의 정의

개념 확인
문제

정답 ②

핵심 암기 · 노드 = 점(대상) / 링크 = 선(관계)

QUESTION 02

연결 중심성이 재는 것

개념 확인
문제
한 노드에 직접 연결된 이웃(링크)의 수로 중요도를 재는 지표는?
정답 ①

연결 중심성은 직접 연결된 이웃의 수를 센다. 매개 중심성은 "다리 역할"을, CONCOR는 "하위집단 묶기"를, 가중치는 "연관성 점수"를 나타내는 서로 다른 개념이다.

핵심 암기 · 연결 중심성 = 이웃이 몇 명이냐(인기)

QUESTION 03

매개 중심성이 높다는 것의 의미

개념 확인
문제
매개 중심성(Betweenness Centrality)이 높은 노드를 가장 잘 설명한 것은?
정답 ③

매개 중심성은 이웃의 "수"가 아니라, 다른 노드들 사이의 최단 경로 위에 얼마나 자주 위치하는지(중개 역할)를 잰다. ①은 연결 중심성, ④는 CONCOR의 결과에 대한 설명이다.

핵심 암기 · 매개 중심성 = 다리(연결 중심성의 "인기"와는 다른 질문)

QUESTION 04

CONCOR이 하는 일

개념 확인
문제
연결 패턴이 비슷한 노드들을 하나의 하위집단(블록)으로 묶어주는 네트워크 군집 기법은?
정답 ④

CONCOR는 노드 간 연결 패턴의 상관관계를 반복 계산해, 비슷하게 연결된 노드들을 같은 하위집단으로 묶는다. 중심성 지표들은 "묶기"가 아니라 "중요도 재기"가 목적이라는 점에서 다르다.

핵심 암기 · CONCOR = 비슷하게 엮인 노드끼리 블록으로

QUESTION 05

"어떤 단어가 함께 나오나" vs "서로 어떻게 엮이나"

개념 확인
문제
빅카인즈에서 "등장한 대상들이 서로 어떻게 엮여 있는가"를 보여주는 분석은?
정답 ②

연관어 분석은 "중심 단어와 함께 나온 단어"를 보는 것이고, 관계도(네트워크) 분석은 여러 대상이 서로 어떻게 연결되는지 전체 구조를 보는 것이다.

핵심 암기 · 연관어 = 함께 나온 단어 / 관계도 = 전체 연결 구조

개념 확인
문제

정답 ①

빅카인즈는 주요 언론사 기사를 분석해 관계도·연관어를 시각화해 주는 서비스다. 텍스톰도 같은 그림을 "의미연결망"이라는 이름으로 만들 수 있다.

핵심 암기 · 관계도 = 빅카인즈 / 의미연결망 = 텍스톰
