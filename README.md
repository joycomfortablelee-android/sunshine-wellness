# 선샤인 웰니스 (Sunshine Wellness)

부산 특화 웰니스 여행사 공식 웹사이트

---

## 소개

선샤인 웰니스는 부산의 자연, 문화, 예술, 역사를 깊고 느리게 경험하는 맞춤형 웰니스 여행을 제공합니다.

- **벤치마킹:** https://kwellnessinkorea.com/
- **타겟:** 신중년 (중장년) 웰니스 여행객
- **지역:** 부산 특화

---

## 프로그램

| # | 프로그램 | 설명 |
|---|----------|------|
| 1 | 부산 근교 투어 | 기장, 해운대, 영도 등 근교 탐방 |
| 2 | 감천 문화 마을 해설 | 전문 해설사와 함께하는 문화 탐방 |
| 3 | 부산 예술 여행 | F1963, 부산현대미술관 등 |
| 4 | 사찰 투어 | 범어사, 해동용궁사 명상 투어 |
| 5 | 시장 워킹 투어 | 국제시장, 부평깡통시장, 자갈치시장 |
